Work with Directory Locations (WRKDIRLOC)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The Work with Directory Locations (WRKDIRLOC) command provides a set of displays that allow an administrator to add, change, remove, display, print, and combine locations. When the WRKDIRLOC command is entered, the Work with Directory Locations display is shown with all the locations defined.

Restriction: The user of this command must have at least security administrator (*SECADM) authority.

There are no parameters for this command.

WRKDIRLOC
