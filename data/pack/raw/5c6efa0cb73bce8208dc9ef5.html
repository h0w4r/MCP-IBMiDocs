Release Program Temporary Fix (RLSPTF)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The Release Program Temporary Fix (PTF) (RLSPTF) command releases a PTF save file (SAVF). When a PTF SAVF is released, it is available for distribution using the Create PTF Package (CRTPTFPKG) command.

Restrictions:

  • This command is shipped with exclude (*EXCLUDE) public authority. The QPGMR, QSYSOPR, QSRV, and QSRVBAS user profiles are shipped with private authorities to use this command.

PTF (PTF)

Specifies the identifier (ID) of the PTF to release.

Top

Product (LICPGM)

Specifies the product ID of the PTF to release.

*ALL
All products are searched for the PTF being released.
character-value
Specify the 7-character product identifier.
Top

Release (RLS)

Specifies the version, release, and modification level of the product of the PTF to release.

*ONLY
This value is valid only when one release of the product's base option is installed on the system.
character-value
Specify the release level in one of the following formats:
  • VxRyMz, where Vx is the version number, Ry is the release number, and Mz is the modification level. The variables x and y can be a number from 0 through 9, and the variable z can be a number from 0 through 9 or a letter from A through Z.
  • vvrrmm, where version vv and release rr must be a number from 00 through 35, and modification mm must be a number from 00 through 09 or a letter from 0A through 0Z. The leading zeros are required. This format must be used if the version or release of the product is greater than 9.
Top

Examples 

RLSPTF   PTF(SI12345)

This command releases the save file of PTF SI12345. Releasing SI12345 allows it to be distributed using the Create PTF Package (CRTPTFPKG) command.
