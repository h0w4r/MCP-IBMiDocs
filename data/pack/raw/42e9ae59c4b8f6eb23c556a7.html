Display Debug Watch (DSPDBGWCH)

Last Updated: 2025-04-08
Where allowed to run:

Threadsafe: No 		Parameters
Examples
Error messages

The Display Debug Watches (DSPDBGWCH) command shows the list of debug watches that have been set by system debug support, for all processes on the system. This does not include watches that have been set in the Dedicated Service Tool (DST) support of the system.

There are no parameters for this command.
