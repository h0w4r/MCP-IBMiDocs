Entradas técnicas

  • TN5250: Terminal emulation protocol commonly used for IBM i 5250 sessions.
  • TN3270: 3270 terminal protocol; not the native 5250 protocol used by IBM i green-screen sessions.
  • PF4: Program/function key often mapped to prompt/help behavior such as F4 in IBM i command entry.
  • F4: Keyboard key commonly mapped to IBM i Prompt.
  • CMDKBD: Command keyboard/map related support.
  • CHGKBDMAP: Changes a keyboard map.
  • DSPKBDMAP: Displays keyboard map information.
  • SETKBDMAP: Sets keyboard map behavior where supported.
  • VT100: Terminal type that can differ from 5250 expectations.
