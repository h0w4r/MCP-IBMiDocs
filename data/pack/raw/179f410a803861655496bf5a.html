Removal of commands requiring Point-to-Point Protocol (PPP) or Layer 2 Tunneling Protocol (L2TP) support

Last Updated: 2025-10-07

Due to the removal of PPP and L2TP software support, the following Point-to-Point (PTP) connection profile commands have been removed:
  • Add Point-to-Point Profile (ADDTCPPTP)
  • Configure Point-to-Point TCPIP (CFGTCPPTP)
  • End Point-to-Point TCP/IP (ENDTCPPTP)
  • Print Point-to-Point Profile (PRTTCPPTP)
  • Remove Point-to-Point Profile (RMVTCPPTP)
  • Start Point-to-Point TCP/IP (STRTCPPTP)
  • Work with Point-to-Point TCPIP (WRKTCPPTP)
