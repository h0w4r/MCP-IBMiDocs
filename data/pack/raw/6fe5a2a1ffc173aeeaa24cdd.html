The Change Notification Command using Job Scheduler (CHGNFYJS) command allows you to specify the command to use from your notification software to send a message to a recipient you specify. The command you specify here is used by the ADDJOBJS, CHGJOBJS, and SBMJOBJS commands to send notifications for normal and abnormal job completion respectively, if a job does not start within a specified amount of time, and error messages received during the run of the job. The notification recipient and notification message values you specified for the Notification normal (PGRRCPNORM), Notification abnormal (PGRRCPABN), Notification start job (PGRRCPSTR), and Notification error message (PGRRCPERR) parameters become the substitution values that are used in the CHGNFYJS command.

Notification command (CMD)

Specifies the command used in the specified notification software to send a message. The command you specify here is used to send messages for normal and abnormal completions of jobs as well as if a job does not start within a specified amount of time.

*SAME
The current value for the parameter does not change.
*SNDDSTJS
You are to use the Send Distribution using JS (SNDDSTJS) to send notification messages using e-mail to the specified recipients. The substitution variables are used but are not specified.

Note: SMTP information must be specified before the Send Distribution using JS (SNDDSTJS) command can be used.

*NONE
You are not using a notification software package with IBM Advanced Job Scheduler for i .
character-value
Specify the command to use when you want IBM Advanced Job Scheduler for i to send a message for normal and abnormal job completion as well as if a job does not start within a specified amount of time. The two substitution variables are &RCP (recipient) and &MSGTXT (message).
Top

Examples 

CHGNFYJS   CMD('SNDMNAMSG TOUSER(&RCP)
           MSG(''&MSGTXT'')')

This command changes notification attributes for IBM Advanced Job Scheduler for i . In this example, the Send MNA Message (SNDMNAMSG) command is used to send messages to recipients as a result of normal or abnormal job completions. The values for variables &RCP (recipient) and &MSGTXT (message) are specified in the PGRRCPNORM, PGRRCPABN, PGRRCPSTR, and PGRRCPERR parameters and are the replacement values used in the CHGNFYJS command. You should enter paired quotes around the &MSGTXT variable.
