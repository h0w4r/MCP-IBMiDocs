Add Physical File Trigger (ADDPFTRG) CL command *PUBLIC authority

Last Updated: 2025-10-07

The Add Physical File Trigger (ADDPFTRG) CL command is being changed such that, by default, the command is not available for use by all users.

On IBM® i with the listed PTFs, the QSYS/ADDPFTRG *CMD will have *PUBLIC *EXCLUDE, whereas it used to be set to *PUBLIC *USE.

PTFs:
  • IBM i 7.5: SJ00316
  • IBM i 7.4: SJ00351
