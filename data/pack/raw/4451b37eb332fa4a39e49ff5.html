Change Cluster Monitor (CHGCLUMON)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: Yes 		Parameters
Examples
Error messages

The Change Cluster Monitor (CHGCLUMON) command is used to change information about a cluster monitor. The monitor was previously added with the Add Cluster Monitor (ADDCLUMON) command. The name of the HMC or VIOS partition, or the user id, or password used to authenticate to the server can be changed.

When a cluster node is started which has cluster monitors configured, Cluster Resource Services will attempt to connect to each monitor's server. If some error occurs while trying to connect, the cluster node will still be started. Cluster Resource Services can be told to connect again by using the Change Cluster Monitor command and specifying *SAME for the new server host name, the user id, and the password. The node whose monitor is being changed must be active in the cluster.

Restrictions:

  • You must have input/output system configuration (*IOSYSCFG) special authority on all nodes in the cluster to run this command.
  • This command cannot be called from a cluster resource group exit program.
  • The node where the monitor was configured to run must be active within the cluster.
  • The command will fail if any node in the cluster has a status of Partition and the server name, user id or password is being changed.
  • This command can only be used with a cluster at cluster version 7 or greater.
  • To change cluster monitors for CIM servers:
    • The 5770-UME Licensed Product (IBM Universal Manageability Enablement for i) must be installed and configured on the node on which the monitor is configured.
    • The 5733-SC1 Licensed Product (IBM Portable Utilities for i) must be installed on the node on which the monitor is configured.
    • Operating system option 33 (Portable Application Solution Environment (PASE)) must be installed on the node on which the monitor is configured.
    • The HMC version must be V8R8.5.0 or earlier.
  • To change cluster monitors for Representational State Transfer (REST) servers:
    • The Extended Base Directory Support (Option 3 of the IBM i operating system) must be installed on the node on which the monitor is configured.
    • The HMC version must be V8R8.5.0 or later.
  • If the name of the server host is being changed, the server host associated with this monitor must be running and able to communicate with the node on which the monitor is configured.

This is a required parameter.

name

This is a required parameter.

name
Specifies the node on which the monitor is configured.

Monitor type (TYPE)

Specifies the type of monitor to be changed.

*CIMSVR
The type of monitor to be changed is a CIM server.
*RESTSVR
The type of monitor to be changed is a Representational State Transfer (REST) server.
Top

Old CIM server host name (OLDCIMSVR)

Specifies the name of the current CIM server host used by the monitor.

The name must match the name that was used on the Add Cluster Monitor or a previous Change Cluster Monitor command. If the monitor was added with the complete domain name such as NYCHMC1.ABCCOMPANY.COM, that is what must be specified for the CIM server host name. If the monitor was added with a short name such as NYCHMC1, that is what must be specified for the CIM server host name.

character-value
Specify the name of the current CIM server host used by the monitor.
Top

New CIM server host name (NEWCIMSVR)

Specifies information about the CIM server which will send information about the system or logical partitions it is monitoring.

Element 1: CIM server host name

A name that uniquely identifies the HMC or VIOS partition and can be found in a domain name server to determine the HMC's or VIOS partition's IP address. The name can be the complete domain name or it can be a short name that can be uniquely found in a domain name server. For example, the domain name may be NYCHMC1.ABCCOMPANY.COM and its short name may be NYCHMC1.

*SAME
The current CIM server host name is not changed.
character-value
Specify a name for the HMC or VIOS partition.

Element 2: CIM server user id

The cluster node running the monitor must authenticate with the HMC or VIOS partition. A user id that is configured on the HMC or VIOS partition must be specified.

*SAME
The current user id is not changed.
character-value
Specify a user id that is configured on the HMC or VIOS partition.

Element 3: CIM server user password

The cluster node running the monitor must authenticate with the HMC or VIOS partition. A password associated with the user id that is configured on the HMC or VIOS partition must be specified.

*SAME
The current password is not changed.
character-value
Specify the password for the user id.

New REST server host name (NEWRESTSVR)

Specifies information about the Representational State Transfer (REST) server which sends information about the system or logical partitions it is monitoring.

Element 1: REST server host name

A name that uniquely identifies the HMC and can be found in a domain name server to determine the IP address of the HMC. The name can be the complete domain name or it can be a short name that can be uniquely found in a domain name server. For example, the domain name may be NYCHMC1.ABCCOMPANY.COM and its short name may be NYCHMC1.

*SAME
The current REST server host name is not changed.
character-value
Specify a name for the HMC.

Element 2: REST server user id

*SAME

character-value
Specify a user id that is configured on the HMC.

*SAME

Examples for CHGCLUMON

CHGCLUMON  CLUSTER(MYCLUSTER)  NODE(NODE2) TYPE(*RESTSVR)
           OLDRESTSVR(NYBLADE) NEWRESTSVR(*SAME newUser Secret2)

This command changes the user id and password the Representational State Transfer (REST) monitor authenticates with for the Hardware Management Console (HMC) NYBLADE. The monitor was configured to run on node NODE2 in the cluster MYCLUSTER. 

CHGCLUMON  CLUSTER(MYCLUSTER)  NODE(NODE2) TYPE(*CIMSVR)
           OLDCIMSVR(NYBLADE) NEWCIMSVR(*SAME newUser Secret2)

This command changes the user id and password the CIM monitor authenticates with for the blade system's VIOS partition, NYBLADE. The monitor was configured to run on node NODE2 in the cluster MYCLUSTER. 

CHGCLUMON  CLUSTER(MYCLUSTER)  NODE(NODE2) TYPE(*RESTSVR)
           OLDRESTSVR(NYBLADE) NEWRESTSVR(*SAME *SAME *SAME)

This command attempts to start the Representational State Transfer (REST) monitor for the Hardware Management Console (HMC) NYBLADE. The monitor was configured to run on node NODE2 in the cluster MYCLUSTER.
