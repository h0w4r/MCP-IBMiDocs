Work with Document Print Queue (WRKDOCPRTQ)

Last Updated: 2025-04-08

Threadsafe: No 		Parameters

The Work with Document Print Queue (WRKDOCPRTQ) command calls OfficeVision/400 to show the Work With Documents To Be Printed display. From this display, users can manage their printed output.

There are no parameters for this command.
