Display Expiration Schedule (DSPEXPSCD)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The Display Expiration Schedule (DSPEXPSCD) command displays the list of user profiles, their expiration date, and the expiration action to be taken (disable or delete the profile). If there are no user profiles set to automatically expire, an empty report will be produced.

If the expiration action is delete then the owned object option (*NODLT, *DLT, *CHGOWN) and the primary group option (*NOCHG, *CHGPGP) are shown. If the owned object option is *CHOWN then the new owner is shown. If the primary group option is *CHGPGP then the new primary group and the new primary group authority are shown.

The user profile entries were added from one of the following:

  • The Create User Profile (CRTUSRPRF) or Change User Profile (CHGUSRPRF) command specified the User expiration date (USREXPDATE) or User expiration interval (USREXPITV) parameter to specify that the user profile should be automatically disabled when the user expiration date is reached.
  • The Change Expiration Schedule Entry (CHGEXPSCDE) command was run to disable or delete a user profile on a specified date.

Restriction: You must have all object (*ALLOBJ) special authority to run this command.

Output (OUTPUT)

Specifies whether the output from the command is shown at the requesting work station or printed.

*
Output requested by an interactive job is shown on the display. Output requested by a batch job is printed with the job's spooled output.
*PRINT
The output is printed with the job's spooled output.
