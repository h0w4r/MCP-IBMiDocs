The Configure TCP/IP REXEC (CFGTCPRXC) command provides a single interface for configuring attributes related to the Remote EXECution (REXEC) server and for running any other REXEC-related configuration commands.

Restrictions:

  • When prompting, you must have input/output system configuration (*IOSYSCFG) special authority or have access to the QIBM_IOSYSCFG_VIEW function usage identifier to view the associated attributes.
  • To change attributes, you must have input/output system configuration (*IOSYSCFG) special authority.
