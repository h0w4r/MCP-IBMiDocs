The Configure Point-to-Point TCPIP (CFGTCPPTP) command is used to display a menu that allows you to define, change, or display the TCP/IP point-to-point configuration.

The following options cannot be used with *PPP line type profiles:

  • Change
  • Copy
  • Remove
  • Display details

The following options can be used with *PPP linetype profiles:

  • Start
  • End
  • Work with line status
  • Work with session job

Use the Systems Director Navigator interface for Configuration of *PPP Slip or Point to Point profiles.

There are no parameters for this command.
