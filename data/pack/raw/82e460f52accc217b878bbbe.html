IBM i database file, member and dependency commands

Comandos de IBM i para inspeccionar archivos físicos/lógicos, miembros, referencias de programa, relaciones de base de datos y dependencias.

Intenciones cubiertas

  • How do I list members of a file?
  • How can I see what files a program uses?
  • How do I inspect database relations or logical files?
  • Which commands help inspect physical files, field descriptions and dependencies?

Comandos principales

  • DSPFD: Display File Description.
  • DSPFFD: Display File Field Description.
  • WRKMBRPDM: Work with Members using Programming Development Manager.
  • DSPDBR: Display Data Base Relations.
  • DSPPGMREF: Display Program References.
  • CRTPF: Create Physical File.
  • CRTLF: Create Logical File.
  • DSPPFM: Display Physical File Member.
  • CPYF: Copy File.
  • RUNQRY: Run Query.
  • STRSQL: Start SQL Interactive Session.
