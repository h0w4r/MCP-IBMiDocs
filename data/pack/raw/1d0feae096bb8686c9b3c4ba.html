Copy PTF to Save File (CPYPTFSAVF)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The Copy Program Temporary Fixes (PTFs) to Save Files (CPYPTFSAVF) command allows you to copy all or selected PTFs for installed and supported products from a device into PTF save files.

A save file is created in the QGPL library for each PTF that is copied. If the PTF exists, the PTF is not copied. When the PTF save file is created in the QGPL library, it is named Qxxxxxxx where xxxxxxx is the PTF identification number or a time stamp.

Cover letters are members of file QAPZCOVER in library QGPL, and are named Qxxxxxxyy, where xxxxxxx is the PTF identification number and yy is the language of the PTF. For English cover letters yy is blank.

Restrictions:

  • This command is shipped with exclude (*EXCLUDE) public authority. The QPGMR, QSYSOPR, QSRV, and QSRVBAS user profiles are shipped with private authorities to use this command.
  • Only PTFs for installed and supported products are copied.

From device (FROMDEV)

Specifies the tape or optical device from which the PTFs are copied.

This is a required parameter.

name
Specify the name of the tape or optical device from which the PTFs are copied.
Top

Product (LICPGM)

Specifies the product for which PTFs are copied.

*ALL
The PTFs for all installed and supported products are copied.
*SUPPTD
The PTFs for all supported products are copied. PTFs for products that are installed but not supported are not copied.
character-value
Specify the 7-character product identifier for which PTFs are copied.
Top

PTF numbers to select (SELECT)

Specifies which PTFs are copied. If individual PTFs are specified, a value cannot be specified for the PTF numbers to omit (OMIT) parameter.

Single values

*ALL
All the PTFs are copied.

Other values (up to 50 repetitions)

character-value
Specify the PTF number of each programming fix to be copied.
Top

PTF numbers to omit (OMIT)

Specifies that all PTFs except for those specified in this parameter are copied. Specify the PTF numbers of the programming fixes not copied when all the rest are copied. A maximum of 50 PTF numbers can be specified. This parameter cannot be specified if single PTF numbers are specified for the PTF numbers to select (SELECT) parameter.

character-value
Specify the PTF number of each programming fix to be omitted (not copied).

Examples

Example 1: Copying PTFs for a Specified Program 

CPYPTFSAVF   FROMDEV(OPTVRT01)  LICPGM(5770SS1)

This command copies all PTFs for the IBM i licensed program from device OPTVRT01 into save files on the system.

Example 2: Copying All PTFs 

CPYPTFSAVF   FROMDEV(OPTVRT01)  LICPGM(*ALL)

This command copies all PTFs for all installed or supported products from device OPTVRT01 into save files on the system.

Example 3: Copying PTFs for a Supported Product 

CPYPTFSAVF   FROMDEV(TAP01)  LICPGM(*SUPPTD)

This command copies PTFs for all supported products from device TAP01 into save files on the system.

Example 4: Copying a Specific PTF 

CPYPTFSAVF   FROMDEV(OPT01)  LICPGM(5770SS1)  SELECT(PTF0001)

This command copies only PTF PTF0001 for the IBM i licensed program from device OPT01 to a save file on the system.
