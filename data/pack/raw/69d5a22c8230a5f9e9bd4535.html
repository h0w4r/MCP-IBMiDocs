Change in the interpretation of dates with 2-digit years in CL programs for the CVTDAT command or commands with date parameters

Last Updated: 2025-10-07

If the source for a CLP or CLLE program or module has a literal value for the Convert Date (CVTDAT) command or for commands in CL programs with parameters of type *DATE, and the literal represents a date with a 2-digit year format such as mmddyy, the meaning of the literal will change if the yy portion of the date is between 40 and 69 and the base year of the job is 1970.

Similarly, if the value specified for the CVTDAT command or for commands in CL programs with date parameters is in a variable representing a date with a 2-digit year, and the value of the variable comes from a permanent location such as the data in a file, the meaning of the variable will change if the yy portion of the date is between 40 and 69 and the base year of the job is 1970.

This change will be in effect whenever the program is called, depending on the base year of the job calling the program. The change will take effect even if the program is not recompiled.
