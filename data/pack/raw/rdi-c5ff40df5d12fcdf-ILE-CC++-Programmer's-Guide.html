ILE C/C++ Programmer's Guide

Requirements

To build a C++ program that uses the 8-byte run-time binding library extensions, use the following compiler options:

  • Data Model option DTAMDL(*LLP64)
  • Storage Model option STGMDL(*TERASPACE)
  • TERASPACE(*YES *TSIFC)
  • Run-Time Binding option RTBND(*LLP64)
Note:
For information specific to using these options, see WebSphere Development Studio: ILE C/C++ Compiler Reference.
