ILE C/C++ Programmer's Guide

Chapter 23. Using ILE C/C++ Call Conventions

This chapter discusses ILE calling conventions as they apply to programs compiled with the ILE C/C++ compiler. For information about calling conventions that apply to multi-language applications, see Chapter 25, Working with Multi-Language Applications.

This chapter describes:

  • Program and procedure calls
  • Renaming programs and procedures
  • Calling programs that have library qualification (using bindable APIs)
  • Calling an ILE C++ program from ILE C
  • Accessing C++ classes from ILE C
Note:
The terms parameter and argument are used interchangeably.
