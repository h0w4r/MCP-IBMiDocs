Network Command and API Authority Changes

Last Updated: 2025-10-07

The following command authority changes were made for IBM® i 7.6.

Public authority changed to public *EXCLUDE (was previously public *USE) for the following command:
  • Display Firmware Status (DSPFMWSTS)
Commands now requiring either *IOSYSCFG special authority or access to the QIBM_IOSYSCFG_VIEW function usage are:
  • Configure TCP/IP (CFGTCP)
  • Configure TCP/IP SNMP (CFGTCPSNMP)
  • Work with TCP/IP Network Stats (NETSTAT, WRKTCPSTS)
  • Work with Network Table Entries (WRKNETTBLE)
  • Work with Protocol Table Entry (WRKPCLTBLE)
  • Work with Service Table Entry (WRKSRVTBLE)
  • Configure TCP/IP Applications (CFGTCPAPP)
Commands now requiring either *IOSYSCFG special authority or access to the QIBM_IOSYSCFG_VIEW function usage in order to see existing parameter values when using the F4 (Prompt) function are:
  • Change Community for SNMP (CHGCOMSNMP)
  • Change SNMP Attributes (CHGSNMPA)
  • Change TCP/IP Attributes (CHGTCPA)
  • Change TCP/IP Domain (CHGTCPDMN)
  • Change TCP/IP Host Table Entry (CHGTCPHTE)
  • Change TCP/IP Route (CHGTCPRTE)
  • Change TCP/IP Server (CHGTCPSVR)
  • Change User for SNMP (CHGUSRSNMP)
  • Change LPD Attributes (CHGLPDA)
The following command now requires *IOSYSCFG special authority in order to see existing parameter values when using the F4 (Prompt) function:
  • Change VACM for SNMP (CHGVACSNMP)
APIs now requiring either *IOSYSCFG special authority or access to the QIBM_IOSYSCFG_VIEW function usage are:
  • List Neighbor Cache Table (QtocLstNeighborTbl)
  • List Network Connections (QtocLstNetCnn)
  • List Network Interfaces (QtocLstNetIfc)
  • List Network Routes (QtocLstNetRte)
  • List Physical Interface ARP Table (QtocLstPhyIfcARPTbl)
  • List Physical Interface Data (QtocLstPhyIfcDta)
  • Retrieve Network Connection Data (QtocRtvNetCnnDta)
  • Retrieve Network Interface Data (QtocRtvNetIfcDta)
  • Retrieve TCP/IP Attributes (QtocRtvTCPA)
APIs now requiring either *SERVICE special authority or access to the QIBM_SERVICE_TRACE function usage are:
  • Change Connection Attributes (QTOCCCNA)
