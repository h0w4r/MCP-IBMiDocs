Display VT Keyboard Map (DSPVTMAP)

Last Updated: 2025-04-08
Where allowed to run: Interactive environments (*INTERACT *IPGM *IREXX *EXEC)
Threadsafe: No 		Parameters
Examples
Error messages

The Display VT Keyboard Map (DSPVTMAP) command displays the current values for the keyboard mapping of your Telnet VT100 or VT220 session.

There are no parameters for this command.

None

DSPVTMAP
