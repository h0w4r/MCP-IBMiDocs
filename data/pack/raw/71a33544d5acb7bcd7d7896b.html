ILE C/C++ Programmer's Guide

Supported Teraspace Environments

ILE C/C++ provides 16-byte pointer libraries. ILE C++ also provides 8-byte pointer libraries (RTBND). These libraries are not binary-compatible. When using teraspace, ensure that bound modules are binary compatible. See Binary Compatibility Considerations When Porting Code in a Teraspace Environment.

Note:
For a detailed description of teraspace and other storage models, see the chapter on "Teraspace and Single-Level Store" in ILE Concepts.
