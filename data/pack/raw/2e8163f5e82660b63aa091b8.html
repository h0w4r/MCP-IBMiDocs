Delete Authority Holder (DLTAUTHLR)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The Delete Authority Holder (DLTAUTHLR) command allows a user to delete an authority holder that secures an object of type *FILE.

Restrictions:

  • The authority holder can be deleted by a user who has all object (*ALLOBJ) special authority or all (*ALL) authority to the object it secures.

name
Specify the name of the authorization holder object.

Qualifier 2: Library

name

Examples 

DLTAUTHLR   OBJ(QGPL/FIL1)

This command deletes the authority holder for FIL1 in the QGPL library.
