Remove Protocol Table Entry (RMVPCLTBLE)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The Remove Protocol Table Entry (RMVPCLTBLE) command is used to remove a protocol entry from the protocol table. The protocol table is used to manage a list of protocols used in the Internet.

Restrictions:

  • You must have input/output system configuration (*IOSYSCFG) special authority to run this command.

Protocol (PROTOCOL)
