Edit DL File Attributes (EDTDLFA)

The Edit DataLink File Attributes (EDTDLFA) command allows the user to display and change the status of DataLinks.

There are no parameters for this command.

None

Examples

Editing a List of DataLinks 

EDTDLFA

This command shows you the DataLinks that have pending DataLink requests. You can edit the sequence for attempting the pending linking or unlinking requests from this display.
