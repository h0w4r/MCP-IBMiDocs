C/C++ Pointer Support

To enable programs for teraspace, C and C++ compilers provide the following pointer support:

  • Syntax for explicitly declaring 8- or 16-byte pointers:
    • Declare a 8-byte pointer as char * __ptr64
    • Declare a 16-byte pointer as char * __ptr128
  • Syntax for specifying and overriding the data model that is unique to the C/C++ programming environment. See The 8-Byte Run-Time Binding (RTBND) Library Extensions.
