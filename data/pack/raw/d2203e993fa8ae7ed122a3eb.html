Display Keyboard Map (DSPKBDMAP)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The Display Keyboard Map (DSPKBDMAP) command shows the current F-to-PF map for the 3270 work station device from which the command was sent. More information on user-assignable keyboard mapping is in the Remote Work Station Support book, SC41-5402 book.

There are no parameters for this command.

Examples 

DSPKBDMAP

The DSPKBDMAP command uses the 3270 help screen to display the active PF key mapping for the device the command was entered on.
