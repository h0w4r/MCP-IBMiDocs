Work with BOOTP table (WRKBPTBL)

The Work with BOOTP Table (WRKBPTBL) command allows you to work with entries in the BOOTP table. Each table entry contains a client host name, an MAC address, and an internet protocol (IP) address.

You can add, change, remove, or display entries in this table. You can also print the table.

There are no parameters for this command.
