Push buttons

Select one of the following push buttons:

OK
Records the information you typed in the entry fields of this prompt window. If no errors are detected, the prompt for the next specification line in the file appears. If you have entered text indicating a different specification line, the prompt for that line replaces the current prompt.
Select
Lets you select another prompt from the RPG Specification Selection window, and closes this prompt without saving any of the values you have typed into it.
Cancel
Returns you to the Editor window. This prompt is closed, and the values you have typed into it are not saved.
Help
Displays ILE RPG help information for the item the cursor is on.
