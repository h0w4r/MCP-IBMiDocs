Documenting command

If you define and create your own CL commands, you can also create online command help to describe your commands.

  • Commands and command help
    Command prompting and online command help are powerful features of CL commands.
  • Writing command help
    After you understand how a command (*CMD) object can be connected to an online help panel group (*PNLGRP) object, you can write the help text that goes into the four types of help modules for a command.
  • Generating HTML source for command documentation
    To generate Hyper Text Markup Language (HTML) information to be viewed using a browser from your online help, use the Generate Command Documentation (GENCMDDOC) command and specify *HTML for the GENOPT (Generation Options) parameter.
