Authority change for tape commands and APIs

Last Updated: 2025-10-07

Tape Command authority changes

The following tape and tape related commands now require *IOSYSCFG special authority to use:
  • Add Tape Cartridge (ADDTAPCTG)
  • Change Tape Cartridge (CHGTAPCTG)
  • Check Tape (CHKTAP)
  • Create Tape Category (CRTTAPCGY)
  • Delete Tape Category (DLTTAPCGY)
  • Display Tape (DSPTAP)
  • Set Tape Category (SETTAPCGY)
  • Change Tape File (CHGTAPF)
  • Create Tape File (CRTTAPF)
  • Override Tape File (OVRTAPF)
The following tape and tape related commands now require *IOSYSCFG special authority or to be authorized to the QIBM_IOSYSCFG_VIEW function ID to use:
  • Display Tape Cartridge (DSPTAPCTG)
  • Display Tape Status (DSPTAPSTS)
  • Work with Tape Cartridge (WRKTAPCTG)

Tape application programming interfaces (API) authority changes

The following tape APIs now require *IOSYSCFG special authority to use:
  • Retrieve Tape Labels (QTARTLBL)
The following tape APIs now require *IOSYSCFG special authority or to be authorized to the QIBM_IOSYSCFG_VIEW function ID to use:
  • Retrieve Cartridge Filter (QTARCTGF)
  • Retrieve Cartridge Information (QTARCTGI)
  • Retrieve Device Status (QTARDSTS)
