CHGRDBDIRE command authority requirements change

Last Updated: 2025-11-20

On IBM® i 7.5, the authority requirements for the Change RDB Directory Entry (CHGRDBDIRE) and Remove RDB Directory Entry (RMVRDBDIRE) commands have changed to be consistent with the prior requirements for the Remove RDB Directory Entry (RMVRDBDIRE) and Change DDM TCP/IP Attributes (CHGDDMTCPA) commands.

Special authorities *SECADM, *ALLOBJ, and *IOSYSCFG are needed to use the CHGRDBDIRE command to change a *LOCAL RDB directory entry. These requirements are already enforced for remove.

*IOSYSCFG is needed when changing or removing an RDB entry associated with an IASP.
