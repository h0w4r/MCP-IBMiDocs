CHGDEVDSP and CRTDEVDSP command changes

Last Updated: 2025-10-07

The Create Device Desc (Display) (CRTDEVDSP) and Change Device Desc (Display) (CHGDEVDSP) commands have changed.

The Maximum length of request unit (MAXLENRU) parameter has been removed.

Any existing CL programs that use these commands might need to be modified.
