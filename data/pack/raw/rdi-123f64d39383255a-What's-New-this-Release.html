What's New this Release?

The following list describes the enhancements made to ILE COBOL in 7.3:

  • New intrinsic function PARMS returns the number of parameters that were passed to the program or procedure in which the PARMS intrinsic function is used.
    Note: Some calling programs may not provide the information for the PARMS intrinsic function to operate correctly for a bound call.
  • The maximum number of CALL PROCEDURE parameters is increased from 400 to 16,382.
  • NATIONAL is now a supported class in the class condition test. You can test whether an item with usage NATIONAL is NATIONAL, ALPHABETIC, ALPHABETIC-LOWER, ALPHABETIC-UPPER, or NUMERIC.
  • National-edited data type is now supported. National-edited data items are similar to alphanumeric-edited data items but encoded in Unicode. The allowed picture string characters are N, B, 0, /, and the picture string must include at least one N and have USAGE NATIONAL. For example 
    01 B pic NN/NN/NN usage national.
  • National numeric-edited data type is now supported. National numeric-edited data items contain numeric-edited data but are encoded in Unicode. The allowed picture string characters are B, P, V, Z, 9, 0, slash (/), comma (,), period (.), CR, DB, asterisk (*), cs, and have USAGE NATIONAL. For example 
    01 C pic Z(9)9V99 usage national.
