Work with Data Dictionaries (WRKDTADCT)

Last Updated: 2025-04-08

The Work with Data Dictionaries (WRKDTADCT) command shows a display that allows you to select options to create, change, delete, or print the contents of a data dictionary.

There are no parameters for this command.
