CHGTELNA Command Authority Changes

Last Updated: 2025-10-07

The Change Telnet Attributes command (CHGTELNA) previously allowed users to view the current Telnet attributes without special authority when prompting. This is changed on IBM® i 7.6 to require users to have *IOSYSCFG special authority or QIBM_IOSYSCFG_VIEW function usage. This changes the required authorities only when prompting and not when running the command.
