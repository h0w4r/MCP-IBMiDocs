End Controller Recovery (ENDCTLRCY)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The End Controller Recovery (ENDCTLRCY) command ends automatic error recovery procedures for a specific controller. If any type of failure occurs after this command is run, an inquiry message is sent to the system operator.

Use the Resume Controller Recovery (RSMCTLRCY) command to reestablish error recovery procedures for the controller.

Controller (CTL)

Specifies the controller whose recovery is to be ended.

This is a required parameter.

Top

Examples 

ENDCTLRCY   CTL(TROLL3)

This command ends error recovery procedures for the controller TROLL3.
