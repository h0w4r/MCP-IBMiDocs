CHGSNMPA command changes

Last Updated: 2025-10-07

Specifying the value *SYSGEN for the System description (SYSD) parameter of the Change SNMP Attributes (CHGSNMPA) command will no longer generate a textual description of the system at the time the command is run. If you have previously specified *SYSGEN and then prompt the CHGSNMPA command, it will show the value *SYSGEN instead of generated text. This does not affect the information returned by the IBM® i SNMP agent when processing a get, get next, or get bulk request for the system description (sysDescr).
