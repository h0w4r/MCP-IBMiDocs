Clear Trace Data (CLRTRCDTA)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The Clear Trace Data (CLRTRCDTA) command clears (removes) all of the data from any previous trace operations in this debugging session. Once cleared, the data can no longer be displayed or printed.

Restriction: This command is valid only in debug mode.

There are no parameters for this command.

Top

Examples 

CLRTRCDTA

This command clears all of the data recorded from any and all previous tracing operations in all of the programs currently being debugged.
