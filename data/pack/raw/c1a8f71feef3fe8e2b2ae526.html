Keyword considerations for printer files that use DBCS

You cannot use these keywords with double-byte character set (DBCS) data fields (the data type specified in position 35 is O or G).

BARCODE
BLKFOLD
CDEFNT
CHRID
COLOR
CPI
CVTDTA
DATE
DATFMT
DATSEP
DFT

EDTCDE
EDTWRD
FLTFIXDEC

FNTCHRSET
FONT

MSGCON
PAGNBR
TIME

TIMSEP
TRNSPY

Do not use the IGCALTTYP and IGCANKCNV keywords on DBCS-graphic data fields (G specified in position 35).

  • CHRSIZ (Character Size) keyword
    You use this record-level or field-level keyword to expand the printed characters to twice their normal width, their normal height, or their normal size (width and height).
  • DFNLIN (Define Line) keyword
    You use this record-level keyword to draw a horizontal or a vertical line.
  • IGCALTTYP (Alternative Data Type) keyword
    You use this field-level keyword to change alphanumeric character fields to the DBCS fields of data type O.
  • IGCANKCNV (Alphanumeric-to-DBCS Conversion) keyword
    You use this field-level keyword to convert alphanumeric characters to equivalent DBCS characters (Japanese only).
  • IGCCDEFNT (DBCS Coded Font) keyword
    You use this record- or field-level keyword to specify the DBCS-coded font for printing named or constant fields.
  • IGCCHRRTT (DBCS Character Rotation) keyword
    This field- or record-level keyword rotates each DBCS character 90 degrees counterclockwise before printing.
