Action parameter for the db2mtool command

Last Updated: 2025-10-07

The db2mtool command has different action parameters for working with the configuration files, performing cloning operations, and configuring clustering.

  • Configuration file actions
    This section describes the actions that work with the JSON configuration files.
  • Clone actions
    This section describes the actions that are used for cloning operations.
  • Cluster actions
    The db2mtool action=cluster parameter provides a command-line interface to IBM® i clustering functions.
