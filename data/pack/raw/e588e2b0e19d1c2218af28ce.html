Command and API Authority Changes

Last Updated: 2025-10-07

The following commands will now require additional authority to display, retrieve and work with configuration information. Authority is required to either the QIBM_IOSYSCFG_VIEW function usage ID or *IOSYSCFG special authority. Commands:

  • Display Configuration List (DSPCFGL)
  • Display Class-of-Service Desc (DSPCOSD)
  • Display Controller Description (DSPCTLD)
  • Display Device Description (DSPDEVD)
  • Display Line Description (DSPLIND)
  • Display Mode Description (DSPMODD)
  • Display NetBIOS Description (DSPNTBD)
  • Display Network Server Desc (DSPNWSD)
  • Retrieve Configuration Source (RTVCFGSRC)
  • Work with Configuration Lists (WRKCFGL)
  • Work with Configuration Status (WRKCFGSTS)
  • Work with COS Descriptions (WRKCOSD)
  • Work with Ctl Descriptions (WRKCTLD)
  • Work with Device Descriptions (WRKDEVD)
  • Work with Line Descriptions (WRKLIND)
  • Work with Media Library Status (WRKMLBSTS)
  • Work with Mode Descriptions (WRKMODD)
  • Work with NetBIOS Descriptions (WRKNTBD)
  • Work with Network Servers (WRKNWSD)

The following APIs will now require additional authority to list or retrieve configuration information.

The QDCCCFGD API requires *IOSYSCFG special authority.

For the following list and retrieve APIs, authority is required to either the QIBM_IOSYSCFG_VIEW function usage ID or *IOSYSCFG special authority. APIs:
  • Change Configuration Description (QDCCCFGD) API
  • List Configuration Descriptions (QDCLCFGD) API
  • Retrieve Configuration Status (QDCRCFGS) API
  • Retrieve Controller Description (QDCRCTLD) API
  • Retrieve Device Description (QDCRDEVD) API
  • Retrieve Line Description (QDCRLIND) API
  • Retrieve Network Server Description (QDCRNWSD) API
The following commands were changed to return a “function not supported” message since the configuration object is not supported:
  • Create Device Desc (Diskette) (CRTDEVDKT)
  • Change Device Desc (Diskette) (CHGDEVDKT)
  • Display Connection List (DSPCNNL)
  • Display IPX Description (DSPIPXD)
  • Display Network Interface Desc (DSPNWID)
  • Work with Connection Lists (WRKCNNL)
  • Work with IPX Descriptions (WRKIPXD)
  • Work with Network Interfaces (WRKNWID)
Commands now requiring *IOSYSCFG special authority are:
  • Add RDB Directory Entry (ADDRDBDIRE)
  • Remove RDB Directory Entry (RMVRDBDIRE)
  • Change RDB Directory Entry (CHGRDBDIRE)
  • Create DDM File (CRTDDMF)
  • Change DDM File (CHGDDMF)Delete File (DLTF) - for Distributed Data Management (DDM) files only when SYSTEM(*RMT) or SYSTEM(*FILETYPE) is specified
Commands now requiring either *IOSYSCFG special authority or access to the QIBM_IOSYSCFG_VIEW function usage are:
  • Display DDM File (DSPDDMF)
  • Work with DDM Files (WRKDDMF)
  • Display Relational Database Directory Entries (DSPRDBDIRE)
  • Work with Relational Database Directory Entries (WRKRDBDIRE)
Commands now requiring either *IOSYSCFG special authority or access to the QIBM_IOSYSCFG_VIEW function usage in order to see existing parameter values when using the F4 (Prompt) function are:
  • Change DDM TCP/IP Attributes (CHGDDMTCPA)
  • Change RDB Directory Entry (CHGRDBDIRE)
  • Change DDM File (CHGDDMF)
