Work with Service Providers (WRKSRVPVD)

Last Updated: 2025-04-08

Threadsafe: No 		Parameters
Examples
Error messages

The Work with Service Providers (WRKSRVPVD) Command allows you to work with a menu which contains a list of service providers to whom you can report service problems and send PTF orders. From this menu, you can add, change, copy, delete, or display service providers.

Restriction: To use this command, the user must be signed on as QSRV or QSRVBAS, or have *ALLOBJ authority.

There are no parameters for this command.
