Start IDDU (STRIDD)

Last Updated: 2025-04-08
Where allowed to run: Interactive environments (*INTERACT *IPGM *IREXX *EXEC)
Threadsafe: No 		Parameters
Examples
Error messages

The Start Interactive Data Definition Utility (STRIDD) command runs the main Interactive Data Definition (IDDU) menu. From this menu, you can select from options that allow you to work with data definitions, data dictionaries, files, and libraries, or use related commands and office tasks.
