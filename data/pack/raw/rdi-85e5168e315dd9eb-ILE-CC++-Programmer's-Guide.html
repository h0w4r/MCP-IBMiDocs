ILE C/C++ Programmer's Guide

Resource Requirements

To create the sample application, you need to create the following resources:

  • A binding directory for the ILE C application modules and service programs
  • Source code for:
    • Data Description Specification (DDS) T1520DD1 for the output file.
    • CL Program T1520CL1
    • CL CMD Program T1520CM1
    • ILE C/400 Program T1520PG1 modules T15201C1 and T15201C2
    • Service program T1520SP1 module T15201C3 and its binder language QSRVSRC
    • Service program T1520SP2 module T15201C4 and its binder language QASRVSRC
Note:
This example is for illustration purposes. It is not necessary to create a binding directory for an ILE C program of this size. You might not want to break up ILE C service programs by data and function as shown.
