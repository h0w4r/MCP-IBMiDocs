Configure TCP/IP RouteD (CFGTCPRTD)

The Configure TCP/IP RouteD (CFGTCPRTD) command is used to display a menu that allows a user to define or change the RouteD configuration.

There are no parameters for this command.

Restrictions:

You must have *IOSYSCFG special authority to use this command.
