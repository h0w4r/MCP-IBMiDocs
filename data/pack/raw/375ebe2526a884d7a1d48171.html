.. EOF Control Statement

Use the end-of-file (.. EOF) control statement to end the reader input stream. When this control statement is in the input stream, it sends an end-of-file sequence to the host subsystem. This control statement can be placed in a command file, issued using direct-workstation input, or issued from the RJE console. It has no parameters.
