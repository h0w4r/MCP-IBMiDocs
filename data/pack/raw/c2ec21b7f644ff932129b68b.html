%LOOKUP, and the IN operator, with arrays of type Object

Last Updated: 2025-10-07

Prior to release IBM® i 7.6, when %LOOKUP was used with an array of type Object, %LOOKUP always returned zero, indicating that the search argument was not found in the array. Similarly, when the IN operator was used with an array or %LIST of type Object, it always returned *OFF.

Starting in the base of release 7.6 for TGTRLS(*CURRENT), %LOOKUP returns the index of the element that matches the search argument and the IN operator returns *ON if an element of the array in the second operand of the IN operator matches the search argument.

For target releases V7R4M0 and V7R5M0, you can add environment variable, QIBM_RPG_CORRECT_OBJECT_LOOKUP, with a value of 'Y', to cause the compiler to handle the Object arrays correctly.
