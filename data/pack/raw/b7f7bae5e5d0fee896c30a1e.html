The Work with Remote Definitions (WRKRMTDFN) command can be used to work with entries in the remote system definition table.

Restriction: You must have *ALLOBJ authority to use this command.

There are no parameters for this command.

Top

Parameters

None
Top

Examples 

WRKRMTDFN

This command shows the Work with Remote Definitions panel, from which you can add, change, remove, display, or print the remote definition for a particular system.
