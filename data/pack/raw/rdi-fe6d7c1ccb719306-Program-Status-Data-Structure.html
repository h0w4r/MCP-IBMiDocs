Program-Status Data Structure

A program-status data structure, identified by the PSDS keyword for a free-form definition, or by an S in position 23 of a fixed-form definition, provides program exception/error information to the program. For a discussion of program-status data structures and their predefined subfields, see Program Status Data Structure.
