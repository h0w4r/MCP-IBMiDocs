Entradas técnicas

  • SETLL: Set Lower Limit; positions a file to a key or limit before subsequent read operations.
  • SETGT: Set Greater Than; positions a keyed file after a key value.
  • CHAIN: Random retrieval from a file by key or relative record number.
  • READE: Read equal key records after file positioning.
  • READPE: Read prior equal key records after file positioning.
  • EXFMT: Write a display format and then read the same format, commonly used for interactive display files.
  • WRITE: Writes a record or display format.
  • READ: Reads the next record or input from a format.
  • CAT: Legacy concatenate operation code for joining character strings.
  • *CAT: CL/RPG-style concatenation operator used to concatenate strings.
  • RETURN: Returns control from a program or procedure.
  • *INLR: Last-record indicator commonly used by RPG programs to end and close resources.
  • SETON LR: Legacy pattern for setting the LR indicator on.
  • VARYING: Variable-length alphanumeric/graphic field support in RPG definitions.
  • %FOUND: Built-in function used to test whether operations such as SETLL or CHAIN found a record.
  • %LEN: Built-in function that returns current or maximum length, including varying-length fields.
