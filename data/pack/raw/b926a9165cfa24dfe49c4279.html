Dump Cluster Trace command (DMPCLUTRC) now PUBLIC authority *EXCLUDE

Last Updated: 2025-10-07

Dump Cluster Trace command (QSYS/DMPCLUTRC) PUBLIC authority is changed from *USE to *EXCLUDE in IBM i 7.6.

This now matches the command CPP, QSYS/QCSTDMPTRC, which is PUBLIC *EXCLUDE. The DMPCLUTRC CPP continues to require *SERVICE special authority and *USE authority to any cluster object that has user authorities (for example: CRG objects, which are PUBLIC *EXCLUDE).
