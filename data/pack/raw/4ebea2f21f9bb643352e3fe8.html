End Transform Manager (ENDTFMMGR)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No		 Parameters
Examples
Error messages

The End Transform Manager (ENDTFMMGR) command is used to end any Infoprint Server for iSeries transform manager server jobs that are running in the QUSRWRK subsystem. If you are currently converting any spool files when the ENDTFMMGR command is issued, the spool files will be held on the output queue.

Restrictions:

  1. *JOBCTL special authority is required to run this command.
