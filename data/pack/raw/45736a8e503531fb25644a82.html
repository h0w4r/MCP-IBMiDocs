TRCCNN command changes

Last Updated: 2025-10-07

The Trace Connection (TRCCNN) command has allowed multiple values to be specified for the Trace type (TRCTYPE)parameter since its introduction in OS/400® V4R5. The command is never used in this manner. The option to specify multiple TRCTYPE values has been eliminated.

The TRCTYPE parameter is replacing the *SSL value with *TLS to accurately reflect that Secure Sockets Layer (SSL) has been replaced by Transport Layer Security (TLS).

The TCP/IP data (TCPDTA) parameter, Protocal element *ARP has been removed.

CL programs that use the TRCCNN command may need to be updated and recompiled to accommodate these changes.
