What's new for IBM i 7.6

Last Updated: 2025-10-07

This topic highlights the changes made to this topic collection for IBM® i 7.6.

The major new features covered in this book include:

  • Support for the XSLTRANSFORM scalar function has been removed due to 5733-XT2 IBM XML Toolkit for i going out of service.
  • data-change-table-reference is extended to return rows affected by UPDATE and DELETE operations: table-reference, DELETE, and UPDATE
  • The CONNECT statement can pass an additional factor for authentication: CONNECT (type 1) and CONNECT (type 2)
  • The authorization rules for creating an alias that references a non-local relational database have changed: CREATE ALIAS
  • When creating an encoded vector index, the default for the estimated number of distinct key values has changed to 65535: CREATE INDEX
  • The GRANT and REVOKE statements issue an error if the authority cannot be completely granted or revoked: GRANT (function or procedure privileges), GRANT (package privileges), GRANT (schema privileges), GRANT (sequence privileges), GRANT (table or view privileges), GRANT (type privileges), GRANT (variable privileges), GRANT (XML schema privileges), REVOKE (function or procedure privileges), REVOKE (package privileges), REVOKE (schema privileges), REVOKE (sequence privileges), REVOKE (table or view privileges), REVOKE (type privileges), REVOKE (variable privileges), REVOKE (XML schema privileges)

What’s new as of November 2025

  • INSERT with VALUES supports named columns: INSERT
  • EVEN and ODD functions are added in the SYSTOOLS schema: EVEN and ODD
  • URL_DECODE and URL_ENCODE support strings up to 2 gigabytes: URL_DECODE and URL_ENCODE

What’s new since the first IBM i 7.5 publication

The following revisions or additions are new since the initial release of IBM i 7.5:
  • REPLICATION_OVERRIDE allows user-provided values to be specified for all generated columns for insert, update, and merge statements: REPLICATION_OVERRIDE
  • ANY_VALUE aggregate function returns an arbitrary value for a group of rows: ANY_VALUE
  • ADD_DAYS, ADD_HOURS, ADD_MINUTES, ADD_SECONDS, and ADD_YEARS scalar functions provide date arithmetic capability: ADD_DAYS, ADD_HOURS, ADD_MINUTES, ADD_SECONDS, and ADD_YEARS
  • ENCRYPT_AES256 function uses a 256 bit encryption key: ENCRYPT_AES256
  • FIRST_DAY scalar function returns the first day of a month: FIRST_DAY
  • The GENERATE_UUID and GENERATE_UUID_BINARY functions return a Universally Unique Identifier (UUID) using the version 4 algorithm: GENERATE_UUID and GENERATE_UUID_BINARY
  • HTML_ENTITY_DECODE and HTML_ENTITY_ENCODE provide conversion of characters in an HTML string: HTML_ENTITY_DECODE and HTML_ENTITY_ENCODE
  • The HTTP functions in QSYS2 support BLOB data: HTTP_DELETE and HTTP_DELETE_BLOB, HTTP_GET and HTTP_GET_BLOB, HTTP_PATCH and HTTP_PATCH_BLOB, HTTP_POST and HTTP_POST_BLOB, HTTP_PUT and HTTP_PUT_BLOB, HTTP_DELETE_VERBOSE and HTTP_DELETE_BLOB_VERBOSE, HTTP_GET_VERBOSE and HTTP_GET_BLOB_VERBOSE, HTTP_PATCH_VERBOSE and HTTP_PATCH_BLOB_VERBOSE, HTTP_POST_VERBOSE and HTTP_POST_BLOB_VERBOSE, HTTP_PUT_VERBOSE and HTTP_PUT_BLOB_VERBOSE
  • The HTTP functions support headers options for passing the values as a JSON object and for returning cookies: HTTP options
  • JSON_UPDATE scalar function allows modification of a value within a JSON document: JSON_UPDATE
  • TIMESTAMPDIFF_BIG returns a BIGINT result data type: TIMESTAMPDIFF_BIG
  • REMOTE TABLE allows a query containing a table function to run on a remote IBM i: table-reference
  • Common table expressions can be defined as NOT DETERMINISTIC or DETERMINISTIC: common-table-expression
  • Comments can be added to the return columns for a table function: COMMENT
  • CREATE ALIAS supports a member value of *LAST to use the most recent member added to a file: CREATE ALIAS
  • The RESTRICT ON DROP clause can be used to prevent functions and procedures from being dropped: CREATE FUNCTION (SQL scalar), CREATE FUNCTION (SQL table), CREATE FUNCTION (external scalar), CREATE FUNCTION (external table), CREATE PROCEDURE (SQL), CREATE PROCEDURE (external), ALTER FUNCTION (SQL scalar), ALTER FUNCTION (SQL table), ALTER FUNCTION (external scalar), ALTER FUNCTION (external table), ALTER PROCEDURE (SQL), and ALTER PROCEDURE (external)
  • SYSCOLUMNSTAT returns varying length statistics: SYSCOLUMNSTAT
  • SYSCOLUMNS2 returns BUFFER_LENGTH and BUFFER_POSITION columns: SYSCOLUMNS2
