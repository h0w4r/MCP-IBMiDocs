ADDPFTRG/CHGPFTRG command changes

Last Updated: 2025-11-20

In IBM® i 7.5 with PTF SI82937, the MIRROR parameter for the Add Physical File Trigger (ADDPFTRG) command and the Change Physical File Trigger (CHGPFTRG) command is modified to remove the *YES value. This value is no longer supported. Existing physical file triggers with MIRROR(*YES) are not affected.
