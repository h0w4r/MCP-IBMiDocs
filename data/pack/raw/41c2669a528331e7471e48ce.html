Check Record Locks (CHKRCDLCK)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: Yes 		Parameters
Examples
Error messages

The Check Record Locks (CHKRCDLCK) command supplies a method to detect whether a job has any record locks. This command sends an escape message if there are any record locks held by the routing step.

There are no parameters for this command.
