End Trap Manager (ENDTRPMGR)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

Use the End Trap Manager (ENDTRPMGR) command to end the local Simple Network Management Protocol (SNMP) trap manager. As an alternative to using this command, the Local trap manager (LCLTRPMGR) parameter of the Change SNMP Attributes CHGSNMPA command can specify that the local trap manager be started and ended when the SNMP server is started or ended.
