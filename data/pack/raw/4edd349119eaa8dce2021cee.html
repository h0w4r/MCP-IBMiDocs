Answer Line (ANSLIN)

Last Updated: 2025-04-08
Where allowed to run: All environments (*ALL)
Threadsafe: No 		Parameters
Examples
Error messages

The Answer Line (ANSLIN) command prepares the system for an incoming call on a line that is not configured for auto-answer. When a call arrives, the system operator manually answers, validates the requirements of the caller, and then enters the Answer Line (ANSLIN) command. When the system is ready to receive the call, a message tells the operator to select data mode on the modem.
