EXT

The EXT keyword is used in a free-form data
structure definition to indicate that the data structure
is externally-described.
If the EXTNAME keyword is not
also specified, the name of the data structure is used
to locate the external file that provides
the subfield definitions.

If the EXT keyword is specified, it must be
the first keyword.
