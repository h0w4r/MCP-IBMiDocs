Primary/Secondary Multi-file Processing

In
an RPG IV program, the processing of a primary input file and one
or more secondary input files, with or without match fields, is termed
multi-file processing. Selection of records from more than one file
based on the contents of match fields is known as multi-file processing
by matching records. Multi-file processing can be used with externally
described or program described input files that are designated as
primary/secondary files.
