Prompt window

A CODE window for editing a fixed-column statement. When you select OK from any prompt and there are no errors, the prompt
for the next specification line in the file is displayed. If the next line
is not a defined specification line, the Specification Selection window is
displayed.

To return to the Editor window from this continuous prompting mode, select Cancel, press the Escape key, or close the current prompt
from its System menu. Changes you made in the current prompt since you last
selected OK are not saved.
