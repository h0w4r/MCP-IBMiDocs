CHGPGM and CHGSRVPGM command behavior change

Last Updated: 2025-10-07

The Change Program (CHGPGM) and Change Service Program (CHGSRVPGM) commands can perform program
modifications that require re-creating the program; examples are changing optimization level or
specifying FRCCRT(*YES).

Starting in IBM® i 7.6, if a change requires re-creating the
program, a copy of the original program object will be stored into the appropriate replaced-object
library (QRPLOBJ for system and basic user Auxiliary Storage Pools (ASPs); QRPLnnnnn for independent
ASPs).

If programs are being changed frequently, the replaced-object library will contain more objects
than on previous releases.
