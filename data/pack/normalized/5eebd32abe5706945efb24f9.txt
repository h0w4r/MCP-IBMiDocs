Setting Run-Time Limits

The maximum amount of storage of any single variable (such as a string or
array) is 16 773 104 bytes
The maximum length of a command passed to the system function is 32 702
bytes
The maximum size of dynamic heap storage is 4 gigabytes
A very large memory allocation may cause a system crash if there is
insufficient auxiliary storage on your system. A 4-gigabtye
memory allocation requires more than 4 gigabytes of available DASD. The
iSeries Work System Status (WRKSYSSTS) command shows auxiliary storage
usage.
The maximum size of a single heap allocation is 16 711 568 bytes
The maximum auto storage is 16 MB and there is a recursion limit of
approximately 21743 levels deep
