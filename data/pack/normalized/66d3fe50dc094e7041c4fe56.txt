The Change PC Organizer Profile (CHGPCOPRF) command allows you to specify if you want to use OfficeVision/400, DW 4, DW 4/2, DW 5, or DW 5/2 as your text editor.

If you select DW 4, DW 4/2, DW 5, or DW5/2, you are asked what DisplayWrite profile you want to use, where to find your DisplayWrite program files, and how you want to save your DisplayWrite files.

If you are using the OS/2 operating system on your personal computer, you can only select OfficeVision/400 or DW 5/2 as your editor.

If you are using the DOS operating system on your personal computer, you can only select OfficeVision/400, DW 4, DW 4/2, or DW 5 as your editor.

There are no parameters for this command.
