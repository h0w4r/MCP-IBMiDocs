HELP and HLPRTN keyword

In a file with the USRDSPMGT keyword, the HELP keyword alone will
not return control to the application program. HLPRTN must be specified to
return control to the application program.

If you specify a response indicator on the HELP keyword in a file containing
the USRDSPMGT keyword, an error message is issued.
