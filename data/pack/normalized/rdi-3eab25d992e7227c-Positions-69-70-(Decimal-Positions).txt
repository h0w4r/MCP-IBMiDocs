Positions 69-70 (Decimal Positions)

Entry
Explanation

Blank

The result field is character data, has been defined elsewhere in the
program, or no field name has been specified.

0-63

Number of decimal positions in a numeric result field.

Positions 69-70 indicate the number of positions to the right of the decimal
in a numeric result field. If the numeric result field contains no decimal
positions, enter a '0' (zero). This position must be blank if the
result field is character data or if no field length is specified. The number
of decimal positions specified cannot exceed the length of the field.
