CLIENT_IPADDR
This global variable contains the IP address of the current
client, as returned by the system.
This global variable has the following characteristics:It is read-only, with values maintained by system.
The type is VARCHAR(128).
The schema is SYSIBM.
The scope of this global variable is session.

If the client did not connect by using the TCP/IP or SSL
protocol, the value of the global variable is NULL.
