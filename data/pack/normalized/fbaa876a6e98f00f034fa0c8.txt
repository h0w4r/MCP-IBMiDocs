Position 22 (File Format)

Free-Form Syntax

Parameter of the device-type keyword

This entry must be blank if the LIKEFILE keyword is
specified. The File Format of the parent file is used.

Entry
Explanation

F

Program-described file

E

Externally described file

An F in position 22 indicates that the records for the file are
described within the program on input/output specifications (except
for array/table files and record-address files).

An E in position 22 indicates that the record descriptions for
the file are external to the RPG IV source program. The compiler
obtains these descriptions at compilation time and includes them in
the source program.
