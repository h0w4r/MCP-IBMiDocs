ILE C/C++ Programmer's Guide
Chapter 13. Stepping Through Programs
The STEP command of the ILE source debugger allows you to run a specified
number of statements of a program, and then return to the Display Module
Source display at the position of the next statement to be run. The
cursor is positioned on this statement if the cursor was in the text area of
the display the last time the source was displayed. Otherwise, it is
positioned on the debug command line. The program begins at the
statement where the program stopped. Setting a breakpoint causes the
program to stop before the statement is run. The default number of
statements to run is one.
This chapter describes how to:

Step over programs
Step into programs
Step over procedures
Step into procedures
