Type Casting to Override a Function without Overriding Linkage
To override a function without overriding extern "OS" use a type
cast, as shown in Figure 236.
Figure 236. Type Cast to Override a Function without Overriding Linkage

extern "ILE"
{
typedef void (*ILE) ();
}
extern "C++"
{
typedef void (*CPP) ();
}
ILE pILE;
CPP pCPP = (CPP) pILE;
