GEN / NOGEN
GEN indicates that the compiler creates
a module or program object after the COBOL source is compiled. GEN is the
default value.
NOGEN indicates that the compiler does not create
a module or program object after the COBOL source program is compiled. You
might specify this option if you want only error messages and/or listings.
