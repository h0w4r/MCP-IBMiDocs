NOINZDLT / INZDLT
NOINZDLT indicates that relative files
with sequential access are not initialized with deleted records during the
CLOSE operation if the files have been opened for OUTPUT. The record boundary
is determined by the number of records written at OPEN OUTPUT time. Subsequent
OPEN operations allow access only up to the record boundary. NOINZDLT is the
default value.
INZDLT indicates that relative files with sequential
access are initialized with deleted records during the CLOSE operation if
the files were opened for OUTPUT. Active records in the files are not affected.
The record boundary is defined as the file size for subsequent OPEN operations.
