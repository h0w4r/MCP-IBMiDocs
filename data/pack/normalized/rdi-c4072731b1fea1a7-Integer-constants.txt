Integer constants
An integer constant specifies an integer as a signed or
unsigned number with a maximum of 19 digits that does not include a decimal
point. The data type of an integer constant is large integer if its value
is within the range of a large integer. The data type of an integer constant
is big integer if its value is outside the range of a large integer, but within
the range of a big integer. A constant that is defined outside the range of
big integer values is considered a decimal constant.
Examples 64 -15 +100 32767 720176 12345678901

In syntax diagrams, the term integer is used for a large
integer constant that must not include a sign.
