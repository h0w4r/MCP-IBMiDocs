UDT_PRIVILEGES
The UDT_PRIVILEGES view contains one row for every privilege
granted on a type. Note that this catalog view cannot be used to determine
whether a user is authorized to a type because the privilege to use
a type could be acquired through a group user profile or special authority
(such as *ALLOBJ).
The following table describes the columns in the view:
