Where allowed to run: All environments (*ALL)

Threadsafe: No | Parameters

Error messages

The Display Network Attributes (DSPNETA) command displays the network attributes of the system.

The QSYS2.NETWORK_ATTRIBUTE_INFO view returns similar information.

Restrictions:

- You must have either input/output system configuration (*IOSYSCFG) special authority or have access to the QIBM_IOSYSCFG_VIEW function usage identifier to display the following network attributes:

JOBACN
DDMACC
PCSACC
ALWADDCLU

A value of *NOTAVL will be returned if the user is not authorized.

Top

Output (OUTPUT)

Specifies whether the output from the command is displayed at the requesting work station or printed with the job's spooled output.

*
The output is displayed for interactive jobs or printed with the job's spooled output for non-interactive jobs.

*PRINT
The output is printed with the job's spooled output.

Top

Examples

DSPNETA OUTPUT(*)

If the job is interactive, this command displays the network attributes of the system at the work station. If the job is batch, the network attributes are printed with the job's spooled output.
