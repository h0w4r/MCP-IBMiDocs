Rules for the TEMPLATE keyword:

The RPG symbol name for the template file can be used only as
the parameter of a LIKEFILE keyword on a file specification, or a
LIKEFILE keyword on a Definition specification.

The RPG symbol name of a record format of a template file can
be used only as the parameter of a LIKEREC Definition keyword.

Keywords that are not inherited by LIKEFILE definitions are not
allowed for a template file.
