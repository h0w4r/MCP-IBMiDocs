Mapping Class Template Instantiations to ILE C Syntax
To map the class template instantiation to the desired ILE C syntax, C++
uses the macros shown in the following figure:
Figure 216. BCD Macros that Map C++ Class Template Instantiations to ILE C Syntax

#define decimal _Decimal
#define _Decimal(n,p) _DecimalT<n,p>

Note:ILE C code using the decimal(n,p) specifier can be ported to C++
without any modification.

The _DecimalT<n,p> specifier supported by ILE C is not
supported by the C++ compiler To use the _DecimalT<n,p>
specifier, you need to insert a zero explicitly at the type specifier.
For example, you must change decimal(10) to
decimal(10,0).
