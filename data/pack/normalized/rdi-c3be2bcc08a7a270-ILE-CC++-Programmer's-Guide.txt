Without a pathname, the system assumes that your source is located in the
current directory. The default current directory is the base
(/) directory of the root file system, but your individual user
profile may change this default to a different directory. You can
change the current directory with the Change Current Directory (CHGCURDIR)
command.
Note:The current directory and the current library are separate and distinct
entities. Although you can set the current library and the current
directory to be the same name, a change in one will not affect the
other.

The header files specified in any #include statements in your
source will be searched for in the source directory first and then the
specified INCDIR directory. For example, if you compile the following
source in file /goodness/mysource.cpp:
#include "special/mystuff.h"

class test : public base
{
···

with the INCDIR value set to /mydir, your included header file
is first searched for as /goodness/special/mystuff.h and
then /mydir/special/mystuff.h.
