Program Data
Program data is created by the program itself, instead of being read from
a file.
The concept of logical records applies to program data as well as to file data. Program data can
thus be grouped into logical records, and be defined by a series of record
description entries. Items that need not be so grouped can be defined in independent
data item description entries.
