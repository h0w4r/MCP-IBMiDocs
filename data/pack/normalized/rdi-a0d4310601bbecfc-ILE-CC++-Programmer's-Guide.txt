Binding Directories
You can create a binding directory to contain the names of modules and service programs that your ILE
C++ program or service program may need. Each binding directory is
created in a specific library with the Create Binding Directory (CRTBNDDIR)
command. Use binding directories to reduce program size. Modules
or service programs listed in a binding directory are called only if
needed.
