Command processing program
The command processing program (CPP) is the program that the command
analyzer calls to perform the function requested.
The CPP can be a CL program, another high-level language (HLL) program,
or a REXX procedure.
For example, it can be an application program that your command calls, or
it can be a CL program or REXX procedure that contains a system command or series
of commands.
The CPP must accept the parameters as defined by the command definition
statements.
