Turning Off C2M Messages during Record Input and Output

To turn off C2M messages during record I/O, set the variable
_C2M_MSG (in <recio.h>) to zero. If
_C2M_MSG is set to a different value, record I/O sends C2M messages
to your program when it detects any of the following errors: C2M3003,
C2M3004, C2M3005, C2M3009, C2M3014, C2M3015, C2M3040, C2M3041, C2M3042 and
C2M3044.
Note:Removing data truncation messages with signal handlers or message handlers is
no longer necessary when the C2M messages are turned off during record
I/O.
