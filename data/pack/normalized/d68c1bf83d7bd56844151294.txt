Using a listing view to debug ILE programs
A listing view is similar to the source code portion of the compile
listing or spool file produced by the Integrated Language Environment® (ILE) CL compiler.
To debug an ILE CL module object by using a listing view, use
the *LIST or *ALL option on the DBGVIEW parameter for either the Create
CL Module (CRTCLMOD) or Create Bound CL (CRTBNDCL) commands
when you create the module.
One way to create a listing view is as follows:

CRTCLMOD
MODULE(MYLIB/MYPGM) SRCFILE(MYLIB/QCLLESRC) SRCMBR(MYPGM) TEXT('CL Program')
DBGVIEW(*LIST)
