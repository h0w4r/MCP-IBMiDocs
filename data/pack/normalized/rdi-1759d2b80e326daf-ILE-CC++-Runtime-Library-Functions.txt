ILE C/C++ Runtime Library Functions

<xxfdbk.h>
The <xxfdbk.h> include file
contains the declarations that are used by the i5/OS® feedback areas. To retrieve information from
feedback areas, see _Riofbk() — Obtain I/O Feedback Information and _Ropnfbk() — Obtain Open Feedback Information.
The following is an example of a type that is defined in the <xxfdbk.h> include
file:
typedef _Packed struct _XXIOFB_T {
short file_dep_fb_offset;
int write_count;
int read_count;
int write_read_count;
int other_io_count;
char reserved1;
char cur_operation;
char rec_format[10];
char dev_class[2];
char dev_name[10];
int last_io_rec_len;
char reserved2[80];
short num_recs_retrieved;
short last_io_rec_len2;
char reserved3[2];
int cur_blk_count;
char reserved4[8];
} _XXIOFB_T;
For further information about the open feedback areas, see the Files and file systems category in the Information
Center.
