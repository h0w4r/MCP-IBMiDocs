Removing traces from programs
The Remove Trace (RMVTRC) command
removes all or some of the trace ranges specified in one or more Add
Trace (ADDTRC) commands.
Removing a trace range consists of specifying the statement identifiers
used on the Remove Trace (RMVTRC) command, or specifying
that all ranges be removed.
You can use the STMT parameter on the Remove
Trace (RMVTRC) command to specify:
All high-level language (HLL) statements or machine instructions or both
in the specified program are not to be traced regardless of how the trace
was defined by the Add Trace (ADDTRC) command.
The start and stop trace location of the HLL statements or system instructions
or both to be removed.

The Remove Program (RMVPGM) and End Debug
(ENDDBG) commands also remove traces, but they also remove the program
from debug mode.
