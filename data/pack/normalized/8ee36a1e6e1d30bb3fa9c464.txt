Removing All Breakpoints
You can remove all breakpoints, conditional and unconditional, from a
program that has a module shown on the Display Module Source display by using
the CLEAR PGM debug command. To use the debug command, type
CLEAR PGM on the debug command line and press Enter. The
breakpoints are removed from all of the modules bound to the program.
