Debugging CL programs and procedures
Debugging means detecting, diagnosing, and eliminating errors in Integrated Language Environment® (ILE) or original program model (OPM) programs.

Debugging ILE programs
To debug your Integrated Language Environment (ILE)
programs, use the ILE source debugger.
Debugging original program model programs
To debug your original program model (OPM) programs,
use testing functions. These functions are available through a set of commands
that can be used interactively or in a batch job.
