Using Record Input and Output Functions
Using record I/O functions instead of stream I/O functions
can greatly improve I/O performance. Instead of accessing one byte
at a time, record I/O functions access one record at a time.
The two types of record I/O supported by the ILE C/C++ run-time libraries
are ISO C record I/O and ILE C record I/O.
