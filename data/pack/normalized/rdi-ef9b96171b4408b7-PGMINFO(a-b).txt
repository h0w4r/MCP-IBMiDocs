PGMINFO(a b)
Specifies options controlling whether program interface information should
be generated, and where it should be generated.

The possible values for a are:
NOPGMINFO
This option specifies the default which
does not generate program interface information.

PCML
Specifies
that PCML (Program Call Markup Language) should be generated.

The possible value for b is:
MODULE
Specifies that the program information should be stored in the
COBOL module.
