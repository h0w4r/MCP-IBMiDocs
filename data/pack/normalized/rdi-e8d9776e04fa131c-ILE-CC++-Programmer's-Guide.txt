Example: Passing OS/400 pointers as Arguments on a Dynamic Program Call to Another ILE C Program

The following example demonstrates how to pass OS/400 pointers as arguments on
a dynamic program (OS-linkage) call to another ILE C program.
The example consists of 2 ILE C programs. Program T1520DL8 passes
several types of OS/400 pointers as arguments to Program T1520DL9.
Program T1520DL9 receives the arguments and checks them to make sure that they
were passed correctly.
