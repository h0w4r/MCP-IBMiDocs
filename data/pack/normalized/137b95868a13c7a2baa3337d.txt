Prototypes and Parameters

The recommended way to call programs and procedures is to use prototyped
calls, since prototyped calls allow the compiler to check the call
interface at compile time. If you are coding a subprocedure, you will
need to code a procedure-interface definition to allow the compiler
to match the call interface to the subprocedure.
