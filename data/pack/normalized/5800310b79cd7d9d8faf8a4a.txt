INTEGER
The INTEGER function returns the greatest integer value that is less than
or equal to the argument.
The function type is integer.

Format

>>-FUNCTION INTEGER--(--argument-1--)--------------------------><

argument-1
Must be class numeric.

The returned value is the greatest integer less than or equal to the value
of argument-1. For example,
FUNCTION INTEGER (2.5)
will return
a value of 2; and
FUNCTION INTEGER (-2.5)
will return a value of
-3.
