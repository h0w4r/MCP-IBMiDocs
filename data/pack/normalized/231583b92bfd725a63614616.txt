The Start Debug Server (STRDBGSVR) command starts the debug server router function. Only one debug server router can be active at a time. Once started, the debug server router remains active until it is ended using the ENDDBGSVR command.

Restrictions:

- For the debug server job to service multiple users, it requires starting with a user profile that has *SECOFR security class.

There are no parameters for this command.
