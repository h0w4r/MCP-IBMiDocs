Obtaining the Session Handle
You can obtain the session handle for the C/C++ session and then use
the DSM APIs to manipulate that session. The session handle is supplied
through _C_Get_Ssn_Handle() in
<stdio.h>.
You can write a simple C program to clear the C session using the DSM
QsnClrScl API, as shown in the following example:
Figure 102. Simple C Program to Clear a C Session

#include <stdio.h>
#include "qsnapi.h"
void main (void)
{
QsnClrScl(_C_Get_Ssn_Handle(), '0', NULL);
}
