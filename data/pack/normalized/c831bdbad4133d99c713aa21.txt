The End Job Scheduler (ENDJS) command allows you to end the IBM Advanced Job Scheduler for i job monitor or to stop capturing job information for software applications that you started using the STRJS command.

Top

Parameters

Keyword | Description | Choices | Notes
OPTION | Option | *MONITOR, *CAPTURE | Optional, Positional 1
DTALIB | Data library | Name, *ALL, *USRPRF, *PROMPT | Optional

Top

Option (OPTION)

Specifies whether you want to end the IBM Advanced Job Scheduler for i monitor or you want to stop capturing job information.

*MONITOR
End the IBM Advanced Job Scheduler for i monitor.

*CAPTURE
Stop capturing job information for application software.

Top

Data library (DTALIB)

Specify the data library that you want to end monitoring for IBM Advanced Job Scheduler for i .

*USRPRF
The data library specified in the user profile for the current user will be used.

*ALL
All existing data libraries will be used.

name
Specify the name of the data library that you want to use.

Top

Examples

ENDJS OPTION(*MONITOR)

This command ends the Job Scheduler monitor. The monitor stays inactive until the next time you run the Start Job Scheduler (STRJS) command.
