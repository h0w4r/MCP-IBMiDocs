Program-Described File

For program-described files, the file name
specified on the file definition must also be entered on:

Input specifications if the file is a global primary,
secondary, or full procedural file

Output specifications or an output calculation operation line
if the file is an output, update, or combined file, or if file addition
is specified for the file

Definition specifications if the file is a table or array file.

Calculation specifications if the file name is required for the
operation code specified
