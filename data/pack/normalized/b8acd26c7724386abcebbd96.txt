SYSVARIABLEAUTH
The SYSVARIABLEAUTH view contains one row for every privilege
granted on a global variable. Note that this catalog view cannot be
used to determine whether a user is authorized to a global variable
because the privilege to use a global variable could be acquired through
a group user profile or special authority (such as *ALLOBJ).

view:
