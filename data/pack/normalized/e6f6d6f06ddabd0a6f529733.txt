ILE C/C++ Runtime Library Functions

<setjmp.h>
The <setjmp.h> include file declares the setjmp() function and longjmp() function.
It also defines a buffer type, jmp_buf, that the setjmp() and longjmp() functions
use to save and restore the program state.
