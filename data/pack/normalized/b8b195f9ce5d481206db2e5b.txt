Traditional File Description Specification Statement

The general layout for the file description specification is as
follows:

the file description specification type (F) is entered in position
6

the non-commentary part of the specification extends from position
7 to position 80

the fixed-format entries extend from positions 7 to
42. For files defined with the LIKEFILE keyword, the entries from
position 17 to position 43 must be blank. The values for those fixed-form
entries are taken from the parent file specified by the LIKEFILE keyword.

the keyword entries extend from positions
44 to 80

the comments section of the specification extends from position
81 to position 100
