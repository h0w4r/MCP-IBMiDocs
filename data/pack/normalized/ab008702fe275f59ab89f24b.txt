Using Static Procedure Calls
Within a bound object, procedures can be called using static procedure
calls. These bound calls are faster than external calls.
Therefore, an application consisting of a single bound program with many bound
calls should perform faster than a similar application consisting of separate
programs with many external inter-program calls.
