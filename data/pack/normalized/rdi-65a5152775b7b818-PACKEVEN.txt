PACKEVEN

The PACKEVEN keyword indicates that the packed field or array has an even
number of digits. The keyword is only valid for packed program-described data-structure
subfields defined using FROM/TO positions. For a field or array element of
length N, if the PACKEVEN keyword is not specified, the number of digits is
2N - 1; if the PACKEVEN keyword is specified, the number of digits is 2(N-1).
