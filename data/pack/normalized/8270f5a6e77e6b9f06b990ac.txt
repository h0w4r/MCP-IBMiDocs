The Check ASP Balance (CHKASPBAL) command allows the user to check which auxiliary storage pool (ASP) balance function is currently active and which units have been marked to not allow new allocations (*ENDALC). Informational messages will be sent to the job log indicating which ASP function is active and which units are marked *ENDALC. Message CPI18A5 will indicate which ASP balancing function is active. Message CPI18A6 will indicate no ASP balancing is active. Message CPI18A4 will indicate that no units are marked *ENDALC. Message CPI18A3 is issued for each unit marked *ENDALC.

This command has no parameters.

Examples

Example 1: Checking ASP Balancing

CHKASPBAL

This command will check which ASP balance function is currently active and which units, if any, are marked to not allow new allocations (*ENDALC). Informational messages will be sent to the job log for each configured ASP indicating which balance operation is active. An informational message will be sent to the job log for each unit that is marked *ENDALC.
