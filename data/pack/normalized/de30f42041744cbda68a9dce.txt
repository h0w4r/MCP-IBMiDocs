Message descriptions
A message description defines a message to the i5/OS® operating system.
The message description contains the text of the message and information
about replacement variables, and can include variable data that is provided
by the message sender when the message is sent.
Message descriptions are stored in message files. Each description must
have an identifier that is unique within the file. When a message is sent,
the message file and the message identifier tell the system which message
description is to be used.
