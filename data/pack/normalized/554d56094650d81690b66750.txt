Where allowed to run: All environments (*ALL)

Threadsafe: No | Parameters

The Delete Product Load (DLTPRDLOD) command deletes a product load object.

Restrictions:

- This command is shipped with exclude (*EXCLUDE) public authority. The QPGMR, QSYSOPR, QSRV, and QSRVBAS user profiles are shipped with private authorities to use this command.

Top

Product load (PRDLOD)

Specifies the name of the product load to be deleted.

The possible library values are:

*CURLIB
The current library for the job is used to locate the product load.

library-name
Specify the name of the library where the product load is located.

The possible values are:

product-load-name
Specify the name of the product load being deleted.

Note: You must specify either the product ID, option, load ID, and release, or the product load name and the library.

Top

Product ID (PRDID)

Specifies the 7-character identifier of the product for which a product load is being deleted.

Top

Product option (OPTION)

Specifies the product option for which a product load is being deleted.

The possible values are:

*BASE
The product load is part of the base option of the product.

product-option-number
Specify the option number of the product load to be deleted. Valid values range from 1 through 99.

Top

Load identifier (LODID)

Specifies the identifier of the product load to be deleted.

The possible values are:

*CODEDFT
The default code load ID, 5001, is used.

product-load-ID
Specify the product load ID of the product load to be deleted.

Top

Release (RLS)

Specifies the version, release, and modification level of the product load to be deleted.

The possible values are:

*ONLY
The release level is determined by searching the system for a product load specified on the PRDID, OPTION, and LODID parameters. This value can be specified only when one release of the product is installed on the system.

version-release-modification
Specifies the version, release, and modification level of the product. The release level can be passed as one of the following two formats:
Specify the release level in VxRyMz format, where Vx is the version number, Ry is the release number, and Mz is the modification level. The variables x and y can be a number from 0 through 9, and the variable z can be a number from 0 through 9 or a letter from A through Z.

Specify the release level in vvrrmm format, where vv are any numeric characters 00 through 35 representing the version of the product, rr are any numeric characters 00 through 35 representing the release of the product, and mm can be 00 through 09 or 0A through 0Z representing the modification of the product.

Examples

DLTPRDLOD PRDLOD(MYLIB/MYLOD)

This command deletes the product load MYLOD in library MYLIB.
