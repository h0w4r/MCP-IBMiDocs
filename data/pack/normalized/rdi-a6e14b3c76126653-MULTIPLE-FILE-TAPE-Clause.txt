MULTIPLE FILE TAPE Clause
This clause specifies that two or more files share the same reel of tape.
The function is provided by the system through the use of command language.
The MULTIPLE FILE TAPE clause is syntax checked, but is treated as documentation.
See the CRTTAPF, CHGTAPF, and OVRTAPF commands in the CL and APIs section of the Programming category in the IBM® i
Information Center at this Web site - http://www.ibm.com/systems/i/infocenter/.

MULTIPLE FILE TAPE Clause - Format

    (1)    
>>-MULTIPLE--FILE------+------+--+----------+------------------->
    '-TAPE-' '-CONTAINS-'   

   .--------------------------------------.   
   V |   
>----file-name-5--+---------------------+-+--------------------><
    '-POSITION--integer-2-'    

Notes:Syntax-checked only.integer-2
Must be an unsigned integer. It specifies the relative position of
the file on the tape.
file-name-5
Names the files that share the tape.
