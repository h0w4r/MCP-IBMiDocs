DB-FORMAT-NAME Special Register
After the execution of an input/output statement, for a FORMATFILE or DATABASE
file, the DB-FORMAT-NAME special register is modified according to the following
rules:
After completion of a successful READ, WRITE, REWRITE, START, or DELETE
operation, the record format name used in the I-O operation is implicitly
moved to the special register.
After an unsuccessful input/output operation, DB-FORMAT-NAME contains
the record format name used in the last successful input/output operation.
DB-FORMAT-NAME is implicitly defined as PICTURE X(10) and GLOBAL in the
outermost program.

You may specify the DB-FORMAT-NAME special register in a function whenever
an alphanumeric argument is allowed.
