Commands from IBM Rational Development Studio for i (5770-WDS) option 21 (Application
Development ToolSet)

Last Updated: 2025-10-07

Source Entry Utility (SEU) and Programming Development Manager (PDM) along with the Interactive
Source Debugger (ISDB) are the only functions that remain fully supported in IBM Rational
Development Studio for i (5770-WDS) option 21 (Application Development ToolSet). These commands and
menu driven screen interfaces continue to be supported:

- Start Programming Development Manager (STRPDM)

- Start Source Entry Utility (STRSEU) Start Interactive Source Debugger (STRISDB)

- End Interactive Source Debugger (ENDISDB)

- Work with Members using Programming Development Manager (WRKMBRPDM)

- Work with Objects using Programming Development Manager (WRKOBJPDM)

- Change Programming Development Manager Defaults (CHGPDMDFT)

- Find String Using Programming Development Manager (FNDSTRPDM)

- Find String with List using Programming Development Manager (FNDSTRPDM2)

- Work with Libraries using Programming Development Manager (WRKLIBPDM)

Support for selected Application Development ToolSet tools and their associated commands is being
removed. These commands and menu driven screen interfaces have been removed in IBM i 7.6:

- Start Report Layout Utility (STRRLU)

- Start Screen Design Aid (STRSDA)

- Start Advanced printer Function (STRAPF)

- Merge Form Description (MRGFORMD)

- Start Character Generator Utility (STRCGU)

- Copy DBCS Master Sort Table (CPYIGCSRT)

- Merge Form Description (MRGFORMD)

Selected Application Development ToolSet tools and their associated commands continue to be
available but not supported in IBM i 7.6:

- Start Data File Utility (STRDFU)

- Create DFU Display File (CRTDFUDSPF)

Selected Application Development ToolSet tools and their associated commands continue to be
available but not supported in IBM i 7.6, also the PDM menu option is removed
for these commands in IBM i 7.6:

- Compare Physical File Member (CMPPFM)

- Merge Source (MRGSRC)
