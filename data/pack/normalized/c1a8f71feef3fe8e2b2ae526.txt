Keyword considerations for printer files that use DBCS

You cannot use these keywords with double-byte
character set (DBCS) data fields (the data type specified in position 35 is
O or G).

BARCODE
BLKFOLD
CDEFNT
CHRID
COLOR
CPI
CVTDTA
DATE
DATFMT

DATSEP
DFT
DLTEDT
EDTCDE
EDTWRD
FLTFIXDEC
FLTPCN
FNTCHRSET
FONT

HIGHLIGHT
MSGCON
PAGNBR
TIME
TIMFMT
TIMSEP
TRNSPY

Do not use the IGCALTTYP and IGCANKCNV keywords on DBCS-graphic
data fields (G specified in position 35).
