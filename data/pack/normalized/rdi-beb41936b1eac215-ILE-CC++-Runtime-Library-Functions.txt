ILE C/C++ Runtime Library Functions

Newline Character
When the UTF support is not used, the hexadecimal value generated
by the compiler for the character \n and used by the run
time has two different values. The hexadecimal value 0x15 is used
if SYSIFCOPT(*NOIFSIO) is specified on the compilation command. The
hexadecimal value 0x25 is used if SYSIFCOPT(*IFSIO) or SYSIFCOPT(*IFS64IO)
is specified on the compilation command. When the UTF support is
used, the newline character in UTF-8 will be hexadecimal 0x0a regardless
of what SYSIFCOPT value is used.
