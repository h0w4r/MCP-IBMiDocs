Returned Values
The following values are returned by the LOCALE-DATE intrinsic function:
If mnemonic-name-1 is specified, the locale used for formatting the date
is the one associated with mnemonic-name-1; otherwise, the current locale
is used. If the locale associated with mnemonic-name-1 is not available, an
operating system escape message is issued.
The returned value is a character string containing the date specified
by argument-1, and is returned in the date format specified in the locale.
The length of the returned value depends on the format specified in the
locale.
