Run-Time Arrays

To initialize each element in a run-time array to the same value,
specify the INZ keyword on the definition specification. If the array
is defined as a data structure subfield, the normal rules for data
structure initialization overlap apply (the initialization is done
in the order that the fields are declared within the data structure).
