ILE C/C++ Language Reference

Industry Standards
The following standards are supported:

The C language is consistent with the International Standard for
Information Systems-Programming Language C (ISO/IEC 9899-1990).
The C language is also consistent with the International Standard
for Information Systems-Programming Language C (ISO/IEC 9899–1999
(E)).
The C++ language is consistent with the International Standard
for Information Systems-Programming Language C++ (ISO/IEC 14882:1998).
The C++ language is also consistent with the International Standard
for Information Systems-Programming Language C++ (ISO/IEC 14882:2003(E)).
