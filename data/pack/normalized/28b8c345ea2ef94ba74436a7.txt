Use the Start Trap Manager (STRTRPMGR) command to start the local Simple Network Management Protocol (SNMP) trap manager. The Forward traps (FWDTRP) parameter may be specified, which enables trap and inform messages that are received on the local system to be forwarded to other Network Management stations, as configured in the SNMP attributes with the Change SNMP Attributes (CHGSNMPA) command. As an alternative to using this command, the Local trap manager (LCLTRPMGR) parameter of the CHGSNMPA command can specify that the local trap manager be started and ended when the SNMP server is also started or ended. It also allows the specification of whether trap and inform messages are forwarded. The QIBM_ZCA_SNMPTRAP exit point can be used to log trap and inform messages received to a data queue.

Forward Trap (FWDTRP)

Specifies whether trap and inform messages received on the system are to be forwarded to other network management stations.

The possible values are:

*SNMPA
Forwarding of trap and inform messages is controlled by the SNMP attributes specified by the LCLTRPMGR parameter of the CHGSNMPA command.

*NO
Received trap and inform messages will not be forwarded.

*YES
Received SNMP version 1 (SNMPv1) traps will be forwarded to the SNMPv1 trap managers specified by the TRPMGR parameter of the CHGSNMPA command. SNMP version 3 (SNMPv3) traps will be forwarded to the SNMPv3 trap managers specified by the TRPMGR parameter of the CHGSNMPA command. SNMPv3 informs will be forwarded to the inform manager specified by the LCLTRPMGR parameter of the CHGSNMPA command.

Examples

Example 1: Start Local Trap Manager (Enqueue Only)

STRTRPMGR

This command starts the trap manager job. Trap and inform messages received by the trap manager are enqueued only.

Example 2: Start Local Trap Manager (Enqueue and Forward)

STRTRPMGR FWDTRP(*YES)

This command starts the local trap manager. Traps received by the trap manager are enqueued and forwarded.
