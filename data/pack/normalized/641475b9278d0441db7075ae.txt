RETKEY (Retain Function Keys) and RETCMDKEY (Retain Command Keys) keywords
for display files

You use these record-level keywords to indicate that
function keys, command function (CFnn) keys, or command
attention (CAnn) keys, which are enabled on
a display, should be retained when the record you are defining is displayed.

These keywords have no parameters.
See System/36 environment considerations for display files for information about how to specify the RETKEY
and RETCMDKEY keywords.
