SYSXSROBJECTAUTH
The SYSXSROBJECTAUTH view contains one row for every privilege
granted on an XML schema. Note that this catalog view cannot be used
to determine whether a user is authorized to a XML schema because
the privilege to use a XML schema could be acquired through a group
user profile or special authority (such as *ALLOBJ).
