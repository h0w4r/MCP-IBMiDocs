ILE C/C++ Runtime Library Functions

<signal.h>
The <signal.h> include file defines the values for
signals and declares the signal() and raise() functions.
The <signal.h> include file also defines the following
macros:

SIGABRT
SIGALL
SIG_DFL

SIG_ERR
SIGFPE
SIG_IGN

SIGILL
SIGINT
SIGIO

SIGOTHER
SIGSEGV
SIGTERM

SIGUSR1
SIGUSR2

<signal.h> also declares the function _GetExcData,
an i5/OS® extension to the
C standard library.
