Overflow Indicators

An overflow indicator is defined by the OFLIND keyword on the file
description specifications. It is set on when the last line on a page
has been printed or passed. Valid indicators are *INOA through *INOG,
*INOV, and *IN01 through *IN99. A defined overflow indicator can
then be used to condition calculation and output operations. A description
of the overflow indicator and fetch overflow logic is given in Overflow Routine.
