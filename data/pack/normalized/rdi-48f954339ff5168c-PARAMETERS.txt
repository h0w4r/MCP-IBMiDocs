PARAMETERS
The PARAMETERS view contains one row for each parameter
of a routine in the relational database.
The following table describes the columns in the view:

NUMERIC_PRECISION
INTEGER Nullable

The precision of all numeric parameters.
Note: This column supplies the precision of all numeric data types,
including single-and double-precision floating point and decimal floating-point.
The NUMERIC_PRECISION_RADIX column indicates if the value in this
column is in binary or decimal digits.
Contains the null
value if the parameter is not numeric.

NUMERIC_PRECISION_RADIX
INTEGER Nullable

Indicates if the precision specified

decimal digits: 2
Binary; floating-point precision is specified in binary digits.
10
Decimal; all other numeric types are specified in decimal digits.

Contains the null value if the parameter is not
numeric.
