TERMINAL Phrase
The TERMINAL phrase specifies the program devices to which the output record
is to be sent.
The contents of literal-2 or identifier-3 must be the name of a program
device previously acquired, either implicitly or explicitly, by the file.
Literal-2, if specified, must be nonnumeric and 10 characters or less in
length. Identifier-3, if specified, must refer to an alphanumeric data item,
10 characters or less in length. A value of blanks is treated as if the TERMINAL
phrase was omitted.
If only a single program device was acquired by the TRANSACTION file, the
TERMINAL phrase can be omitted. That program device is always used for the
WRITE.
If the TERMINAL phrase is omitted for a WRITE operation to a TRANSACTION
file that has acquired multiple program devices, the default program device
is used.
