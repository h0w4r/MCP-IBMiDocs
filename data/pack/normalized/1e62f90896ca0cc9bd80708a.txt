USRDSPMGT (User Display Management) keyword

You use this file-level keyword
to indicate that this display file should be processed with System/36 environment
functions.

This keyword has no parameters.
You cannot use USRDSPMGT
in display files containing any of the following keywords: ASSUME
ERASE
HLPCMDKEY
IGCCNV
KEEP
PUTRETAIN
SFL
SFLCTL

In a file containing the USRDSPMGT keyword, the OVERLAY
keyword is ignored.
Option indicators are not valid for this keyword.
The
following example shows how to specify the USRDSPMGT keyword.

|...+....1....+....2....+....3....+....4....+....5....+....6....+....7....+....8
A USRDSPMGT
A R RECORD
A FIELD1
A
