SIZE Phrase
For a more detailed description of the SIZE
phrase, refer to SIZE Phrase. This section describes the parameters
that you specify for this SIZE phrase.
integer-3, integer-4
Integer-3 and integer-4 determine the size of the date or time item
in number of digits. Integer-3 or integer-4 must be specified if the size
of the date or time item cannot be determined at compile time. For a date
or time item, the values of both integer-3 and integer-4 must be equal to
or greater than 4.
mnemonic-name-1, mnemonic-name-2
For more information about mnemonic-name-1 or mnemonic-name2, refer
to the description in LOCALE Phrase and LOCALE Phrase.
