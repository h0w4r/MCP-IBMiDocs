CL character sets and values
The EBCDIC character sets, special characters,
and IBM-defined fixed values called predefined values can be
used in CL.

Character sets
Control language (CL) uses the extended binary-coded decimal
interchange code (EBCDIC) character set.
Special character use
Special characters can be used only in these special ways or inside
quoted character strings or comments.
Symbolic operators
A variety of characters can be used as symbolic operators in CL
commands.
Predefined values
Predefined values are IBM-defined fixed values that have predefined
uses in control language (CL) and are considered to be reserved in the i5/OS® operating system.
