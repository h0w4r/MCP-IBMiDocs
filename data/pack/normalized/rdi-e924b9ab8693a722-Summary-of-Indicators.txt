of where RPG IV indicators are defined, what the valid entries are,
where the indicators are used, and when the indicators are set on
and off. Table 2 indicates the primary
condition that causes each type of indicator to be set on and set
off by the RPG IV program. Function Key Indicators lists the function
key indicators and the corresponding function keys.

Note:
The overflow indicator must be defined on the file description
specification first.

KA through KN and KP through KY can be used as resulting indicators
only with the SETOFF operation.

Only a record identifying indicator from a main or OR record can
be used to condition a control or match field. L1 or L9 cannot be
used to condition a control or match field.

The 1P indicator is allowed only on heading and detail lines.

Off by the RPG IV Logic Cycle

Type of Indicator

Set On

Set Off

Overflow

OA-OG, OV:  After the following heading

01-99:  By the user.

Record identifying

When specified primary / secondary

immediately after record is read from a full procedural file.

Before the next primary/secondary

Control level

When the value in a control field
changes. All lower level indicators are also set on.

At end of following detail cycle.

Field indicator

By blank or zero in specified fields,
by plus in specified field, or by minus in specified field.

Before this field status is to be
tested the next time.

Resulting

When the calculation is processed
and the condition that the indicator represents is met.

The next time a calculation is processed
for which the same indicator is specified as a resulting indicator
and the specified condition is not met.

Function key

When the corresponding function key
is pressed for WORKSTN files and at subsequent reads to associated

By SETOFF or move fields logic for
a WORKSTN file.
