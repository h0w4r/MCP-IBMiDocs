Opening Diskette Files as Binary Stream Files
To open an iSeries diskette file as a binary stream file for
record-at-a-time processing, use the fopen() function with one of
the following modes:

rb
wb

Note:The only way to create a diskette file is to use the CRTDKTF command.
If you use fopen() and the diskette file does not exist, a physical
database file is created.

The valid keyword parameters are:

type
lrecl
blksize

I/O Considerations for Binary Stream Diskette Files
Blocking Binary Stream Diskette Files
If your program processes diskette files, performance can be improved if
I/O operations are blocked. If you do not specify a value for the
blksize parameter or if you specify blksize=0 on fopen(), the
system calculates a number of records to be transferred as a block to your
program.
