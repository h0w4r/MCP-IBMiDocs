LOWER-CASE
The LOWER-CASE function returns a character string that is the
same length as the argument specified with each uppercase letter replaced
by the corresponding lowercase letter.
The function type depends on the argument types, as follows:

The same character string as argument-1 is returned, except that
each uppercase letter is replaced by the corresponding lowercase letter.
A program collating sequence or code page does not affect the returned
value.
IBM ExtensionIBM Extension If argument-1 is DBCS, the DBCS value is

portions of the literal are affected. End of IBM Extension
End of IBM Extension The returned character string has the same length as argument-1.
