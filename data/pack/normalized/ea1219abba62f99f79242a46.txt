Network command changes

Network command changes

Last Updated: 2025-10-07

The Start TCP/IP Server (STRTCPSVR) command and End TCP/IP Server (ENDTCPSVR) command no longer
supports the values *BOOTP, *DHCP, *DNS, *MGTC, *QOS, and *ROUTED.

The Trace TCP/IP Application (TRCTCPAPP) command no longer supports the values: *L2TP, *PPP, and
*QOS. The PPP connection profile (PPPCNNPRF), TCP/IP data to trace (TCPTRCDTA), and QOS trace type
(QOSTRCTYPE) parameters will be ignored.

The IP QoS enablement (IPQOSENB), IP QoS datagram batching (IPQOSBCH), IP QoS timer resolution
(IPQOSTMR), and Network file cache (NFC) parameters of the Change TCP/IP Attributes (CHGTCPA)
command will be ignored.

PPP/Dial-Up Service Disabled

The following Dial-Up and Point-to-Point networking services are being disabled:

- The Start TCP/IP (STRTCP) command will ignore the Start point-to-point profiles (STRPTPPRF)
parameter. Point-to-point profiles will no longer be started.

- The RADIUS (Remote Authentication Dial In User Service) is no longer available for use.

Quality of Service (QoS) APIs no longer available

The following Quality of Service APIs are removed from IBM® i 7.6:

- QgyOpenListQoSMonitorData (Open List of QoS Monitor Data)

- qtoq_accept() (Accept QoS Sockets Connection)

- qtoq_accept_ex() (Accept QoS Sockets Connection)

- qtoq_close() (Close QoS Sockets Connection)

- qtoq_connect() (Make QoS Sockets Connection)

- qtoq_connect_ex() (Make QoS Sockets Connection)

- qtoq_ioctl() (Set QoS Sockets Control Options)

- qtoq_ioctl_ex() (Set QoS Sockets Control Options)

- QtoqDeleteQoSMonitorData (Delete QoS Monitor Data)

- QtoqEndQoSMonitor (End QoS Monitor)

- QtoqListSavedQoSMonitorData (List Saved QoS Monitor Data)

- QtoqSaveQoSMonitorData (Save QoS Monitor Data)

- QtoqStartQoSMonitor (Start QoS Monitor)

- rapi_fmt_adspec() (Format a RAPI Adspec into a string suitable for printing)

- rapi_fmt_filtspec() (Format a RAPI Filter spec into a string suitable forprinting)

- rapi_fmt_flowspec() (Format a RAPI Flowspec into a string suitable for printing)

- rapi_fmt_tspec() (Format a RAPI Tspec into a string suitable for printing)

- rapi_getfd() (Get a descriptor to wait on before dispatching the RAPI messagehandling
routine)

- rapi_release() (Release the currently active RAPI reservation and close the opensessions)

- rapi_reserve() (Make, modify, or delete a RAPI reservation)

- rapi_sender() (Identify a RAPI sender)

- rapi_session() (Create a RAPI session)

- rapi_version() (Retrieve the current RAPI version)
