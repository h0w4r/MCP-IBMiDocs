ILE C/C++ Runtime Library Functions

<string.h>
The <string.h> include file declares the string manipulation
functions:

memchr
memcmp
memcpy
memicmp1
memmove
memset

strcat
strchr
strcmp
strcmpi1
strcoll
strcpy

strcspn
strdup1
strerror
stricmp1
strlen
strncat

strncmp
strncpy
strnicmp1
strnset1
strpbrk
strrchr

strset1
strspn
strstr
strtok
strtok_r
strxfrm

Note:
1 These functions are available
for C++ programs. They are available for C only when the program defines
the __cplusplus__strings__ macro.

The <string.h> include file also defines the macro NULL,
and the type size_t.
For more information about NULL and the type size_t,
see <stddef.h>.
