Type of name or specification for physical and logical files (position
17)

For physical files, type a value in this position
to identify the type of name. For logical files, type a value to
identify the type of specification. If you specify a name type, the name is
specified in positions 19 through 28.

The valid entries for physical files are:

Entry
Meaning

R

Record format name

Blank

Field name

K

Key field name

Note: Specify only one R because a physical file can contain
only one record format.

The valid entries for logical files are:

Entry
Meaning

R

Record format name

J

Join specification

Blank

Field name or select/omit AND condition

K

Key field name

S

Select field name

O

Omit field name
