Data Type Compatibility

Each high-level language has different data types. When you want
to pass data between programs that are written in different languages,
you must be aware of these differences.
Some data types in the ILE C programming language have no direct
equivalent in other languages. However, you can simulate data types
in other languages that use ILE C data types.

A CL character array (string) will not be NULL-ended when passed
to an ILE C program. A C program that will receive such arguments
from a CL program should not expect the strings to be NULL-ended.
You can use the QCMDEXC to ensure that all the arguments will be NULL-ended.

CL variables and numeric constants are not passed to an ILE C program
with null-ended strings. Character constants and logical literals
are passed as null-ended strings, but are not padded with blanks.
Numeric constraints such as packed decimals are passed as 15,5 (8
bytes).
