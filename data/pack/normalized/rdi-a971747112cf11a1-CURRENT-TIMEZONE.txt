CURRENT TIMEZONE
The CURRENT TIMEZONE special register specifies the difference
between UTC and local time at the current server.
The difference is represented by a time duration (a decimal
number in which the first two digits are the number of hours, the
next two digits are the number of minutes, and the last two digits
are the number of seconds).1 The number of hours is between -24 and 24 exclusive.
Subtracting CURRENT TIMEZONE from a local time converts that local
time to UTC.
ExampleUsing the IN_TRAY table, select
all the rows from the table and adjust the value to UTC.
SELECT RECEIVED - CURRENT TIMEZONE, SOURCE,
      SUBJECT, NOTE_TEXT FROM IN_TRAY

1 Coordinated Universal Time, formerly
known as GMT.
