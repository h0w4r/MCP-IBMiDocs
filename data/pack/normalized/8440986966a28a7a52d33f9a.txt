Instructions

To create the display file T1520DDJ using the DDS source shown in Figure 186, type:

CRTDSPF FILE(MYLIB/T1520DDJ) SRCFILE(QCPPLE/QADDSSRC)

To create the program T1520EHD using the source shown below, type:

CRTBNDC PGM(MYLIB/T1520EHD) SRCFILE(QCPPLE/QACSRC)

Note:Program T1520EHD uses signal() function to raise a SIGIO signal,
which is sent when normal data, OOB data, error conditions, or just about
anything happens on any type of socket.

If you need to add library MYLIB to the library list, enter:
ADDLIBLE LIB(MYLIB) 

To run the program T1520EHD, enter:

CALL PGM(MYLIB/T1520EHD)

The output is:
+--------------------------------------------------------------------------------+
| PHONE BOOK  |
| Name: Smith, John  |
| Address: 2711 Westsyde Rd.  |
| Phone #: 721-9729  |
| <ENTER> : Saves changes |
| f3 : Exits with changes saved |
| f5 : Brings back original field values |
+--------------------------------------------------------------------------------+
