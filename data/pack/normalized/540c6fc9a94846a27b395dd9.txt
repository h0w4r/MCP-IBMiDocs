ILE RPG SQL Precompiler use of CONST for arrays

Last Updated: 2025-10-07

When an array data structure is defined with the CONST keyword in ILE RPG, the SQL precompiler
was incorrectly allowing an element in the constant structure to be changed by a FETCH or SET RESULT
SETS statement. This invalid use of CONST is now correctly diagnosed with an SQL5011 message,
causing the precompile to fail.

This change occurs with the following:

- IBM® i Db2® for i 7.6:
PTF SJ05364

- IBM i Db2 for i 7.5: PTF Group SF99950 level 10

- IBM i Db2 for i 7.4: PTF Group SF99704 level 31
