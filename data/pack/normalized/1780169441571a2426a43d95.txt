Setting a Conditional Thread Breakpoint from the Work with Module Breakpoints Display
To set a conditional thread breakpoint using the Work with Module
Breakpoints display:

Press F13 to display Work with Module Breakpoints and press Enter.
Type 1 (Add) in the Opt field and press Enter.
Fill in the remaining fields as if it were a conditional job
breakpoint.

To remove a conditional thread breakpoint using the Work with Module
Breakpoints display: Type 4 (Clear) in the Opt field next to
the breakpoint you want to remove and Press Enter.
