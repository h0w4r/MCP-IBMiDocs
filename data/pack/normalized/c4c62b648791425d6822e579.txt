INDICATORS Phrase
Specifies which indicators are to be used when a data record is
written. Indicators can be used to pass information about the data
record and how it was entered into the program.
For detailed information on the INDICATORS phrase, refer to Using
Indicators with Transaction Files in the IBM® Rational® Development Studio for i: ILE COBOL
Programmer's Guide.
Identifier-4 must be either an elementary Boolean data item specified
without the OCCURS clause or a group item that has elementary Boolean
data items subordinate to it.
