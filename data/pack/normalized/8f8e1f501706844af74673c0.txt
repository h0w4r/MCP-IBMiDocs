LIKE(object-name)

You can use the LIKE keyword to specify that one object has the same class
as a previously defined object. Only the values on the CLASS keyword are inherited.

Figure 1. Defining objects LIKE other objects

* Variables MyString and OtherString are both Java String objects.
D MyString S O CLASS(*JAVA
D :'java.lang.String')
D OtherString S LIKE(MyString)
* Proc is a Java method returning a Java String object
D Proc PR EXTPROC(*JAVA:'MyClass':'meth')
D LIKE(MyString)

Note: You cannot use the *LIKE DEFINE operation to define an object.
You must use the LIKE keyword.
