Example: Setting Debug Options during a Debug Session
This example shows how to set the Update production files debug
option during a debug session.

To set debug options from a debug session, enter:

DSPMODSRC

When the Display Module Source display appears, enter

SET

When the Set Debug Options display appears, type Y (Yes) for
the Update production files field, and press Enter to return to the
Display Module Source display. The database files in production
libraries are updated while the job is in debug mode.
