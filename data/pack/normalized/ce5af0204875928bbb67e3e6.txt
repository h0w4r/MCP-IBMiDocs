CRT Status Key 3
The last two bytes of data-name-2 form CRT Status Key 3. If CRT Status
Key 1 is 0, CRT Status Key 3 contains the code for the keyboard key that terminated
the ACCEPT operation. Otherwise, if CRT Status Key 1 is 9, an error is signaled
by the operating system, and CRT Status Key 3 will be set to 99.
The codes for the keys are:
00 Enter key
90 Roll up key
91 Roll down key
93 Help key
94 Clear key

Help and Clear keys accept data only on local IBM® i workstations.
