Instructions

To create the MYLIB library, enter:

ADDLIBLE LIB(MYLIB)

To create the program T1520DL8 using the source shown in Figure 194, enter:

CRTBNDC PGM(MYLIB/T1520DL8) SRCFILE(QCPPLE/QACSRC)

To create the program T1520DL9 using the source shown in Figure 195, enter:

CRTBNDC PGM(MYLIB/T1520DL9) SRCFILE(QCPPLE/QACSRC)

To run the program T1520DL8, enter:

CALL PGM(MYLIB/T1520DL8)

The output is as follows:
+--------------------------------------------------------------------------------+
|Pointers passed correctly. |
|Press ENTER to end terminal session. |
+--------------------------------------------------------------------------------+
