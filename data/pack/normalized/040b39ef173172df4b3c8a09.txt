ADDUSRSNMP command changes

Last Updated: 2025-10-07

On the Add User for SNMP (ADDUSRSNMP) command, the default value of the Key
type (KEYTYPE) parameter has been changed from *LOCALIZED to *NONLOCALIZED.
Having a non-localized key allows the user to be available for incoming SNMPv3 trap messages in
addition to already being available for incoming get, get next, or set requests.
