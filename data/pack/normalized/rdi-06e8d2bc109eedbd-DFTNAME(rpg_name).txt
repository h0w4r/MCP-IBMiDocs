DFTNAME(rpg_name)

The DFTNAME keyword specifies a default program or module name. When *CTLSPEC
is specified on the create command, the rpg_name is used as the program or
module name. If rpg_name is not specified, then the default name is RPGPGM
or RPGMOD for a program or module respectively. The RPG rules for names (see Symbolic Names) apply.
