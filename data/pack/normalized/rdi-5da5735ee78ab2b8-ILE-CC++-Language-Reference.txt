Qualification conversions (C++ only)
An type-qualified rvalue of any type, containing zero or more const or volatile qualifications,
can be converted to an rvalue of type-qualified type where the second
rvalue contains more const or volatile qualifications
than the first rvalue.
An rvalue of type pointer to member of a class can be converted
to an rvalue of type pointer to member of a class if the second rvalue
contains more const or volatile qualifications
than the first rvalue.
