Mixed Functions
When the compiler handles a mixed function as fixed-point arithmetic, the
result will be either integer or fixed-point with decimals (when any argument
is floating-point, the function becomes a floating-point function and will
follow floating-point rules). For MAX, MIN, RANGE, REM,and
SUM, the outer-dmax is always equal to the inner-dmax. To determine the precision
of the result returned for these functions, apply the rules for fixed-point
arithmetic to each step in the algorithm used to calculate the function result.
