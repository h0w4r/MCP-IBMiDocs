Code Pages and CCSIDs
For source physical files, the compiler respects the CCSID of ILE C
source. A similar scheme exists for stream file compilation.
Stream files have a code page attribute.
The compiler converts source files, translating code pages to the root
source.
The source stream file may have been entered through a mounted file on an
ASCII system. In such a case, the compiler translates from the ASCII
codepage that is associated with the stream file (for example, 437) to EBCDIC
(for example, 37).
Support for Unicode wide-character literals can be enabled when building
your program by specifying LOCALETYPE(*LOCALEUCS2) on the compile
command. See Chapter 32, International Locale Support for more information..
You can configure most file transfer utilities to automatically do the
conversion to enable ASCII-based file systems to work for producing stream
file source.
