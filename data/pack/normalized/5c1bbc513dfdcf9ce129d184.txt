Package Product Option (PKGPRDOPT)

Package Product Option (PKGPRDOPT)

Last Updated: 2025-04-08

Where allowed to run: All environments (*ALL)

Threadsafe: No | Parameters

Examples

Error messages

The Package Product Option (PKGPRDOPT) command packages one or more product loads for a specified product option enabling the loads to be saved using the Save License Program (SAVLICPGM) command.

The only object types included in the packaged product are those supported by the Save Object List (QSRSAVO) API. Other object types are ignored.

Restrictions:

- This command is shipped with exclude (*EXCLUDE) public authority. The QPGMR, QSYSOPR, QSRV, and QSRVBAS user profiles are shipped with private authorities to use this command.

- To package a product load that has folders, you must be enrolled in the system distribution directory and you must have *ALL authority to the folders.

Top

Product ID (PRDID)

Specifies the 7-character identifier of the product option being packaged.

Top

Product option (OPTION)

Specifies the product option being packaged.

The possible values are:

*BASE
The base option is packaged.

product-option-number
Specify the option number of the to be packaged. Valid values range from 1 through 99.

Top

Allow change by program (ALWAPICHG)

Specifies whether to prevent changes to the description of each object included in the packaged product.

The possible values are:

*SAME
The 'Allow change by program' attribute of the objects being packaged is not changed by this command.

*NO
The object description for each object packaged cannot be changed by the Change Object Description (QLICOBJD) API or the Change Product Object Description (CHGPRDOBJD) command.

Top

Load identifier (LODID)

Specifies the load identifier of the product loads being packaged.

The possible values are:

*ALL
All product loads for which a product load object exists are packaged.
If only a code load exists, the code load is packaged.

*CODEDFT
The default code load ID, 5001, is packaged.

product-load-ID
Specify a language load ID or the default code load, 5001, for a code load.

Top

Release (RLS)

Specifies the version, release, and modification level of the product option.

The possible values are:

*ONLY
The release level is determined by searching the system for a product definition for the given product ID. The release level is taken from the product definition. This value is not valid if more than one product definition exists for the same product ID.

version-release-modification
Specifies the version, release, and modification level of the product. The release level can be passed as one of the following two formats:
Specify the release level in VxRyMz format, where Vx is the version number, Ry is the release number, and Mz is the modification level. The variables x and y can be a number from 0 through 9, and the variable z can be a number from 0 through 9 or a letter from A through Z.

Specify the release level in vvrrmm format, where vv are any numeric characters 00 through 35 representing the version of the product, rr are any numeric characters 00 through 35 representing the release of the product, and mm can be 00 through 09 or 0A through 0Z representing the modification of the product.

Top

Package again (REPACKAGE)

Specifies whether to allow the command to package a product option which has already been packaged.

The possible values are:

*NO
Product options which have been packaged are not repackaged.

*YES
Package all specified product options regardless of their current state.

Top

Examples

PKGPRDOPT PRDID(9XYZ123) OPTION(*BASE) ALWAPICHG(*SAME)

This command packages the base option of the product 9XYZ123.
