Summary of ′name′ scoping in nested compound statements
Nested compound statements can be used within an SQL routine
to define the scope of SQL variable declarations, cursors, condition
names, and condition handlers.
Additionally, labels have a defined scope in the context
of nested compound statements. However the rules for name space, and
how non-unique names can be referenced, differs depending on the type
of name. The following table summarizes these differences.
