Creating a file using DDS

Creating a file using DDSLast Updated: 2025-09-29

You can use data description specifications (DDS)
to create a file.

To create a file using DDS, follow these steps:

Complete the DDS form.
Type the source statements into a source file. The source file can be part of
the IBM i database (in a source physical file such
as the IBM-supplied QDDSSRC in library QGPL).
Create the file using the appropriate control language
(CL) command.
