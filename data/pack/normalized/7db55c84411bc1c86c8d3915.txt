CHGDEVPRT and CRTDEVPRT command changes

Last Updated: 2025-10-07

The Create Device Desc (Printer) (CRTDEVPRT) and Change Device Desc
(Printer) (CHGDEVPRT) commands have changed.

The Maximum length of request unit (MAXLENRU) parameter has been removed.

Any existing CL programs that use this command might need to be modified.
