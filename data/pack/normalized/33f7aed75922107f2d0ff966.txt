ABSVAL (Absolute Value) keyword for physical and logical files

You can use this key-field level keyword to direct
the operating system to ignore the sign of the field when the system sequences
the values associated with this numeric field.

This keyword has no parameters.

The ABSVAL keyword is not valid for a character, date, time, timestamp,
and hexadecimal data type field. You cannot use this keyword with the DIGIT,
SIGNED, UNSIGNED, or ZONE keywords.
ABSVAL (a key field-level
keyword) causes ALTSEQ (a file-level keyword) to be ignored. If you specify
ABSVAL for a key field, NOALTSEQ is in effect for that key field, even if
ALTSEQ was specified at the file level. This occurs, even if the NOALTSEQ
keyword is specified.
