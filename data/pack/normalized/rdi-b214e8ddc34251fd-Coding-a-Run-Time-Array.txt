Coding a Run-Time Array

If you make no further specifications beyond the essential array
specifications, you have defined a run-time array.
Note that the keywords ALT, CTDATA, EXTFMT, FROMFILE, PERRCD, and
TOFILE cannot be used for a run-time array.
