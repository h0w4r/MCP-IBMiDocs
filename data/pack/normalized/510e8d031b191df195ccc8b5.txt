OPTVALUE(a)
The possible values are:
NOOPT The generation of code to initialize
data items containing a VALUE clause in the working-storage section is not
optimized. This is the default.
OPT The generation of code to initialize data items
containing a VALUE clause in the working-storage section is optimized.
