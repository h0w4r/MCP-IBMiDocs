INTO Phrase
identifier-4
Represents the data receiving fields. Each must have
USAGE DISPLAY. These fields can be defined as: Alphabetic
Alphanumeric
Numeric (without the symbol P in the PICTURE string).

IBM ExtensionIBM Extension Identifier-4 cannot be defined as a floating-point
item. End of IBM Extension
End of IBM Extension IBM ExtensionIBM Extension Identifier-4 can
be a DBCS or national data-item. End of IBM Extension
End of IBM Extension
DELIMITER IN
Identifier-5 represents the delimiter receiving fields.
Identifier-5 must be alphanumeric. IBM ExtensionIBM Extension Identifier-5
can be a DBCS or national data-item. End of IBM Extension
End of IBM Extension The DELIMITER
IN phrase can be specified only if the DELIMITED BY phrase is specified.
The identifiers must not be defined as alphanumeric-edited or numeric-edited
items. If no delimiter is found in identifier-1, then identifier-5
is space filled.
IBM ExtensionIBM Extension If
identifier-5 is a national item, it is padded or filled as needed
with the 'national to national' padding character specified in the
NTLPADCHAR compiler or PROCESS statement option. End of IBM Extension
End of IBM Extension
COUNT IN
Identifier-6,
an integer data-item defined without the symbol P in the PICTURE string,
is the data-count field for each data transfer. Each field
holds the count of examined characters in the sending field, terminated
by the delimiters or the end of the sending field, for the move to
this receiving field; the delimiters are not included in this count.
IBM ExtensionIBM Extension When identifier-1 (the sending
field) is a DBCS or national data item, identifier-6 indicates the
number of characters (not the number of bytes) examined in the sending
field. End of IBM Extension
End of IBM Extension The COUNT IN phrase must not be specified unless the
DELIMITED BY phrase is specified.
