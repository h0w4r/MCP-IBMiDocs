Using the ixlc Command to Invoke the C/C++ Compiler
The ixlc command lets you invoke the compiler
and specify compiler options from a IBM i Qshell command line. Module
binder commands can be specified. The ixlc command can be used together
with AIX® make files to control
compilation.
