Using breakpoints within traces
Breakpoints can be used within a trace range.
At a breakpoint within a trace, you can display the trace data
(Display Trace Data (DSPTRCDTA) command) to determine
if you need to take some action. The trace data is recorded before the breakpoint
occurs. The trace information contains the value of any variables before
the statement was processed.
