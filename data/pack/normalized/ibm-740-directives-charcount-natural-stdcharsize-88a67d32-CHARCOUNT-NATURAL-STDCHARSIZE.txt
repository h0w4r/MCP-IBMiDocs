/CHARCOUNT NATURAL | STDCHARSIZE

/CHARCOUNT NATURAL | STDCHARSIZELast Updated: 2025-10-07

The parameter for the /CHARCOUNT directive can be NATURAL or STDCHARSIZE.

Specify NATURAL if you want the calculations following the directive to handle
string data by the natural size of each character.

Specify STDCHARSIZE if you want the calculations following the directive to handle
string data by bytes (Alphanumeric data) or double bytes (UCS-2 or graphic data).

See Processing string data by the natural size of each character.
