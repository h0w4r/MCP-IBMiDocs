CHGNETA command changes

Last Updated: 2025-10-07

Parameter changes for the Change Network Attributes (CHGNETA)
command

Default ISDN connection list (DFTCNNLST) parameter has been removed.

The Allow AnyNet® support (ALWANYNET) parameter has been removed. It will treated as *NO and AnyNet will no longer be started or useable. Customers currently using AnyNet should convert to Enterprise Extender before installing IBM® i 7.4.
