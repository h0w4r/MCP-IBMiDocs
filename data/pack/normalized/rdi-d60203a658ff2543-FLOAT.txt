FLOAT
The FLOAT function returns a floating point representation
of a number or string.
Numeric to Float
FLOAT(numeric-expression)
String to Float
FLOAT(string-expression)
FLOAT is a synonym for the DOUBLE_PRECISION and DOUBLE
functions. For more information, see DOUBLE_PRECISION or DOUBLE.
