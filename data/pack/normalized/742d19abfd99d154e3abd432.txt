IBM i journaling commands

Descripción
Comandos de IBM i para crear journals y journal receivers, iniciar o finalizar journaling de archivos físicos, visualizar entradas, aplicar/remover cambios y recuperar entradas de journal.

Intenciones cubiertas
- What are the journaling commands?
- Which commands manage journal receivers and journal entries?
- How do I start or end journaling for a physical file?
- How do I display, receive, retrieve, apply or remove journaled changes?

Comandos principales
- APYJRNCHG: Apply Journaled Changes.
- APYJRNCHGX: Apply Journaled Changes Extend.
- CHGJRN: Change Journal.
- CHGJRNA: Change Journal Attributes.
- CMPJRNIMG: Compare Journal Images.
- CRTJRN: Create Journal.
- CRTJRNRCV: Create Journal Receiver.
- DLTJRN: Delete Journal.
- DLTJRNRCV: Delete Journal Receiver.
- DSPJRN: Display Journal.
- DSPJRNRCVA: Display Journal Receiver Attributes.
- ENDJRN: End Journal.
- ENDJRNAP: End Journal Access Path.
- ENDJRNLIB: End Journal Library.
- ENDJRNOBJ: End Journal Object.
- ENDJRNPF: End Journal Physical File.
- RCVJRNE: Receive Journal Entry.
- RMVJRNCHG: Remove Journaled Changes.
- RTVJRNE: Retrieve Journal Entry.
- SNDJRNE: Send Journal Entry.
- STRJRN: Start Journal.
- STRJRNAP: Start Journal Access Path.
- STRJRNLIB: Start Journal Library.
- STRJRNOBJ: Start Journal Object.
- STRJRNPF: Start Journal Physical File.
- WRKJRN: Work with Journal.
- WRKJRNA: Work with Journal Attributes.
- WRKJRNRCV: Work with Journal Receivers.
