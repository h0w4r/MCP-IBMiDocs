NULL-KEY-MAP IS Phrase
Specifies the null key map of the record for the START
operation according to the value specified for identifier-2. Identifier-2
must be a boolean or alphanumeric item.
Identifier-2 can be subscripted or reference modified.
If the file has alternate keys, identifier-2 is associated with the null
key map of the current key of reference.
This phrase can only be specified for a file with the ALWNULL attribute
and a device type of DATABASE specified in the ASSIGN clause. If one of the
key fields is null-capable and the NULL-KEY-MAP phrase is not used, a null-key-map
with all boolean zeroes is used.
