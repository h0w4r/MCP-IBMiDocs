For All Other Files
If Format 3 is used for non-tape files, the records are treated as fixed
length records the size of the largest data record. The logical records are
truncated or padded to the length of the record as defined in the CRTxxxF
CL command. User length in the following table is defined as the largest
record associated with the given file, as specified by its record description.
  Input/Output Type
User Length Less Than File Record Length
User Length Greater Than File Record Length

Input
Truncation
Pad with blanks.

Output
Pad with blanks
Truncation if old file (non-empty); for new
(empty files) the larger record length is used.

Note: The maximum record length for a file is 32 767.
