Specifying an External Format for a Character, Graphic, or UCS-2 Field

For any of the input and output fields in Table 1, specify
one of the following valid external data formats:

A

Character (valid for character and indicator
data)

N

Indicator (valid for character and indicator
data)

G

Graphic (valid for graphic data)

C

UCS-2 (valid for UCS-2 data)

The EXTFMT keyword can be used to specify the data for an array or table
in UCS-2 format.

Specify the *VAR data attribute in positions 31-34 on an input specification
and in positions 53-80 on an output specification for variable-length character,
graphic, or UCS-2 data.
