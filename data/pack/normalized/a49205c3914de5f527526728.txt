ILE C/C++ Runtime Library Functions

<stdarg.h>
The <stdarg.h> include file defines macros that allow
you access to arguments in functions with variable-length argument
lists: va_arg(), va_start(),
and va_end(). The <stdarg.h> include
file also defines the type va_list.
