PDF file for DDS for display files

You can view and print a PDF file of this information.

To view or download the PDF version of this document,
select DDS
for Display files.

Saving PDF filesTo save a PDF on your workstation
for viewing or printing:
Right-click the PDF link in your browser.

Click the option that saves the PDF locally.

Navigate to the directory in which you want to save the PDF.

Click Save.

Downloading Adobe ReaderYou
need Adobe Reader installed on your
system to view or print these PDFs. You can download a free copy from
the Adobe Web
site (www.adobe.com/products/acrobat/readstep.html).
