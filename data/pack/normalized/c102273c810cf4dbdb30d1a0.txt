Identifier
An identifier is a syntactically correct combination of a data-name, with its
qualifiers, subscripts, and reference modifiers as required for uniqueness
of reference, that names a data item. In any Procedure Division reference
(except the class test or function argument in a test intrinsic function),
the contents of an identifier must be compatible with the class specified
through its PICTURE or FORMAT clause, or results are unpredictable.
