Removing all breakpoints
To remove all breakpoints, conditional and unconditional,
from a program object that has a module object shown on the Display Module
Source display, use the CLEAR PGM debug command.
To use the debug command, type the following on the debug command
line:
CLEAR PGM
The breakpoints are removed from all of the modules bound to
the program or service program.
