ORGANIZATION IS INDEXED (Format 3)

ORGANIZATION Clause - Indexed Files

>>-+----------------------+--INDEXED---------------------------><
   '-ORGANIZATION--+----+-'    
    '-IS-'    

The position of each logical record in the file is determined by the key
sequence access path created with the file and maintained by the system. The
access path is based on an embedded key within the file’s records.
