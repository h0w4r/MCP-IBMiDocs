Blank=Non-keyed Program-Described File

A program-described file that is processed without keys can be
processed:

Randomly by relative-record numbers, positions 28 and 34 must
be blank.

Entry Sequence, positions 28 and 34 must be blank.

As a record-address file, position 28 must be blank.
