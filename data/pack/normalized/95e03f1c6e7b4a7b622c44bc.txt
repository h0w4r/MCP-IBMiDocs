ILE COBOL Language Reference
This reference describes the Integrated Language Environment® COBOL (ILE COBOL) programming language.
It provides information on the structure of the ILE COBOL programming language
and the structure of an ILE COBOL source
program. It also provides a description of all Identification Division
paragraphs, Environment Division clauses, Data Division clauses, Procedure
Division statements, and Compiler-Directing statements.
This book refers to other IBM® publications.
These publications are listed in the Bibliography with their full title
and base order number. When they are referred to in text, a shortened
version of the title is used.
