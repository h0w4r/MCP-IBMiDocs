Using the STEP OVER Debug Command
Use the Step Over debug command to step over a called program in a debug
session. To use the Step Over debug command, enter STEP
number-of-statements OVER. The variable
number-of-statements is the number of statements of the program that
you want to run in the next step before the program is halted again.
If this variable is omitted, the default is 1. If one of the
statements that are run contains a call to another program, the ILE source
debugger steps over the called program.
