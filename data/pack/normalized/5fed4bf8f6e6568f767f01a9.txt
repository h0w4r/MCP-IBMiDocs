Create Service Configuration (CRTSRVCFG) and Change Service Configuration (CHGSRVCFG) command
changes

Last Updated: 2025-10-07

Due to the removal of PPP and L2TP software support, the CRTSRVCFG and CHGSRVCFG
commands will no longer allow values of *OTHERISP or *MULTIHOP for the Connection type
(CNNTYPE) parameter.
