Reading a file multiple times (CLOSE command)
The Close Database File (CLOSE) command can
be used to close a database file that is implicitly opened by the Receive
File (RCVF) command.
You can use the CLOSE command to process the records
in the database file more than once. When the file is closed, the next RCVF command
implicitly reopens the file and reads a record. You can also use the CLOSE command
for a database file that is already closed or was never opened; no error message
is sent. When the CL program or procedure ends, all database and display files
that are implicitly opened within the CL program or procedure were implicitly
closed.
