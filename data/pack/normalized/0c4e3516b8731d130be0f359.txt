ILE C/C++ Runtime Library Functions

<ctype.h>
The <ctype.h> include file defines functions
that are used in character classification. The functions that are
defined in <ctype.h> are:

isascii1
isalnum
isalpha

isblank2
iscntrl
isdigit

isgraph
islower
isprint

ispunct
isspace
isupper
isxdigit

toascii1
tolower
toupper

Note:
1 These functions
are not available when LOCALETYPE(*CLD) is specified on the compilation
command.

Note:
2 This
function is applicable to C++ only.
