FLAG(nn)
FLAG(nn) specifies the minimum severity level of
messages that will appear in the compiler listing.
You can specify a one or two-digit number, nn,
that specifies the minimum severity level of messages that you want to appear
in the compiler listing. Messages that have severity levels of this specified
value or higher will appear in the compiler listing. The default value for
FLAG is 0. FLAG(0) indicates that all messages will appear in the compiler
listing.
