DDS access path keywords

You can specify one or more access path keywords to affect the
way the operating system builds and uses key values.

The access path keywords are:

File level

Key field level

ALTSEQ
FCFO
FIFO
LIFO
REFACCPTH
UNIQUE

DESCEND
DIGIT
SIGNED
UNSIGNED
ZONE

Different key fields within a composite key can have different access path
keywords.
