Specifying the alert option
On the Add Message Description (ADDMSGD) command,
you can specify an alert option to allow an alert to be created for a message.
A message with an alert option specified can cause an SNA alert
to be created and sent to a problem management focal point.
The alert created for a message can be defined using the Add Alert
Description (ADDALRD) command.
