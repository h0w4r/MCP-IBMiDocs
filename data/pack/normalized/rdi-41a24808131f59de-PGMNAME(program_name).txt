PGMNAME(program_name)

The PGMNAME keyword identifies the program that is to handle the
support for the special I/O device (indicated by a Device-Entry of
SPECIAL).
Note: The parameter must be a valid program name
and not a bound procedure name.

See Positions 36-42 (Device) and PLIST(Plist_name) for more information.
