DSPRL (Display Right to Left) keyword for display files

You use this file-level keyword to specify that
the records in the display file are written right to left on the display.

This keyword has no parameters.
Option indicators are not
valid for this keyword.
This keyword can only be used on a bidirectional
device.

ExampleThe following example shows how to specify
the DSPRL keyword.
