CSOPT
This option lets you specify one or more compiler service options.
Valid option strings will be described in PTF cover letters and release
notes.

CSOPT Syntax:

|--+------------------------------------------------------+-----|
| .-*NONE---------------------------------. |
'-CSOPT(--+---------------------------------------+--)-'
'-'--compiler-service-options-string--'-'

*NONE
Default setting. No compiler service options selected.

compiler-servicing-options-string
Specified compiler service options are used when creating a
module object.
