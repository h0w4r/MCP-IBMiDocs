define

define syntax

>>-#--pragma--define--(--template_class_name--)----------------><

Description
The #pragma define directive forces the definition of a template
class without actually defining an object of the class. The pragma
can appear anywhere that a declaration is allowed. It is used when
organizing your program for the efficient or automatic generation
of template functions.
