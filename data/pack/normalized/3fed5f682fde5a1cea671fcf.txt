ILE C/C++ Runtime Library Functions

Conversion Errors
Some runtime routines perform a CCSID conversion from UTF-8 to
an EBCDIC CCSID when required to interface with an operating system
function that does not support UTF-8. When a conversion error occurs
in these cases, a C2M1217 message is generated to the job log with
the conversion information.
