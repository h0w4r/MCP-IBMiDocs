%UPPER (Convert to Upper Case)

%UPPER(string {: start { : length { : *NATURAL | *STDCHARSIZE } } })
%UPPER returns the string operand converted to upper case.

See %LOWER and %UPPER (Convert to Lower or Upper Case) for detailed information about both %LOWER and %UPPER.
