Entradas técnicas
- DCL: Declares CL variables and their type, length and optional initial value.
- TYPE(*CHAR): Character CL variable type.
- TYPE(*DEC): Packed decimal CL variable type.
- TYPE(*LGL): Logical CL variable type.
- GOTO CMDLBL: Transfers control to a command label inside a CL procedure or program.
- CMDLBL: Command label used as a target for GOTO or MONMSG handling.
- SNDPGMMSG: Sends a program message, including completion, diagnostic, escape or informational messages.
- SNDUSRMSG: Sends a message to a user or message queue.
- SNDMSG: Sends a simple message.
- OVRDBF: Override with Database File command; temporarily changes file attributes for a job or call level.
- OPNQRYF: Open Query File command for query-like access paths in CL-driven processing.
- OVRDBF before OPNQRYF: Common CL pattern: override/open scope before opening query file where required by the job flow.
- *CAT: Concatenates character operands in CL expressions.
- *BCAT: Concatenates strings with one blank separator.
- *TCAT: Concatenates strings after trimming trailing blanks.
- QCMDEXC: API used to execute CL command strings from programs.
