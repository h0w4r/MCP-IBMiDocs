Double-byte character set considerations for DDS

Be aware of these double-byte character
set (DBCS) considerations for the positional entries and keyword entries for
display files, as well as general considerations for using DBCS data in display
files.

The functions described in these topics are supported on both DBCS and
non-DBCS systems.
