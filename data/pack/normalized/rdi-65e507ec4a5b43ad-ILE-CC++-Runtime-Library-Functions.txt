ILE C/C++ Runtime Library Functions

<xxenv.h>
The <xxenv.h> include file contains the
declarations for the QPXXCALL and QPXXDLTE EPM
environment handling program. ILE procedures cannot be called from
this interface.
The definition of _ENVPGM_T is:
typedef struct _ENVPGM_T {
char pgmname[10];
char pgmlib[10];
} _ENVPGM_T;
