CHGFTPA command authority change

Last Updated: 2025-10-07

The Change FTP Attributes (CHGFTPA) command previously required *IOSYSCFG special authority to
view or change FTP server attributes. Now, on IBM® i 7.6, FTP
server attributes can be viewed when the user is enabled to the QIBM_IOSYSCFG_VIEW function usage
ID.
