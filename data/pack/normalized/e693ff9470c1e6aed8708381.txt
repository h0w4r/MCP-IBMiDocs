IBM i object and record lock commands

Descripción
Comandos de IBM i para ver locks de objetos, asignar/liberar objetos, revisar jobs propietarios y diagnosticar bloqueos operativos.

Intenciones cubiertas
- How do I check object locks?
- How can I see which job owns a lock?
- Which commands help diagnose locked members, objects or records?
- How do I allocate or deallocate objects?

Comandos principales
- WRKOBJLCK: Work with Object Locks.
- ALCOBJ: Allocate Object.
- DLCOBJ: Deallocate Object.
- WRKJOB: Work with Job.
- DSPJOB: Display Job.
- DSPJOBLOG: Display Job Log.
- WRKACTJOB: Work with Active Jobs.
- ENDJOB: End Job.

Términos semánticos
object locks, record lock, member lock, lock state, owner job, WRKOBJLCK, allocate object
