I/O Considerations for Record Save Files
If a save file is opened for input, the _Rfeod() function
returns an end-of-file to your program. If a save file is opened for
output, the _Rfeod() function ensures that any data that is
written to the file is forced to auxiliary storage. If you want to
continue reading from or writing to the save file after calling this function,
you must close the file and open it again.
