Special Considerations for Device Types DISK, DATABASE, and FORMATFILE
Only a physical file is cleared when opened for OUTPUT. When the file is successfully opened, it contains
no records. If an attempt is made to open a logical file for OUTPUT, the
file is opened but no records are deleted. The file is treated as though the
EXTEND phrase had been specified. To clear a logical file, all the members
on which the logical file is based should be cleared.
