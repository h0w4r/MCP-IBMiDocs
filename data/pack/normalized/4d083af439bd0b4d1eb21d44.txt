Entradas técnicas
- SFL: DDS keyword that identifies the record format as the subfile record format.
- RSTDSP: Restore display keyword/parameter used to restore the display when returning to a screen.
- USRRSTDSP: User Restore Display keyword for display files.
- SFLDSP: Subfile display keyword.
- SFLDSPCTL: Subfile control display keyword.
- SFLCTL: Defines the subfile control record format.
- SFLPAG: Specifies records per subfile page.
- SFLSIZ: Specifies total subfile size.
- SFLMSGKEY: Message key keyword used with message subfiles.
- SFLPGMQ: Program message queue keyword used with message subfiles.
- SFLMSGRCD: Subfile message record keyword.
- ERRMSG: Displays an error message for a field or record condition.
- ERRMSGID: Displays an error message by message ID.
- CFxx: Command function key keyword.
- CAxx: Command attention key keyword.
- INDARA: Uses a separate indicator area for display or printer files.
