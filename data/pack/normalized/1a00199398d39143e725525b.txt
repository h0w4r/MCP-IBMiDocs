Use the Work with CICS Group (WRKCICSGRP) command to list all groups in the library. This command also allows:

- Groups to be changed, deleted, installed, recovered, and saved.

- New groups to be created.

- The WRKCICS command to be invoked for tables associated with the group.

Top

Library (LIB)

Enter the name of the library that will contain the group.

Possible values are:

- *LIBL: The library list is used to locate all the groups that are in the libraries specified in the library list.

- *CURLIB: The current library contains the group. If no library is specified as the current library, the QGPL library is used.

- library-name: Specify the name of the library that contains the group.

Top

Group (GROUP)

Enter the name of the group to work with.

Possible values are:

- *ALL: All the groups that are associated with the library are listed.

- *FIRST: No group is specified. The first group found is used.

- group-name: The group name may have a maximum length of 10 characters. The first character must be alphabetic, or one of the special characters, $, @, or #. The remaining characters can be alphanumeric or one of the special characters, $, @, or #.
