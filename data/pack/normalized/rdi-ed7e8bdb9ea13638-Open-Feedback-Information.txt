Open Feedback Information

Positions 81 through 240 in the file information data structure contain
open feedback information. The contents of the file open feedback area are
copied by RPG to the open feedback section of the INFDS whenever the file
associated with the INFDS is opened. This includes members opened as a result
of a read operation on a multi-member processed file.

A description of the contents of the open feedback area, and what file
types the fields are valid for, can be found in the IBM® i
Information Center.
