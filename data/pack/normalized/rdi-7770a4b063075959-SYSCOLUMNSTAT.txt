SYSCOLUMNSTAT
The SYSCOLUMNSTAT view contains one row for every column
in a table partition or table member that has a column
statistics collection. If the table is a distributed table, the partitions
that reside on other database nodes are not contained in this catalog
view.
They are contained in the catalog views of the other database
nodes. The following table describes the columns in the SYSCOLUMNSTAT
view:
