Deleted Records
When a database record is deleted, the physical record is marked as deleted
but remains in the file. Deleted records can be overwritten by using
the _Rwrite() function. Deleted records can be removed
from a file by using the RGZPFM (Reorganize Physical File Member)
command. They can also be reused on write operations by specifying the
REUSEDLT(*YES) parameter on the CRTPF command.
Deleted records can occur in a file if the file has been initialized with
deleted records using the Initialize Physical File Member (INZPFM)
command. Once a record is deleted, it cannot be read.
