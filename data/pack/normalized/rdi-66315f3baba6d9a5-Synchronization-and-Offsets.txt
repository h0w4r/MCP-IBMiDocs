IBM ExtensionIBM Extension The SYNCHRONIZED clause is implicit for pointer data and procedure-pointer
data items. Pointer data and procedure-pointer data items declared in the
Linkage Section are not synchronized.

The SYNCHRONIZED clause cannot be specified in the same data description
entry as the TYPE clause.

The SYNCHRONIZED clause is ignored for a DBCS, national, external
floating-point, date, time, or timestamp data item.

The SYNCHRONIZED clause for a COMPUTATIONAL-1 data item aligns the data
on a fullword boundary.

The SYNCHRONIZED clause for a COMPUTATIONAL-2 data item aligns the data
on a doubleword boundary.
