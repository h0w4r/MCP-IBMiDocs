APYJRNCHGX command

Last Updated: 2025-10-07

The Apply Journaled Changes Extended (APYJRNCHGX) command will be
removed in a future release.

The support for the Apply Journaled Change Extended (APYJRNCHGX) command will
be removed in a future release. The (APYJRNCHGX) command was first delivered in
i5/OS V5R2 and provided additional functions that the Apply Journaled Changes
(APYJRNCHG) command did not have. In IBM® i 7.1 and subsequent releases, the APYJRNCHG command and other CL commands provide the functions that were provided
by the APYJRNCHGX command.
