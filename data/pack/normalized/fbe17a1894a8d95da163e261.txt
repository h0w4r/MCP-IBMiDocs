Enabling Unicode Character Set Support

To enable Unicode character set support, specify
LOCALETYPE(*LOCALEUCS2) on the CRTCMOD/CRTCMODCPP or
CRTBNDC/CRTBNDCPP command line. When this option is selected, the
__UCS2__ macro is defined. Wide-character literals are
interpreted using the CCSID of the root source file, then translated to the
Unicode CCSID (13488) when stored.
