Specifying File Translation

To specify file translation, use the FTRANS
keyword on the control specification. The translations must be transcribed into the correct record
format for entry into the system. These records, called the file translation table records, must
precede any alternate collating sequence records, or arrays and tables loaded at compile time. They
must be preceded by a record with **␢ (␢ = blank) in positions 1 through 3 or **FTRANS in positions
1 through 8. The remaining positions in this record can be used for comments.
