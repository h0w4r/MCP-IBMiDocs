Retrieving network attributes
Using the Retrieve Network Attributes (RTVNETA) command,
you can retrieve the network attributes of the system.
These attributes can be changed using the Change Network
Attributes (CHGNETA) command and displayed using the Display
Network Attributes (DSPNETA) command.
