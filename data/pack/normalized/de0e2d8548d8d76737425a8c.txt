Error messages

The End Font Downloader (ENDFNTDWN) command ends the font
downloader server job and closes the TCP/IP port being used by the
server job.
The server job will be ended immediately, whether or not it is
receiving a font from a a font downloader client application.

Error messages for ENDFNTDWN

*ESCAPE Messages

IPS2204
Infoprint Server Font Downloader was not started.
IPS2205
Font Downloader ended.
IPS2207
Infoprint Server Font Downloader could not be ended.
