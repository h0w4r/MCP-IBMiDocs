Separators

When coding a date format on a MOVE, MOVEL or TEST operation, separators
are optional for character fields. To indicate that there are no separators,
specify the format followed by a zero. For more information on how to code
date formats without separators see
%CHAR(date|time|timestamp {: format}),
%DATE (Convert to Date),
MOVE (Move),
MOVEL (Move Left) and TEST (Test Date/Time/Timestamp).
