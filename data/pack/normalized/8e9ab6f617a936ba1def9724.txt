UNDERLINE (Underline) keyword in printer files

You use this field-level keyword to specify that
the IBM® i operating system
underlines the field when it is printed.

Specify UNDERLINE only if the printer supports underlining.
This
keyword has no parameters.
Option indicators are valid for this keyword.

ExampleThe following example shows how to specify
the UNDERLINE keyword.
|...+....1....+....2....+....3....+....4....+....5....+....6....+....7....+....8
00100A ALLOC R 17 11
00101A 03 04 UNDERLINE
