SYSINDEXSTAT
The SYSINDEXSTAT view contains one row for every SQL index partition.
Use this view when you want to see information for a specific
SQL index or set of SQL indexes. The information is similar to that
returned via Show Indexes in System i® Navigator.
The following
table describes the columns in the SYSINDEXSTAT view:
