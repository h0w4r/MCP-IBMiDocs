Template parameters (C++ only)
There are three kinds of template parameters:

Type template parameters (C++ only)
Non-type template parameters (C++ only)
Template template parameters (C++ only)You can interchange the keywords class and typename in
a template parameter declaration. You cannot use storage class specifiers
(static and auto) in a template parameter declaration.
