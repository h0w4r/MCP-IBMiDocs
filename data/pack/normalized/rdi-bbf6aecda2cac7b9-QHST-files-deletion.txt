QHST files deletion
Log version physical files accumulate on a system and you should
periodically delete old logs that are not needed.
A log version is created such that only the security officer
is authorized to delete it.
The Operational Assistant provides a cleanup
function which includes the deletion of old QHST files. Another alternative
is:
As the security officer, specify:
WRKOBJ OBJ(QSYS/QHST*) OBJTYPE(*FILE)
Use option 4 to delete old unneeded files.
