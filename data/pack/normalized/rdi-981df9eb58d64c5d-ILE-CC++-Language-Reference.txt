The noinline function attribute
The noinline function attribute prevents the function
to which it is applied from being inlined, regardless of whether the
function is declared inline or non-inline. The attribute takes
precedence over inlining compiler options and the inline keyword.

noinline function attribute syntax

>>-__attribute__--((--+-noinline-----+--))---------------------><
'-__noinline__-'

Other than preventing inlining, the attribute does not remove the
semantics of inline functions.
