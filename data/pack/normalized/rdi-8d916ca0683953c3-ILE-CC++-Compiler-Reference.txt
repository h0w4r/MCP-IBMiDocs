DTAMDL
Specifies how pointer types are interpreted in absence of an explicit
modifier. The __ptr64 and __ptr128 type modifiers and the datamodel
pragma override the setting of the DTAMDL compiler option.

DTAMDL Syntax:

|--+------------------------+-----------------------------------|
| .-*P128--. |
'-DTAMDL(--+-*LLP64-+--)-'

*P128
Default setting. The default size of pointer
variables is 16 bytes.

*LLP64
The default size of pointer variables is 8 bytes,
and the compiler defines the macro __LLP64_IFC__.

Use of DTAMDL(*LLP64) together with TERASPACE(*NO)
is flagged as an error by the compiler, and compilation stops.
See pragma datamodel for more information.
For more information about valid combinations for the STGMDL, TERASPACE,
and DTAMDL compiler options, see TERASPACE.
