Special Considerations for Device Types DISK and DATABASE
Null-capable fields are supported when the READ statement is performed
on a file which is found on a DISK or DATABASE device. However,
null values are only supported for DATABASE files that have ALWNULL specified
on their ASSIGN clause. If ALWNULL is not specified, the READ operation will
fail and file status 90 will be returned, if a field contains a null value.
You should also specify NULL-MAP/NULL-KEY-MAP on your READ statement, so you
can see which fields contain the null value.
