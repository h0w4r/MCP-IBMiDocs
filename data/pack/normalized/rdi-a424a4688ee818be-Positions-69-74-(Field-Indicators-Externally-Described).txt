Explanation

RT

Return indicator.

Field indicators are allowed for null-capable fields only if the ALWNULL(*USRCTL)
keyword is specified on a control specification or as a command parameter.

If a field is a null-capable field and the value is null, the indicator
is set off.

See Positions 69-74 (Field Indicators - Program Described) for more information.
