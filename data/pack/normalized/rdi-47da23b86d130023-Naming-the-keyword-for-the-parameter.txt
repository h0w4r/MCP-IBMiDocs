Naming the keyword for the parameter
The name of the keyword that you choose for a
parameter should be descriptive of the information that is requested in the
parameter value.
For example, USER for user name, CMPVAL for compare value, and
OETYPE for order entry type. The keyword can be as long as 10 alphanumeric
characters, the first of which must be alphabetic.
