Special Considerations for Device Type DATABASE
The file may be placed under commitment control. See "Commitment
Control" in the IBM® Rational® Development Studio
for i: ILE COBOL Programmer's Guide for more information.
If the file contains null-capable fields, and ALWNULL was not specified on
the ASSIGN clause for the file, a file status of 0P is set, and only
the records that do not contain null fields may be processed. Otherwise,
if ALWNULL was specified for a null-capable file, null fields can
be processed, and file status 0P is not set.
