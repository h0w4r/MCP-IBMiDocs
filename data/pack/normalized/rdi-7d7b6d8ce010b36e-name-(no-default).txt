name (no default)

The name option is used for DATA-GEN.

The name option specifies the name
to be used for the top-level of the generated document for the
DATA-GEN operation.
The name is passed to the generator in the same case as it
is specified for the option.

For example, for the following DATA-GEN operation,
the name passed to the generator as the name of the top-level
item is "Orders".

Without the "name" option, the name passed to the generator
would be "Rec", which is the name specified for the
definition of the data structure, in the same mixed-case
form as the name was specfied.

DCL-DS Rec LIKEDS(orders_t);
...
DATA-GEN rec %DATA(filename : 'doc=file name=Orders') %GEN('MYPGM');
