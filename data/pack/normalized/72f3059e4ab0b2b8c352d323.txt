PRFDTA(*NOCOL | *COL)

The PRFDTA keyword specifies whether the collection of profiling data is
enabled.

If *NOCOL is specified, the collection of profiling data is not enabled
for this object.

If *COL is specified, the collection of profiling is enabled for this object.
*COL can be specified only when the optimization level of the object is *FULL.

If the PRFDTA keyword is not specified, then the value specified on the
command is used.
