Returned Values
The following values are returned by the LOCALE-TIME intrinsic function:
If mnemonic-1 is specified, the locale used for formatting the time is
the one associated with mnemonic-name-1; otherwise, the current locale is
used. If the locale associated with mnemonic-name-1 is not available, an
operating system escape message is issued.
The returned value is a character-string containing the hours, minutes,
and seconds of the time specified by argument-1 in the culturally-appropriate
format indicated in the locale. The value will be adjusted for any difference
between the offset from Universal Coordinated time (Greenwich Mean time) held
in the last five character positions of argument-1, and that specified for
the LC-TOD category of the locale.
The length of the returned value depends on the format indicated in the
locale.
