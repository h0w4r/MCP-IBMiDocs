Using the STEP INTO Debug Command
Use the STEP INTO debug command to step into a called program in a debug
session. To use the STEP INTO debug command, enter:
STEP number-of-statements INTO

The variable number-of-statements is the number of statements of
the program that you want to run in the next step before the program is halted
again. If this variable is omitted, the default is 1.
