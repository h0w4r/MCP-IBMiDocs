Size Operations

The following built-in functions return information about the size of a
varible, field, constant, array, table, or data structure:

%DECPOS (Get Number of Decimal Positions)

%LEN (Get or Set Length)

%SIZE (Get Size in Bytes)

These built-in functions are available in both the traditional syntax and
free-form syntax.
