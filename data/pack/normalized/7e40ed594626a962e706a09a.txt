_C_Get_Ssn_Handle() — Handle to C Session
Format
#include <stdio.h>

_SSN_HANDLE_T _C_Get_Ssn_Handle (void)
Language Level: ILE C Extension
Threadsafe: Yes.
Description
Returns a handle to the C session for use with Dynamic Screen Manager
(DSM) APIs.
Return Value
The _C_Get_Ssn_Handle() function returns
a handle to the C session. If an error occurs, _SSN_HANDLE_T
is set to zero. See the APIs topic in the
Information Center for more information about using the _C_Get_Ssn_Handle() function
with DSM APIs.
