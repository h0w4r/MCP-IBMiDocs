NTLCCSID(a)
Specifies the national coded character set identifier (NTLCCSID) that
will be used for all National data items.
NTLCCSID(a)
where a is the CCSID to be used for all National data items.
The possible values are:
13488
The UCS-2 CCSID 13488 is used for all
National data items.

coded-character-set-identifier
The specified
CCSID is used for all National data items. The CCSID specified must be UCS-2
compatible, for example UTF-16 CCSID 1200.
