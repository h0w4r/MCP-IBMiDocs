Arranging Key Fields
Keyed sequence access paths can be ordered in ascending or descending
sequence. When you describe a key field, the default is ascending
sequence. If you are using Data Description Specifications (DDS) to
create a keyed sequence file, the DESCEND DDS keyword can be used to specify
that the key fields are to be arranged in descending sequence.
