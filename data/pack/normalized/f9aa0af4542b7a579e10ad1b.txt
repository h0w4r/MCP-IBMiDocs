Positional entries for files that use DBCS data

Last Updated: 2025-10-07

Positional entries are adapted so that you can
define data fields that contain double-byte character set (DBCS) data. The
entries are adapted for the length and data type positional entries.

DBCS data is either bracketed or graphic. Bracketed-DBCS
data begins with a shift-out character and ends with a shift-in character.
DBCS-graphic data contains only DBCS data and does not contain shift-out or
shift-in characters. The term DBCS refers to both bracketed and graphic DBCS
data.
