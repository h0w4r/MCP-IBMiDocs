fileccsid (default utf8)

The fileccsid option is used for DATA-GEN.

The fileccsid option specifies
the CCSID to be used if the output file for the DATA-GEN operation
does not exist.

If the fileccsid option is not specified,
and the output file does not exist, the output file is created
with CCSID UTF-8 (1208).

utf8

UTF-8 (1208)

utf16

UTF-16 (1200)

job

The job CCSID.
If the job CCSID is 65535, the default CCSID of the job is used.

number

A specific CCSID
