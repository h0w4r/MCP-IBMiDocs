The Delete Device Media Library (DLTDEVMLB) command deletes a library device name from the system that had previously been created with the Create Device Media Library (CRTDEVMLB) command.

Top

Parameters

Keyword | Description | Choices | Notes
DEVD | Device description | Name | Required, Positional 1

Top

Device description (DEVD)

Specifies the library device to be deleted from the system.

This is a required parameter.

name
Specify the name of the library device.

Top

Examples

DLTDEVMLB DEVD(TAPMLB01)

This command deletes the tape media library device description TAPMLB01.
