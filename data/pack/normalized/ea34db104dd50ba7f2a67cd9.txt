Release to release Command Output considerations

Applications that specify OUTPUT(*PRINT) or OUTPUT(*)
must be able to tolerate changes to the record layout in either the spooled file or the screen
output. From release to release, commands can add, change, or remove records from the output. Any
application that has a dependency on the record layout for a specific command might have to
change.
