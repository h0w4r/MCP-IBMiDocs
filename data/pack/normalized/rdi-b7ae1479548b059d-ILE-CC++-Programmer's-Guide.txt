Converting from Packed Decimal Data Types
If the value of the packed decimal type to be converted is within the range
of values that can be represented exactly, the value of the packed decimal
type is not changed. Packed decimal types are compatible if their types
are the same. For example, decimal(n1,
p1) and decimal(n2,
p2) have compatible types if and only if
((n1 = n2) and
(p1 = p2)).
