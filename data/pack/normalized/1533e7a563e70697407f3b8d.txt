Command-related APIs
Some application programming interface
programs can be used with commands.

QCAPCMD program
The Process Commands (QCAPCMD) API performs
command analyzer processing on command strings.
QCMDEXC program
The Execute Command (QCMDEXC) API is an IBM-supplied program that
runs a single command.
QCMDCHK program
The Check Command Syntax (QCMDCHK) API is an
IBM-supplied program that performs syntax checking for a single command, and
optionally prompts for the command.
