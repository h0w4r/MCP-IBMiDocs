LIKEFILE(parent-filename)

The LIKEFILE keyword is used to define one file like another file.

Note: In the following discussion, the term new file is
used for the file defined using the LIKEFILE keyword, and the term
parent file is used for the parameter of the LIKEFILE keyword whose
definition is used to derive the definition of the new file.
