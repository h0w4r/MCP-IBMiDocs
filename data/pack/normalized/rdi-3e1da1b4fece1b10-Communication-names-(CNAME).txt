Communication names (*CNAME)
A communications name has a restrictive name syntax. It is typically
used to refer to a device configuration object whose name length and valid
character set is limited by one or more communication architectures.
Communications names are the same as unquoted basic names with some exceptions:
Periods (.) and underscores (_) cannot be used.
For IBM® commands,
*CNAME is limited to 8 characters.

An example of a communications name is shown as follows:
APPN3@@
Because restricted character sets are sometimes used by other IBM systems, use
caution when choosing names that use the special characters #, $, and @. These
special characters might not be on the remote system's keyboard. The names
that can be exchanged with the remote systems include the following names:
Network IDS
Location names
Mode names
Class-of-service names
Control point names
