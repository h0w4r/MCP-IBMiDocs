END-RETURN Phrase
This explicit scope terminator serves to delimit the scope of the RETURN
statement. END-RETURN permits a conditional RETURN statement to be nested
in another conditional statement. END-RETURN may also be used with an imperative
RETURN statement.
For more information, see Delimited Scope Statements.
