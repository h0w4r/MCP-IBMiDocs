Calling Programs
When you call a program, the OS/400 system locates the corresponding
executable code and performs the instructions found in the program.
Note:Only programs can run independently. Service programs or other bound
procedures must be called from a program that requires their services.

There are several ways to call a program:

Using the Call (CALL) command
Using the Transfer Control (TFRCTL) command
Creating a CL command to call a program
