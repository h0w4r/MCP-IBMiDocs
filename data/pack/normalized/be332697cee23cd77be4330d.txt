The Start System Service Tools (STRSST) command shows the System Service Tools (SST) menu.

Note: Improper use of service tools can damage your system.

You can:

- Start a service function

- Work with active service functions

- Work with disk unit configuration and data

- Work with diskette data recovery

- Work with system partitions

- Work with system capacity

- Work with system security

- Work with service tools user IDs and Devices

Restriction: To use this command, you must have *SERVICE special authority.

There are no parameters for this command.
