TRCTCPAPP command parameter changes

Last Updated: 2025-10-07

With IBM® i 7.6, the Trace TCP/IP Application
(TRCTCPAPP) command has removed parameter values and parameters that are obsolete. The
command has changed to remove obsolete Maximum storage for trace (MAXSTG), Device description
(DEVD), and Device type (DEVTYPE) parameters.

Additionally, the Additional traces (ADLTRC) parameter has removed obsolete special values *DEVD,
*DEVMGR, *JOB, *USER and *USERDEVD.

The TRCTCPAPP command has also removed parameter positional for all parameters except APP and
SET. TRCTCPAPP is only used under recommendation by IBM support, but if this is used in any user CL
scripts or programs, the TRCTCPAPP command call may need modification.

Note: These removed functions
only affect the *TELNET and *VTAPI applications. The TRCTCPAPP command is generally only requested
under IBM support direction, this should not affect users of
this command unless they have been instructed in prior releases to use these obsolete
parameters.
