CLOSE Statement - Format 2 - Tape Files

    .-------------------------------------------------.   
    V |   
>>-CLOSE----file-name-1--+--------------------------------+-+--><
    +-+-REEL-+--+------------------+-+    
    | '-UNIT-' '-+-----+--REMOVAL-' |    
    | '-FOR-' |    
    '-+------+--+-NO REWIND-+--------'    
    '-WITH-' '-LOCK------'    

file-name-1
Designates the file upon which the CLOSE statement is to operate. If
more than one file name is specified, the files need not have the same organization
or access. File-name-1 must not be a sort or merge file.
