Reducing Program Startup Time

When a new ILE program is first called, the system needs to perform some
initialization to prepare the program to run. Part of this
initialization requires creating an activation group for all of the program
storage, resolving all service programs bound to the program, getting program
arguments and so on. Several recommendations for improving start-up
time can be drawn from these initialization steps:

Reduce the use of global variables.
Reduce the number of service programs bound to the program.
The more service programs used by an ILE program, the more time is required to
start up the program. It is often better to have a few large service
programs than many small ones. For example, the C run-time libraries
comprise a small number of service programs.
