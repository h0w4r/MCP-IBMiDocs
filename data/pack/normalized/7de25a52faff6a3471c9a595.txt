Error Handling for Database Data Mapping Errors

For any input or output operation, a data mapping error will cause a severe
error message to be issued. For blocked output, if one or more of the records
in the block contains data mapping errors and the file is closed before reaching
the end of the block, a severe error message is issued and a system dump is
created.
