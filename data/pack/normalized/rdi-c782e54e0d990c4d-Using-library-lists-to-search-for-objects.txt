Using library lists to search for objects
By using library lists, you can either search
for multiple objects or a single object. A generic search can be used for
multiple object searches.

Generic object names searching
A generic search can be used to search for more than one object.
Searching for multiple objects or a single object
In all commands for which you can specify a generic name, you can
specify an object name (no asterisk is specified) and you can search for multiple
objects.
