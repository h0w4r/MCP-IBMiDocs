SYSSCHEMAS
The SYSSCHEMAS view contains one row for every schema in
the relational database.
For information related to a single schema,
a query that uses table function OBJECT_STATISTICS will perform much
better than querying SYSSCHEMAS. For example: SELECT *
FROM TABLE (QSYS2.OBJECT_STATISTICS('MJATST ','LIB ')) AS A
