Positions 30, 38, and 46 (Character)

In this position enter the identifying character that is to be compared
with the character in the position specified in the input record.

The check for record type always starts with the first record type specified.
If data in a record satisfies more than one set of record identification
codes, the first record type satisfied determines the record types.

When more than one record type is specified for a file, the record identification
codes should be coded so that each input record has a unique set of identification
codes.
