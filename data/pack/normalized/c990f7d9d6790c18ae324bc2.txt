The CLEAR operation sets elements in a structure (record
format, data structure, array, or table) or a variable (field, subfield,
array element or indicator), to their default initialization value
depending on field type (numeric, character, graphic, UCS-2, indicator,
pointer, or date/time/timestamp). For the default initialization value
for a data type, see Data Types and Data Formats.

You can specify *NOKEY
for some record formats and you can specify *ALL
for tables, multiple-occurrence data structures, and record formats.

Fully qualified names may be specified as the Result-Field
operand for CLEAR when coded in free-form calculation specifications. If
the structure or variable being cleared is variable-length, its length
changes to 0. The CLEAR operation allows you to clear structures on
a global basis, as well as element by element, during run time.

See Initialization Operations.
