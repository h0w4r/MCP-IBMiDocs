ILE C/C++ Compiler Reference

MODULE
Valid only on the CRTCMOD and CRTCPPMOD commands. Specifies the
module name and library for the compiled ILE C or C++ module object.

MODULE Syntax:

.-*CURLIB/------.
|--MODULE(--+---------------+--module-name--)-------------------|
'-library-name/-'

*CURLIB
This is the default library value. The object is stored in the
current library. If a job does not have a current library, QGPL is
used.

library-name
Enter the name of the library where the object is to be stored.

module-name
Enter a name for the module object.
