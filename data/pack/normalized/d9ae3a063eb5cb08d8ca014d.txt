Example: Displaying logical variable
This example uses the EVAL debug command to display the value of
logical variables.
CL declarations: DCL VAR(&LGL1) TYPE(*LGL) VALUE('1')

Debug command: EVAL &LGL1

Result: &LGL1 = '1'
