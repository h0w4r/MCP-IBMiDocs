Positions 63-64 (Control Level)

This entry indicates whether the field is to be used as a control field
in the program.
Entry
Explanation

Blank

This field is not a control field.

L1-L9

This field is a control field.

Null-capable and UCS-2 fields cannot be used as control fields.
Note: For externally described files, split control fields are combined
in the order in which the fields are specified on the data description specifications
(DDS), not in the order in which the fields are specified on the input specifications.
