Coding Examples
To create data item DEPTH with the same attributes as data item HEIGHT,
you simply write:
   DEPTH LIKE HEIGHT

To create data item PROVINCE with the same attributes as data item STATE,
except one byte longer, you write:
   PROVINCE LIKE STATE (+1)
