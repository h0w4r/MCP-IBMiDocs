Example: Retrieving QTIME system value

Example: Retrieving QTIME system valueLast Updated: 2025-10-07

In this example, QTIME is received and moved to a variable,
which is then compared with another variable.

Note: By using the code example, you agree to the terms of
the Code license and disclaimer information.

PGM
DCL VAR(&PWRDNTME) TYPE(*CHAR) LEN(6) VALUE('162500')
DCL VAR(&TIME) TYPE(*CHAR) LEN(6)
RTVSYSVAL SYSVAL(QTIME) RTNVAR(&TIME)
IF (&TIME *GT &PWRDNTME) THEN(DO)
SNDBRKMSG('Powering down in 5 minutes. Please sign off.')
PWRDWNSYS OPTION(*CNTRLD) DELAY(300) RESTART(*NO) +
IPLSRC(*PANEL)

ENDDO
ENDPGM
