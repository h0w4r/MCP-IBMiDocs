The Edit Rebuild of Access Paths (EDTRBDAP) command displays the Edit Rebuild of Access Paths menu, from which the access path information can be displayed or changed.

Restrictions:

- To use this command, you must be signed on as QSYSOPR or have all object (*ALLOBJ) special authority.
