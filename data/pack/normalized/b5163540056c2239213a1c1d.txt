Removal of RouteD commands

Last Updated: 2025-10-07

Support for the RouteD server is being removed. These CL commands used to configure the RouteD
server have been removed in IBM i 7.6:

- Configure TCP/IP RouteD (CFGTCPRTD)

- Change RouteD Attributes (CHGRTDA)

- Work with RouteD Configuration (WRKRTDCFG)
