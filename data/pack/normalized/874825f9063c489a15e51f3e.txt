Command changes Application Development ToolSet

Last Updated: 2025-10-07

Support for selected Application Development ToolSet tools and their associated commands is being
limited to security related fixes. These commands continue to be available in IBM® i 7.6:

- Start Data File Utility (STRDFU)

- Create DFU Display File (CRTDFUDSPF)

Support for selected Application Development ToolSet tools and their associated commands is being
limited to security related fixes. These commands continue to be available in IBM i 7.6, however the PDM menu option for these commands is removed in IBM i 7.6:

- Compare Physical File Member (CMPPFM)

- Merge Source (MRGSRC)
