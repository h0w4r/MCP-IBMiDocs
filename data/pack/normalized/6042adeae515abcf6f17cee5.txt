QXXZTOI() — Convert Zoned Decimal to Integer
Format
#include <xxcvt.h>
int QXXZTOI(unsigned char *zptr, int digits, int fraction);
Language Level: ILE C Extension
Threadsafe: Yes.
Description
The QXXZTOI function converts to an integer, the zoned
decimal number (with digits total digits, and fraction fractional
digits) pointed to by zptr. The resulting integer is returned.
Example that uses QXXZTOI()

#include <xxcvt.h>
#include <stdio.h>

int main(void)
{
unsigned char zptr[] = "000111115";
int digits = 9, fraction = 0, result;

result = QXXZTOI(zptr, digits, fraction);
/* result = 111115 */
}
