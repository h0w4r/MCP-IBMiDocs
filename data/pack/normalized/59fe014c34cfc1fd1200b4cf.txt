Enabling Integrated File System Stream I/O
You can enable ILE C/C++ stream I/O for files up to two gigabytes in
size by specifying the *IFSIO option on the system interface keyword
(SYSIFCOPT) on the Create Module or Create Bound Program command
prompt. For example:
CRTCMOD MODULE(QTEMP/IFSIO) SRCFILE(QCPPLE/QACSRC) SYSIFCOPT(*IFSIO)
CRTBNDC PGM(QTEMP/IFSIO) SRCFILE(QCPPLE/QACSRC) SYSIFCOPT(*IFSIO)
