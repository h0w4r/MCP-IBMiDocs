Keywords supported for printer file device type of *AFPDS.

Beginning with OS/400® V3R1, the Advanced Function Printing (AFP) subsystem was a separately orderable
feature of the IBM® i operating
system, called Print Services Facility (PSF).

There are two separate subsystems in the IBM i operating system.
The original IBM i printing
subsystem continues to support line printers, ASCII printers, and
a subset of IBM Intelligent
Printer Data Stream (IPDS) printers and print functions. Full support
for all IPDS printers
is provided by the integrated AFP printing subsystem. The printing subsystem
used to process application output is determined by the device description
of the target printer. Only printers defined as DEVTYPE(*IPDS) and
AFP(*YES) (both specified in the printer device description) are controlled
by the AFP printing
subsystem.

In order to print based on the values specified
for certain keywords, PSF is required. For example, some spooled files
generated with DEVTYPE(*AFPDS) can only be printed by PSF. Most can
also be printed on a printer configured to use Host Print Transform.

that have the printer device type (DEVTYPE) parameter value specified
