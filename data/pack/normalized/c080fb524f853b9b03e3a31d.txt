SYSTABAUTH
The SYSTABAUTH view contains one row for every privilege
granted on a table or view. Note that this catalog view cannot be
used to determine whether a user is authorized to a table or view
because the privilege to use a table or view could be acquired through
a group user profile or special authority (such as *ALLOBJ).

view:
