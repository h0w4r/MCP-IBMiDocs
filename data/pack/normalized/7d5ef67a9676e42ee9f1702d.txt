The Procedure Division Header
The Procedure Division, if specified, is identified by the following
header.

Procedure Division - Header - Format

>>-PROCEDURE DIVISION--+-----------------------------+---------->
    | .------------------. |   
    | V | |   
    '-USING----| Using-phrase |-+-'   

>--+-------------------------------------------------+--.------><
   | (1) |    
   '-+-RETURNING------+--+------------+--data-name-2-'    
    '----------------' '-ADDRESS OF-'    
    '-+------------+-'    
    | (1) |    
    '-GIVING-----'    

Notes:IBM® ExtensionThe USING phrase is required only if the object program is to be
invoked by a CALL statement and that statement includes a USING phrase.
