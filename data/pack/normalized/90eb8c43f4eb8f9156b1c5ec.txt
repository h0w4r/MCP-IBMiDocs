Type of name or specification for ICF files (position 17)

You can enter a value in this position to identify
the type of name specified in positions 19 through 28.

The valid entries for ICF files are:

Entry

Meaning

R

Record format name

Blank

Field name

The ICF file example in Defining an ICF file using
DDS shows how to code the name type.
