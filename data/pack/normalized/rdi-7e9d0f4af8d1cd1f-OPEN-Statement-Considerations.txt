OPEN Statement Considerations
The successful execution of an OPEN statement determines the availability
of the file and results in that file being in an open mode. The file is unavailable
if the OPEN operation fails. A file is available if it is physically present
and is recognized by the input-output control system. OPEN Statement Programming Notes shows
the results of opening available and unavailable files.
