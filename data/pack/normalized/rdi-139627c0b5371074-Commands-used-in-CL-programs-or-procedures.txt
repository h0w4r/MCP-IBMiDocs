Commands used in CL programs or procedures
A CL program or procedure contains only CL commands.
These can be IBM-supplied commands or commands defined by you.
You cannot use some IBM-supplied commands in CL programs
or procedures. Use the CL command finder or the online help to find CL command
descriptions and their applicability in CL programs or procedures.
Commands entered on the RQSDTA and CMD parametersCertain CL commands, such as Transfer Job (TFRJOB) and Submit
Job (SBMJOB), have the Request data or command (RQSDTA) or Command
(CMD) parameter that can use another CL command as the parameter
value. Commands that can only be used within CL programs and procedures cannot
be used as values on the RQSDTA or CMD parameter.
