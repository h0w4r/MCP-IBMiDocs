The <stdlib.h> include file also contains definitions
for the following macros:

NULL
The NULL pointer value.

EXIT_SUCCESS
Expands to 0; used by the atexit function.

EXIT_FAILURE
Expands to 8; used by the atexit function.

RAND_MAX
Expands to an integer that represents the largest number that
the rand function can return.

MB_CUR_MAX
Expands to an integral expression to represent the maximum number
of bytes in a multibyte character for the current locale.

For more information about NULL and the types size_t and wchar_t,
see <stddef.h>.
