The Work with Locations using BRM (WRKLOCBRM) command allows you to work with all storage locations. You can select a single location or all locations. Output can be a display or printed report. The report that is produced is the Storage Location report. The report is written to the printer file QP1ASL.

To use this command, you must have the Backup Recovery and Media Services for IBM i licensed program installed.

Top

Output (OUTPUT)

Specifies whether the output from the command is displayed at the requesting work station or printed with the job's spooled output.

*
The output is displayed (if requested by an interactive job) or printed (if requested by a batch job).

*PRINT
The output is printed with the job's spooled output.
