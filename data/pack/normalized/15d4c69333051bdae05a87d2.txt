The Configure TCP/IP LPD (CFGTCPLPD) command provides a single interface for configuring the attributes related to line printer daemon (LPD) and for running any other LPD-related configuration commands.

There are no parameters for this command.

Restrictions:

- You must have input/output system configuration (*IOSYSCFG) special authority to use this command.
