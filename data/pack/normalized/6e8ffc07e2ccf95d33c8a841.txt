LOG
The LOG function returns a numeric value that approximates the logarithm
to the base e (natural log) of the argument specified.
The function type is numeric.

Format

>>-FUNCTION LOG--(--argument-1--)------------------------------><

argument-1
Must be class numeric. The value of argument-1 must be greater than
zero.

The returned value is the approximation of the logarithm to the base e of argument-1.
