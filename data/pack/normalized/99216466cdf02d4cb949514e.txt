Cancel Handler Reason Codes
The following table lists the bits that are set in the reason code.
If the activation group is to be stopped, then the activation
group is stopped bit is also set in the reason code. These bits
must be correlated to _CNL_MASK_T in _CNL_Hndlr_Parms_T
in <except.h>. Column 2 contains the macro constant defined for
the cancel reason mask in <except.h>.

This API is only used during exception

is not possible, or at least the behavior would be undefined if control
was resumed in them. Also, these invocations have had a chance to
handle the exception but did not do so. Invocations canceled by this
API are done with reason code of abnormal.
