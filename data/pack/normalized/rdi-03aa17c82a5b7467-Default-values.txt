Default values
If you are defining an optional parameter, you can define a value
on the DFT parameter to be used if the user does not enter the parameter value
on the command.
This value is called a default value. The default value must
meet all the value requirements for that parameter (such as type, length,
and special values). If you do not specify a default value for an optional
parameter, the following default values are used.
