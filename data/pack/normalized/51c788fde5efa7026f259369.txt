SYSPARTITIONINDEXDISK
The SYSPARTITIONINDEXDISK view contains one row for every
disk unit used to store the index data of every table partition or
table member. If the index is a distributed index, the partitions
that reside on other database nodes are not contained in this catalog
view. They are contained in the catalog views of the other database
nodes.
