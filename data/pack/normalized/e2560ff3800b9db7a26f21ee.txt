Sorting using part of the array as a key

You can use the OVERLAY keyword to overlay one array over another.
For example, you can have a base array which contains names and salaries
and two overlay arrays (one for the names and one for the salaries).
You could then sort the base array by either name or salary by sorting
on the appropriate overlay array.
