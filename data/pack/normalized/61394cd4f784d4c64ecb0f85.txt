Control Language Command Options
The following pages describe the keywords for the CRTCMOD, CRTCPPMOD,
CRTBNDC, and CRTBNDCPP commands. In most cases the keywords are identical
for any of the commands. Differences are noted where they exist.
The term object is used throughout the descriptions and has one
of two meanings:

If you are using the CRTCMOD or CRTCPPMOD commands, object means
module object.
If you are using the CRTBNDC or CRTBNDCPP commands, object means
program object.
