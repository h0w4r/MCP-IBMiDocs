Preprocessor Output
If you specify SRCSTMF with OPTION(*PPONLY), then the
preprocessor writes a stream file to the current directory with the new
extension .i. For example, if you specify
SRCSTMF('/home/MOE/mainprogram.c') with
OPTION(*PPONLY), then the preprocessor writes output to the current
directory as a stream file called mainprogram.i. For
this to happen, you need *RW authority to the current
directory.
