The Remove Protocol Table Entry (RMVPCLTBLE) command is used to remove a protocol entry from the protocol table. The protocol table is used to manage a list of protocols used in the Internet.

Restrictions:

- You must have input/output system configuration (*IOSYSCFG) special authority to run this command.

Parameters

Keyword | Description | Choices | Notes
PROTOCOL | Protocol | Character value | Required, Positional 1

Top

Protocol (PROTOCOL)

Specifies the name of the protocol entry to be removed.

Top

Examples

RMVPCLTBLE PROTOCOL(TCP)

This command removes the TCP protocol entry from the protocol table.
