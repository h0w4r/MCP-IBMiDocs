Data type (position 35)

You can use any of the four DBCS data types: J (Only), E (Either),
O (Open) and G (Graphic).

J (Only)

Fields can contain only DBCS data.

E (Either)

Fields can contain either DBCS or alphanumeric data.

O (Open)

Fields can contain both DBCS and alphanumeric data. Distinguish DBCS data
from alphanumeric data with shift-control characters.

G (Graphic)

Fields can contain only DBCS data with no shift-control characters.
