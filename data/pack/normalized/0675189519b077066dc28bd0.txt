Displaying a library list
The Display Library List (DSPLIBL) command
displays the library list for a job that is currently running.
The display contains a list of all the libraries in the library
list in the same order that they appear in the library list.
You can
also display the library list for an active job using the Display
Job (DSPJOB) command and selecting option 13 from the Display Job
menu.
