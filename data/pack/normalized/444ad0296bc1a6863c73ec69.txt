Example of Using a Direct Monitor Handler and Signal Handler Together
The following example shows you how to use the #pragma
exception_handler directive and the signal() function together. This example also shows how an exception
is handled using SIGIO. An end-of-file message is mapped to
SIGIO. The default for SIGIO is SIG_IGN. It also shows that
when both a HLL-specific handler and direct monitor handler are defined, the
direct monitor handler is called first.
This example uses the source shown in Figure 171.

To create the program T1520ICA, enter:

CRTBNDC PGM(MYLIB/T1520ICA) SRCFILE(QCPPLE/QACSRC)

To run the program T1520ICA, enter:

CALL PGM(MYLIB/T1520ICA)
