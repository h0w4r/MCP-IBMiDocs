DELETE Statement Considerations
The action of this statement can be inhibited at program run time by the
inhibit write (INHWRT) parameter of the Override with Database File (OVRDBF)
CL command. When this parameter is specified, non-zero file status codes are
not set for data dependent errors. Duplicate key and data conversion errors
are examples of data dependent errors. For more information on the OVRDBF
command, see the CL and APIs section of the Programming category in the IBM® i
Information Center at this Web site - http://www.ibm.com/systems/i/infocenter/.
