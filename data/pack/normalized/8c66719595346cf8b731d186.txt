End Device Recovery (ENDDEVRCY)

End Device Recovery (ENDDEVRCY)

Last Updated: 2025-04-08

Where allowed to run: All environments (*ALL)

Threadsafe: No | Parameters

Examples

Error messages

The End Device Recovery (ENDDEVRCY) command ends automatic error recovery procedures for a specific device. If any type of failure occurs after this command is run, an inquiry message is sent to the system operator. The user must have object operational authority for the device.

Use the Resume Device Recovery (RSMDEVRCY) command to reestablish error recovery procedures for the device.

Parameters

Keyword | Description | Choices | Notes
DEV | Device | Name | Required, Positional 1

Top

Device (DEV)

Specifies the device whose recovery is to be ended. Specify the name specified for the device in the device description.

Top

Examples

ENDDEVRCY DEV(WSPR03)

This command ends error recovery procedures for the device WSPR03.
