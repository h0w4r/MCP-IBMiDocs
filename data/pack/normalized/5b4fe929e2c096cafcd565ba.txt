Positions 7-16 (File Name)

Entry
Explanation

A valid file name

Same file name that appears on the file description specifications
for the output file.

Specify the file name on the first line that defines an output
record for the file. The file name specified must be the same file
name assigned to the output, update, or combined file on the file
description specifications. If records from files are interspersed
on the output specifications, the file name must be specified each
time the file changes.

For files specified as output, update, combined or input with ADD,
at least one output specification is required unless an explicit file
operation code with a data structure name specified in the result
field is used in the calculations. For example, a WRITE operation
does not require output specifications.
