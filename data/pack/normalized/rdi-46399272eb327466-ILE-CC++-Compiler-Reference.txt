implementation

implementation syntax

>>-#--pragma--implementation--(--string_literal--)-------------><

Description
The #pragma implementation directive tells the compiler
the name of the file containing the function-template definitions
that correspond to the template declarations in the include file which
contains the pragma. This pragma can appear anywhere that a declaration
is allowed. It is used when organizing your program for the efficient
or automatic generation of template functions.
