Multi-file Processing with No Match Fields

When no match fields are used in multi-file processing, records
are selected from one file at a time. When the records from one file
are all processed, the records from the next file are selected. The
files are selected in this order:

Primary file, if specified

Secondary files in the order in which they are described on the
file description specifications.
