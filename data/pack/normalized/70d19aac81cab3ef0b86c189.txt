Example: Adding an OPM Program to an ILE Debug Session
This example shows you how to allow the ILE source debugger to add an OPM
program to an ILE debug session.
Suppose you are in a debug session working with an ILE program and you
decide you should also debug an OPM program that has debug data
available. To enable the ILE source debugger to accept OPM programs,
follow these steps:

If, after you enter STRDBG, the current display is not the Display Module
Source display, enter:

DSPMODSRC

The Display Module Source display appears
Enter

SET

When the Set Debug Options display appears, type Y (Yes) for
the OPM source debug support field, and press Enter to return to the Display
Module Source display.

You can now add the OPM program, either by using the Work with Module
display, or by processing a call statement to that program.
