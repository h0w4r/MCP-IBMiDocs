Using the Register Storage Class

Use the Register Storage classfor a variable that is frequently used.
Do not overuse the Register Storage class, so that the optimizer can place the
most frequently used variables into the available hardware registers.
If you use the Register Storage class, you cannot rely on the value
displayed from within the debugger because you may be referencing an older
value that is still in storage.
