ILE Activation Group

Figure 52. ILE Activation Group of the Sample Application

When the CL Command program calls the CL program, all the resources
necessary to run these programs are allocated in the default activation
group.
When the CL program calls the ILE C program, a new activation group is
started, as shown in Figure 52, because the ILE C program is created with the ACTGRP(*NEW)
parameter. The ILE C service programs are also activated in this new
activation group because they are created with the ACTGRP(*CALLER)
parameter.
In other words, the ILE C program and ILE C service programs are activated
within one activation group because the programs are developed as one
cooperative application.
Note:To isolate programs from other programs running in the same job you can
select different activation groups. For example, a complete customer
solution may be provided by integrating software packages from four different
vendors. Different activation groups ease the integration by isolating
the resources associated with each vendor package.
