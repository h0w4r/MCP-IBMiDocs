VALUE
The VALUE function returns the value of the first non-null expression.
VALUE(expression,expression)
The VALUE function is identical to the COALESCE scalar function.
For more information, see COALESCE.
NoteSyntax alternatives: COALESCE
should be used for conformance to the SQL 2003 standard.
