WEAKTMPL

Specifies whether weak definitions are used for
static members of a template class. Weakly defined static members
of a template class will prevent the collisions of multiple definitions
in a program or service program.

WEAKTMPL Syntax:

|--+------------------------+-----------------------------------|
| .-*YES-. |
'-WEAKTMPL(--+-*NO--+--)-'

The possible options are:

*YES
Default setting. Weak definitions will be used for static members
of a template class.

*NO
Weak definitions will not be used for static members of a template
class.

Some programs require strong static data members when they are
linked to other modules. You can override the default only at compilation
time.
