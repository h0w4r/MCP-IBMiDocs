The Configure TCP/IP (CFGTCP) command is used to display a menu that allows a user to define or change the Transmission Control Protocol/Internet Protocol (TCP/IP) configuration.

Restrictions:

- You must have input/output system configuration (*IOSYSCFG) special authority or have access to the QIBM_IOSYSCFG_VIEW function usage identifier to run this command.
