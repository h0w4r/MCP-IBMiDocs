Retrieving a data area
You can retrieve a data area and copy it to a
variable by using the Retrieve Data Area (RTVDTAARA) command.
The Retrieve Data Area (RTVDTAARA) command
retrieves all or part of a specified data area and copies it into a CL variable.
The data area does not need to exist at compilation time, and the CL variable
need not have the same name as the data area. Note that this command retrieves,
but does not alter, the contents of the specified data area.
