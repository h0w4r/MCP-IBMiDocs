DATA RECORDS Clause
The DATA RECORDS clause is syntax checked and it serves only as documentation
for the names of data records associated with this file.

DATA RECORDS Clause - Format

    .-------------.   
    (1) V |   
>>-DATA------+-RECORD--+----+---+----data-name-2-+-------------><
    | '-IS-' |    
    '-RECORDS--+-----+-'    
    '-ARE-'    

Notes:Syntax-checked only.data-name-2
The names of record description entries associated with this file. Data-name-2 must not be a
type-name.

The specification of more than one data-name indicates that this file contains
more than one type of data record. Two or more record descriptions for this
file occupy the same storage area. These records need not have the same description
or length. The order in which the data-names are listed is not significant.
