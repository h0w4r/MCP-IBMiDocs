%DECH (Convert to Packed Decimal Format with Half Adjust)

%DECH(numeric or character expression :precision:decimal places )
%DECH is the same as %DEC except that if the expression
is a decimal or float value, half adjust is applied to the value of
the expression when converting to the desired precision. No message
is issued if half adjust cannot be performed..

Unlike, %DEC, all three parameters are required.

For more information, see Conversion Operations or Built-in Functions.
