Using Unicode Support for Wide-Character Literals

Using Unicode character storage permits processing of characters in multiple
character sets without loss of data integrity. Wide-character literals
and strings can be stored as UCS-2 characters (Unicode CCSID 13488), which
minimizes the need for code page conversions when developing applications for
international use. The ILE C/C++ compiler supports Unicode character
storage.
