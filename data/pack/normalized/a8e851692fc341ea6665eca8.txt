VRYCFG command changes

Last Updated: 2025-10-07

Parameter changes for the Vary configuration VRYCFG
command

The (CFGTYPE) parameter no longer supports the *NWI - Network Interface
Descriptions value.

The (CFGOBJ) parameter no longer supports the *ANYNW - All controller
descriptions that specify a link type of *ANYNW value.
