Reclaim Library (RCLLIB)

Where allowed to run: All environments (*ALL)

Threadsafe: No | Parameters

The Reclaim Library (RCLLIB) command rebuilds the internal objects of a library that contain the object descriptive information for all objects in the library and the library object itself.

This command rebuilds, where possible, internal objects of the library that were damaged or destroyed.

Restrictions:

- You must have object existence (*OBJEXIST) and use (*USE) authorities for the library to be rebuilt. This is the same authority required to delete a library with the Delete Library (DLTLIB) command.

- Only the internal objects of a library which contain the object descriptive information are rebuilt. No other objects in the library are validated or rebuilt.

- This command can be used on any library other than QTEMP.
