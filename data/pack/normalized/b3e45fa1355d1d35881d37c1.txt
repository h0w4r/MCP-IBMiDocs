Last Updated: 2025-04-08

Where allowed to run: All environments (*ALL)

Threadsafe: No | Parameters

Examples

Error messages

The Delete Network Server Storage Space (DLTNWSSTG) command deletes an existing network server storage space.

A storage space cannot be deleted if it is linked to a network server description. Before you can delete a linked storage space, the link must be removed by using the Remove Network Server Storage Link (RMVNWSSTGL) command.
