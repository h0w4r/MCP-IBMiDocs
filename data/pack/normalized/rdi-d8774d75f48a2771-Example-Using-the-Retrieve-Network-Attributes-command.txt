Example: Using the Retrieve Network Attributes command
This example shows how to retrieve network attributes by using
the Retrieve Network Attributes (RTVNETA) command.
In the following example, the default network output queue and
the library that contains it are retrieved, changed to QGPL/QPRINT, and later
changed back to the previous value.
PGM
DCL VAR(&OUTQNAME) TYPE(*CHAR) LEN(10)
DCL VAR(&OUTQLIB) TYPE(*CHAR) LEN(10)
RTVNETA OUTQ(&OUTQNAME) OUTQLIB(&OUTQLIB)
CHGNETA OUTQ(QGPL/QPRINT)
.
.
.
CHGNETA OUTQ(&OUTQLIB/&OUTQNAME)
ENDPGM
