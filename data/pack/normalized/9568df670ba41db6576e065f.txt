DISPLAY Phrase
The data item is stored in character form, 1 character for each 8-bit byte.
This corresponds to the format used for printed output. DISPLAY can be explicit
or implicit.
USAGE IS DISPLAY is valid for the following types of items:
Alphabetic
Alphanumeric
Alphanumeric-edited
Numeric-edited
External decimal (numeric)
