Prerequisites for using data queues
Before using a data queue, you must first create it using the Create
Data Queue (CRTDTAQ) command.
The following is an example:
CRTDTAQ DTAQ(MYLIB/INPUT) MAXLEN(128)
TEXT('Sample data queue')
The required MAXLEN parameter specifies the maximum length
(1 to 64 512 characters) of the entries that are sent to the data queue.
