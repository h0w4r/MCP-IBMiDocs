Date values
A date value is a character string that represents
a date.
A date value's format is specified by the system value QDATFMT.
The length of the date value varies with the format used and whether a separator
character is used. For example, if no separator character is used, the length
of a date in a Julian format is five characters, and the length of a date
in a non-Julian format is six characters. If a separator character is used,
the length will be greater.
The system value QDATSEP specifies the optional
separator character that can be used when the date is entered. If a separator
character is used, the date must be enclosed in single quotation marks.
A
date value can be specified for the parameters of type *DATE. A year value
equal to or greater than 40 indicates a year from 1940 through 1999. A year
value less than 40 indicates a year from 2000 through 2039.
