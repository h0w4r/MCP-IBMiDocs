CL command help
All CL commands have online help
available.
Online help contains the parameter and value descriptions for the command.
To display help for a command, do one of the following:
From an i5/OS® command
line, type the command name (for example, CRTUSRPRF) and press F1. The display
shows general help for the command and help for each command parameter.
From an i5/OS command
line, type the command name (for example, CRTUSRPRF) and press F4 to display
the command prompt display. On the prompt display, move the cursor to the
top line and press F1.
