SYSPARTITIONSTAT
The SYSPARTITIONSTAT view contains one row for every table
partition or table member. If the table is a distributed table, the
partitions that reside on other database nodes are not contained in
this catalog view. They are contained in the catalog views of the
other database nodes.
The following table describes the columns in the SYSPARTITIONSTAT
view:
