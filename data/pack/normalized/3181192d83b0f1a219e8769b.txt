Extending the file boundary
After file creation time, the size of a file can be extended. If a file
status 0Q is received for a file, you may need to add more records to the
file before processing it. You can use the INZPFM (Initialize Physical File
Member) command to add deleted records to the file.
For example, suppose you create a file of 10 000 records with 3 increments
of 1 000 records each:
You initialize the (first 10 000) records.
You realize you need to store more data. So, you run the INZPFM command
with the RECORDS(*DLT) option again, until you have all 13 000 records
initialized.
You receive a requirement to store even more data - but you have already
used up all 13 000 records! If you run the INZPFM command again, you will
receive an interactive error message (of severity 99) prompting you either
to
Cancel the INZPFM request
Go ahead with the request (say, initialize another 1 000 records).

If you choose the second option in the previous step, you now have 14 000
initialized records. You have thus increased the size of the file past the
previously defined maximum.
