Including Database Files in the Type Definition
Input and output buffers for database files have the same format.
When you specify input, the fields that are defined as either INPUT or BOTH in
the externally described database file are included in the type
definition. When you specify both, the fields that are defined as
either INPUT, OUTPUT, or BOTH are included in the type definition.
If all the fields are defined as BOTH or INPUT, only one type definition
structure is generated in the type definition.
