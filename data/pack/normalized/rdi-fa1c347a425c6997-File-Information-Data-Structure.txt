File Information Data Structure

You can specify a file information data structure (defined
by the keyword INFDS on a file description
specifications) for each file in the program. This provides you with
status information on the file exception/error that occurred. A file
information data structure can be used for only one file. A file information
data structure contains predefined subfields that provide information
on the file exception/error that occurred. For a discussion of file
information data structures and their subfields, see File Information Data Structure.
