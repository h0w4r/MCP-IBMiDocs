PROCESS_ID
This global variable contains the process ID of the current
job.
This global variable has the following characteristics:It is read-only, with values maintained by system.
The type is INTEGER.
The schema is QSYS2.
The scope of this global variable is session.

ExampleReview the details for this job.SELECT USER, CURRENT SERVER, QSYS2.JOB_NAME, QSYS2.PROCESS_ID, QSYS2.THREAD_ID
FROM SYSIBM.SYSDUMMY1
