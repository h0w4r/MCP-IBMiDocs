File Inclusions

In ILE C++:

The include file name must be a valid workstation file name, for example
"file_name" or <file_name>.
Include files cannot reference *LIBL or *CURLIB
values.

You can use these values in ILE C include names. For example,
("*LIBL/ABC", *LIBL/ABC/*All)"...).
