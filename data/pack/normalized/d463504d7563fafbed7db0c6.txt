Job log message filtering
Message filtering is the process of removing messages
from the job log based on the message logging level set for the job.
Before each new request is received by a request processing program, message
filtering occurs.
Filtering does not occur after every CL command is called within a program.
Therefore, if a CL program is run interactively or submitted to batch, the
filtering runs once after the program ends because the program is not a request
processor.
Note: Since *NOLIST specifies that no job log is spooled for jobs that end
normally, it is a waste of system resource in batch jobs to remove the messages
from this log by specifying log level 0.
