The Work with Auxiliary Storage Pool Copy Descriptions (WRKASPCPYD) command displays a panel of existing auxiliary storage pool (ASP) copy descriptions and identifies any copy sessions they may have.

Restrictions:

- You must have input/output system configuration (*IOSYSCFG) special authority to use this command.

- You must have use (*USE) authority to the ASP device descriptions that are displayed.

Examples for WRKASPCPYD

Example 1: Work with All ASP Copy Descriptions in Current Device Domain

WRKASPCPYD

This command displays all ASP copy descriptions in the current device domain in the cluster.

Example 2: Work with All ASP Copy Descriptions in the device domain named MYDMN

WRKASPCPYD DEVDMN(MYDMN)

This command displays all ASP copy descriptions in the device domain named MYDMN.

Example 3: Work with a Specific ASP Copy Description in Current Device Domain

WRKASPCPYD ASPCPY(ORDER)

This command displays the ASP copy description named ORDER in the device domain the current node is in.

Example 4: Work with Specific ASP Copy Description in a Named Device Domain

WRKASPCPYD ASPCPY(ORDER) DEVDMN(MYDMN)

This command displays the ASP copy description named ORDER in the device domain named MYDMN.
