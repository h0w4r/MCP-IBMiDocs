PI
Returns the value of π 3.141592653589793. There are no
arguments.
PI()
The result of the function is double-precision floating-point.
The result cannot be null.
ExampleThe following returns the circumference of a circle with diameter
10:   SELECT PI()*10
    FROM SYSIBM.SYSDUMMY1
