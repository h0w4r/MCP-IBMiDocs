Qualification of unqualified object names
Unqualified object names are implicitly qualified. The rules for
qualifying a name differ depending on the type of object that the name identifies.

Unqualified alias, constraint, external program, index, mask, nodegroup, package, permission, sequence, table, trigger, view, and XSR object names
Unqualified alias, constraint, external program,
index, mask, nodegroup, package, permission, sequence, table, trigger,
view, and XSR object names are implicitly qualified by the default
schema.
Unqualified function, procedure, specific name, type, and variables
The qualification of function, procedure, specific
name, type (built-in types, distinct types, and array types), and
variables, depends on the SQL statement in which the unqualified name
appears.
