CRT Status Key 1
The first two bytes of data-name-2 form CRT Status Key 1 and should be
described as PIC 99. It indicates the condition that caused the termination
of the ACCEPT operation. The possible values are:
0
Indicates a terminating key such as an enter key, or an auto skip from
the final field
1
Indicates a function key
9
Indicates an error

If the ACCEPT statement contains an ON EXCEPTION phrase, any value in CRT
Status Key 1, except 0, will cause the execution of the imperative statement
in the ON EXCEPTION phrase.
