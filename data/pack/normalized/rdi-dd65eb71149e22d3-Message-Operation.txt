Message Operation

The message operations are

DSPLY (Display Message)
DSPLY allows interactive communication between the program and the operator or
between the program and the display workstation that requested the program.

SND-MSG (Send a Message to the Joblog)
SND-MSG sends an informational message or an exception message to the joblog.
