Floating-Point Fields
A file can contain internal floating-point fields. If the *NOFLOAT value
of the CVTOPT parameter (the default) is in effect, then the floating-point
fields are brought in as FILLER items with a USAGE of BINARY. If *FLOAT is
specified, the fields are brought in using their given DDS names with a USAGE
of COMP-1 (single precision floating-point) or COMP-2 (double precision floating-point).
Floating-point key fields are allowed. If the KEY is an internal floating-point number, the sequence
of key values will be in numeric order. If the KEY is an external floating-point
number, the key is alphanumeric, and the sequence of the records depends on
the collating sequence used.
