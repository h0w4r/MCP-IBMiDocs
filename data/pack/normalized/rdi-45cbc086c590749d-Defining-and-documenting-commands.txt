Defining and documenting commands
This information helps you define your own commands
and provide documentation for them.

Defining commands
CL commands enable you to request a broad range
of functions. You can use IBM-supplied commands, change the default values
for command parameters, and define your own commands.
Documenting command
If you define and create your own
CL commands, you can also create online command help to describe your commands.
Proxy commands
Proxy commands are used to create shortcuts to target commands.
