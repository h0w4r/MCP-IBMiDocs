SQRT
The SQRT function returns a numeric value that approximates the square
root of the argument specified.
The function type is numeric.

Format

>>-FUNCTION SQRT--(--argument-1--)-----------------------------><

argument-1
Must be class numeric. The value of argument-1 must be zero or positive.

The returned value is the absolute value of the approximation of the square
root of argument-1.
