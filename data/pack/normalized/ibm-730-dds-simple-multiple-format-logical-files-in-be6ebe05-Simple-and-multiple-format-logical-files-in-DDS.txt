Simple- and multiple-format logical files in DDS

Simple- and multiple-format logical files in DDSLast Updated: 2025-10-07

You must specify the PFILE keyword at the record
level for simple- and multiple-format logical files. In a multiple-format
logical file, a record format can use only the fields common to all the physical
files specified on the PFILE keyword for that record format.

Specify the entries in the following order to define
a simple- or multiple-format logical file:

Optional: File-level entries
Record-level entries
Optional: Field-level entries
Optional: Key field-level entries
Optional: Select/omit field-level
entries

Repeat steps 2 through 5 for each record format in the file.
The following example shows the code for a multiple-format logical
file.
