LABEL RECORDS Clause
The LABEL RECORDS clause indicates the presence or absence of labels. This
clause is only significant for FD - Format 3 (TAPEFILE). For all
other FD formats, this clause is syntax checked only, then treated as documentation.

LABEL RECORDS Clause - Format

    (1)    
>>-LABEL------+-RECORD--+----+---+--+-STANDARD-+---------------><
    | '-IS-' | '-OMITTED--'   
    '-RECORDS--+-----+-'    
    '-ARE-'    

Notes:Syntax-checked only.If it is not specified for a file, label records for that file must conform
to the system label specifications.
STANDARD
Labels conforming to system specifications exist for this file.
OMITTED
No labels exist for this file.
