Positions 18-20 (Record Addition/Deletion)

Entry
Explanation

ADD

Add a record to the file or subfile.

DEL

Delete the last record read from the file. The deleted record
cannot be retrieved; the record is deleted from the system.

An entry of ADD is valid for input, output, or update files. DEL
is valid for update DISK files only. When ADD is specified, there
must be an A in position 20 of the corresponding file-description
specification.

If positions 18-20 are blank, then for an output file, the record
will be added; for an update file, the record is updated.

The Record-Addition/Deletion entry must appear on the same line
that contains the record type (H, D, T, E) specification (position
17). If an AND/OR line is used following an ADD or DEL entry, this
entry applies to the AND/OR line also.
