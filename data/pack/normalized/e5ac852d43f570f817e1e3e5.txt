Sorting Arrays

You can sort an array or a section of an array using
the SORTA (Sort an Array) operation code. The array is sorted into
sequence (ascending or descending), depending on the sequence specified
for the array on the definition specification. If no sequence is specified
for the array, the sequence defaults to ascending sequence, but you
can sort in descending sequence by specifying the 'D' operation extender.
