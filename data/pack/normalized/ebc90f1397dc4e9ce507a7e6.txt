Positions 26-35 (Operation and Extender)

Positions 26 through 35 specify the kind of operation to be done using
factor 1, factor 2, and the result field entries. The operation code must
begin in position 26. For further information on the operation codes, see Operations and Operation Codes. For further information on the
operation code extenders, see Operation Extender.
