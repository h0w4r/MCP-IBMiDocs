Where allowed to run: All environments (*ALL)

Threadsafe: No | Parameters

The Update Program Temporary Fix Information (UPDPTFINF) command updates PTF information for all PTF save files in library QGPL. This command only needs to be run during a complete system recovery after library QGPL has been restored.

Restrictions:

- This command is shipped with exclude (*EXCLUDE) public authority.
