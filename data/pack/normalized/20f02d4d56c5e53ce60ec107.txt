PRPCMT (Prepare for Commit) keyword for ICF files

You can use this record-level keyword
to request the remote program to prepare for a synchronization point.

An output operation with the PRPCMT keyword specified forces any
data in the output buffer to be sent.
This keyword has no parameters.
When
this operation does not complete, your program does not continue until a response
is received. The remote program must perform a commit or rollback operation
or issue a FAIL or EOS to indicate whether it is prepared to commit its protected
resources.
PRPCMT is only valid with a synchronization
level of *COMMIT specified on the EVOKE keyword.
The
only keywords that can be specified with the PRPCMT keyword are VARBUFMGT
and VARLEN.
Option indicators are valid for this keyword.

Example The following example shows how to specify
the PRPCMT keyword.
