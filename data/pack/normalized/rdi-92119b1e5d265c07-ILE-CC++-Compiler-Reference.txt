noinline (function)

noinline syntax

>>-#--pragma--noinline--(--function_name--)--------------------><

Description
Specifies that a function will not be inlined. The
settings on the INLINE compiler option will be ignored for this function_name.
Notes® on
Usage
The first pragma specified will be the one that is used. If #pragma
inline is specified for a function after #pragma noinline
has been specified for it, a warning will be issued to indicate that #pragma
noinline has already been specified for that function.
The #pragma noinline directive can only occur at
file scope. The pragma will be ignored, and a warning is issued if
it is not found at file scope.
