SYSTEM_USER
The SYSTEM_USER special register specifies the authorization ID
that connected to the current server. The data type of the special register
is VARCHAR(128).
ExampleSelect all notes from the IN_TRAY table
that the user placed there himself.
SELECT * FROM IN_TRAY
  WHERE SOURCE = SYSTEM_USER
