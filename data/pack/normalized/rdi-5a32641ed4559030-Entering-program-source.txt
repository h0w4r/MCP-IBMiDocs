Entering program source
The programmer menu can be used to enter program
source.
The programmer menu can be called directly by calling the QPGMMENU
program, or by using the Start Programmer Menu (STRPGMMNU) command.
You can use the command to specify in advance the defaults that you use with
the programmer menu. In addition, the STRPGMMNU command
also supports other options that can be used to tailor the use of the programmer
menu.

Using the Start Programmer Menu command
The Start Programmer Menu (STRPGMMNU) command
performs the same function as a call to QPGMMENU and fills in the standard
input fields.
