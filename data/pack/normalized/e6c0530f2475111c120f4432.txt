ILE C/C++ Compiler Reference

SRCMBR
Specifies the name of the member that contains the ILE C or C++
source code.

SRCMBR Syntax:

|--+------------------------------+-----------------------------|
| (2) |
| .-*PGM---------. |
| | (1) | |
| +-*MODULE------+ |
'-SRCMBR(--+--------------+--)-'
'-member-name--'

Notes:

Create Module command only
Create Bound Program command only

*MODULE
Valid only with the CRTCMOD or CRTCPPMOD
commands. The module name that is supplied on the MODULE parameter
is used as the source member name. This is the default when a member
name is not specified.

*PGM
Valid only with the CRTBNDC or CRTBNDCPP
commands. The program name that is supplied on the PGM parameter
is used as the source member name. This is the default when a member
name is not specified.

member-name
Enter the name of the member that contains the ILE C or C++
source code.
