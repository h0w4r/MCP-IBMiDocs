%ERROR (Return Error Condition)

%ERROR returns '1' if the most recent operation with extender 'E'
specified resulted in an error condition. This is the same as the
error indicator being set on for the operation. Before an operation
with extender 'E' specified begins, %ERROR is set to return '0' and
remains unchanged following the operation if no error occurs. All
operations that allow an error indicator can also set the %ERROR built-in
function. The CALLP operation can also set %ERROR.

For examples of the %ERROR built-in function, see Figure 1 and Figure 2.

For more information, see Result Operations or Built-in Functions.
