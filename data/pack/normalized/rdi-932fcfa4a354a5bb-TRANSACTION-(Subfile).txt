WRITE Statement - Format 5 - TRANSACTION (Subfile)

>>-WRITE SUBFILE--record-name-1--+--------------------+--------->
    '-FROM--identifier-1-'   

>--FORMAT--+----+--+-identifier-2-+----------------------------->
    '-IS-' '-literal-1----'   

>--+------------------------------------+----------------------->
   '-TERMINAL--+----+--+-identifier-3-+-'   
    '-IS-' '-literal-2----'    

>--+---------------------------------------+-------------------->
   '-+-INDICATOR--+--+-----+--identifier-4-'   
    +-INDICATORS-+ +-IS--+    
    '-INDIC------' '-ARE-'    

>--+------------------------------------------+----------------->
   '-INVALID--+-----+--imperative-statement-1-'   
    '-KEY-'    

>--+----------------------------------------------+------------->
   '-NOT INVALID--+-----+--imperative-statement-2-'   
    '-KEY-'    

>--+-----------+-----------------------------------------------><
   '-END-WRITE-'   

Format 5 can only be used for display devices. If the subfile form of the WRITE
statement is used for any other type of device, the WRITE operation fails
and a file status of 90 is set.
If the format is a subfile record and SUBFILE is specified, the RELATIVE
KEY clause must be specified on the SELECT clause for the file being written.
The record written to the subfile is the record in the subfile identified
by the format name that has a relative record number equal to the value of
the RELATIVE KEY data item.
