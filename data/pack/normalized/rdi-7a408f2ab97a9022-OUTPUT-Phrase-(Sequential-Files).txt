OUTPUT Phrase (Sequential Files)
The file is opened to allow only output operations. When the file is successfully
opened, it contains no records.
Under OPTION(*NOBLK), the compiler
generates code to block output records and unblock input records if the following
conditions are satisfied:
The file access is sequential.
The organization of the file is sequential and the file is open only for
input or output.
The file is assigned to DISK, DATABASE, DISKETTE, or TAPEFILE.

The BLOCK CONTAINS clause does not control the blocking factor for any
files except tape files.
Device type FORMATFILE and PRINTER can only be opened for output.
