Naming within commands
The type of name you specify in control language
(CL) determines the characters you can use to specify a name.
For certain types of names, there are restrictions on the use of certain
characters to represent the name. Those types of names are *NAME, *SNAME,
and *CNAME.
Note: For a description of how to specify these names when you use command
definitions to create commands, see the PARM (parameter) and ELEM (element)
statements in Defining a command.

Quotation marks can only be used for basic names (*NAME).
Both the first and last characters must be a quotation mark (").
