Unary minus operator -
The - (unary minus) operator negates the value of the
operand. The operand can have any arithmetic type. The result is not
an lvalue.
For example, if quality has the value 100, -quality has
the value -100.
The result has the same type as the operand after integral promotion.

Note:
Any minus sign in front of a constant is not part
of the constant.
