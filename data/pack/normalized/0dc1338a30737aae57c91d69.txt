How Overflows Are Handled
Table 28 describes the overflow behavior when a _DecimalT
class template is assigned to a smaller target.
An exception is generated when a _DecimalT class template is
assigned to a _Decimal class template with a smaller target.
An exception is not generated when:

A _DecimalT class template is assigned to a char,
int, short, long, or bit field
with a smaller target
A _DecimalT class template is assigned to a floating point with
a smaller target
