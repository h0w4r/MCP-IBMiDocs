<wchar.h>
The <wchar.h> header file contains declarations and
definitions that are related to the manipulation of wide character
strings. Any functions which deal with files are accessible if SYSIFCOPT(*IFSIO)
is specified.

<wchar.h> also defines the macro NULL
and the types size_t and wchar_t.
For more information about NULL and the
types size_t and wchar_t, see <stddef.h>.
