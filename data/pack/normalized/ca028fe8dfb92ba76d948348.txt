However, the following steps can be used as a reference to install DS CLI on an IBM i node:

- Sign on to your DS8000 and run command
ver to find the version of your storage server.Figure 1. DS8000 version

The screen image above shows what the command output text will look like. Download
the matching version of DSCLI from the following link: https://www-945.ibm.com/support/fixcentral/. Type DS8 in the product
selector and select your DS8000 product.

- Reference the following support document for install steps “How to Install DSCLI for IBM i”: http://www-01.ibm.com/support/docview.wss?uid=nas8N1022421.
