Specifying the Teraspace Environment
The Storage Model (STGMDL) compiler option determines the teraspace
environment for the entire program.
The Data Model (DTAMDL) compiler option determines the pointer size
declaration for the applicable module. To use the 8-byte run-time
libraries, specify DTAMDL(*LLP64).
To override the effect of the default Data Model (DTAMDL) setting for a
section of the source, you can use either DTAMDL(*LLP64) or the #pragma
datamodel directive. See Example: Effect of Forward Declarations on the Data Model and Example: How a Template Adopts a Data Model.
Note:The #pragma datamodel directive overrides the DTAMDL option
setting.

To override the section setting for a specific variable, specify an
attribute for the pointer. See Maintaining Consistent Argument Declarations and Examples: Overloading Functions.
