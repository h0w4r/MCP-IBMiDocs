Using command programs

Last Updated: 2025-10-07

You can automate the installation process by creating a
command ( .cmd ) file to run setup.exe with
predefined parameters. In this situation, users do not need to specify
options at the command prompt.

The .cmd file can include any of the
valid parameters for setup.exe that are listed in
the "Using command line parameters to change the install behavior"
topic.
