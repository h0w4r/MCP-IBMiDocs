Attribute
This part of assignment-name-1 or literal-1 can be SI or ALWNULL. SI
Indicates that a separate indicator
area has been specified in the DDS for a FORMATFILE or WORKSTATION
file.
ALWNULL
When ALWNULL is specified, the program can manipulate null-capable
fields in a database file. This keyword can only be used with device
type DATABASE.

See the IBM® Rational® Development Studio
for i: ILE COBOL Programmer's Guide for details on the use
of the SI or ALWNULL attribute and further information about the ASSIGN
clause.
