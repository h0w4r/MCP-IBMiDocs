I/O Considerations for Binary Stream Database and DDM Files
If the database file contains deleted records, the deleted records are
skipped by all binary stream I/O functions.
Binary stream record-at-a-time files cannot be processed by key. As
well, they can only be opened with the rb, wb, and
ab modes.
