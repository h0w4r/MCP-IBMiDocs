PASSRCD (Passed Record) keyword for display files

You use this file-level keyword to specify the
record format to be used by the IBM® i operating
system when another program passes unformatted data to your program.

The passed data is processed only if your program's first request
after file open is an input operation without a record format name. The data
must be processed according to this record format.
The format of the
keyword is: PASSRCD(record-format-name)
The
record-format-name is a required parameter value for this keyword and must
exist in the file. The following keywords cannot be specified on the record
format: ALWROL
CLRL
SLNO

Option indicators are not valid for this keyword.

the PASSRCD keyword.
