Secondary File

When more than one file is processed by the RPG cycle, the additional
files are specified as secondary files. Secondary files must be input
capable (input, update, or combined file type). The processing of
secondary files is determined by the order in which they are specified
in the file description specifications and by the rules of multi-file
logic.
