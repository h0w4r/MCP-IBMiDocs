FLOAT(bytes)

The FLOAT keyword is a numeric data type keyword.
It is used in a free-form definition to indicate that the item has float format.

It must be the first keyword.

The parameter specifies the length in bytes. It must be one of
4 or 8.

The parameter can be a literal or a named constant. If it is a
named constant, the constant must be defined prior to the definition
statement.

In the following example

field variance is defined as an
8-byte float field.

DCL-S variance FLOAT(8);
