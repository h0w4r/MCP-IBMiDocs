Accessing ILE C Procedures from Any ILE Program
ILE C programs are called by dynamic program calls, but the procedures
within an activated ILE C program are accessed by means of either of the
following:

Static procedure calls
Procedure pointer calls

Note:ILE C programs that have not been activated must be called
dynamically.
