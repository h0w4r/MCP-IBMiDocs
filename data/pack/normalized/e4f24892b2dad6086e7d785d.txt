Using F22 to Step into Programs
Use F22 (Step into) on the Display Module Source display to step into a
called program in a debug session. If the next statement to be run is a
Call (CALL) statement to another program, pressing F22 causes the first
executable statement in the called program to be run. The called
program is then shown in the Display Module Source display.
Note:The called program must have debug data associated with it in order for it to
be shown in the Display Module Source display.
