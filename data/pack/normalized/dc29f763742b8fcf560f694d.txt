Calls to SQLSetConnectAttr API may now return -1 with Message ID SQ99999

Calls to SQLSetConnectAttr API may now return -1 with Message ID SQ99999

Last Updated: 2025-10-07

A call to SQLSetConnectAttr API with a null or missing required parameter was
not flagged as an error until a subsequent call to SQLConnect. Now with IBM® i 7.3 PTF SI75162 or IBM
i 7.4 PTF SI75163, an error for an invalid parameter on the SQLSetConnectAttr API
will be flagged on that call.

Parameter validation will be done to flag empty mandatory fields on the call to
SQLSetConnectAttr. The new error shown for an invalid parameter on the
SQLSetConnectAttr API is SQ99999 with error code 9:
"Argument value not valid"

The previous error that would be issued from the SQLConnect call was
SQL0104: Token <END-OF-STATEMENT> was not valid. Valid tokens: ? : USER
CURRENT DEFAULT SYSTEM_USER.
