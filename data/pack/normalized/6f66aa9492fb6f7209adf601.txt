%LOWER (Convert to Lower Case)

%LOWER(string {: start { : length { : *NATURAL | *STDCHARSIZE } } })
%LOWER returns the string operand converted to lower case.

See %LOWER and %UPPER (Convert to Lower or Upper Case) for detailed information about both %LOWER and %UPPER.
