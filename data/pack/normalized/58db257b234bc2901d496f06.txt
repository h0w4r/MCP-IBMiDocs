CHANGE record-level keyword

You use this record-level keyword to indicate
that on an input operation, the record is to be returned to the
application program only if the user has changed the record.

If the user enters data into any input-capable field, all of the input-capable
fields in the record will be returned. If the user does not enter data into
any field, the input-capable fields will be returned initialized by the compiler.

This keyword has no parameters.

This format of the CHANGE keyword is allowed only in files containing the
USRDSPMGT keyword.

Option indicators are not allowed with this keyword.

For files that are used by the IBM® i operating
system applications (with or without the USRDSPMGT keyword), use the format
of the CHANGE keyword.
