TABLES
The TABLES view contains one row for each table, view,
and alias.
The following table describes the columns in the view:
Table 1. TABLES
viewColumn Name
Data Type
Description

TABLE_CATALOG
VARCHAR(128)
Relational database name

TABLE_SCHEMA
VARCHAR(128)
Name of the SQL schema that contains
the table, view or alias.

TABLE_NAME
VARCHAR(128)
Name of the table, view or alias.

TABLE_TYPE
VARCHAR(24)
Indicates the type of the table: ALIAS
The table is an alias.
BASE TABLE
The table is an SQL table or physical file.
MATERIALIZED QUERY TABLE
The object is a materialized query table.
VIEW
The table is an SQL view or logical file.

YES
