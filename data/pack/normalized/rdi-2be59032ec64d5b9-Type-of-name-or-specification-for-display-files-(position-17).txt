Type of name or specification for display files (position 17)

You can specify a value in this position to identify the type of
name in positions 19 through 28.

The valid entries for display files are:

Entry
Meaning

R

Record format name

H

Help specification

Blank

Field name

The example in Defining a display file for DDS shows
how to code the name type.
