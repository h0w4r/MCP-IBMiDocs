AUTHORIZATIONS
The AUTHORIZATIONS view contains one row for every authorization
ID.
The following table describes the columns in the view:
Table 1. AUTHORIZATIONS
viewColumn Name
Data Type
Description

AUTHORIZATION_NAME
VARCHAR(128)
Authorization ID name

AUTHORIZATION_TYPE
VARCHAR(4)
The type of authorization ID. Contains
'USER'.

AUTHORIZATION_ATTR
VARCHAR(5)
The type of user profile. Contains
'USER' or ’GROUP’.

AUTHORIZATION_TEXT
VARCHAR(50)
The text description for the profile.
