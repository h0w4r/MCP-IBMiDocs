The Work with Document Libraries (WRKDOCLIB) command allows you to manage the Document Interchange Architecture (DIA) library services available on remote systems in the network. A document library name and level of DIA supported can be specified for each distribution queue with a Document Library Services (DLS) queue type.

There are no parameters for this command.
