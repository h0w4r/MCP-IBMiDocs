CCSIDs of Data

All character, graphic, and UCS-2 data has a Coded Character Set ID (CCSID)
that determines the meaning of the data.
For example, the data x'20' means "blank" in the UTF-8 CCSID 1208 while the
data x'40' means "blank" in the EBCDIC CCSID 37 and the value x'0020' means
"blank" in the UCS-2 CCSID 13488.

Data can be converted from one CCSID to another.
For example, if you assign a variable having EBCDIC data with CCSID 37
to a variable having UCS-2 CCSID 13488, the EBCDIC data must be converted
to CCSID 13488.
See CCSID definition keyword for detailed
information on the valid CCSIDs for each type.
