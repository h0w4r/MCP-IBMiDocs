SYSPROCS
The SYSPROCS view contains one row for each procedure created
by the CREATE PROCEDURE statement.
The following table describes the columns in the SYSPROCS
view:

EXTERNAL_NAME

VARCHAR(279) Nullable

This column identifies the external
program name. For ILE service programs, the external program name is schema-name/service-program-name(entry-point-name).
For REXX,

For Java™ programs, the external
program name is an optional jar-id followed by a fully-qualified-class-name!method-name or fully-qualified-class-name.method-name.
For all other languages, the external program name is schema-name/program-name.

IS_DETERMINISTIC

VARCHAR(3)
This column identifies whether the

YES

VARCHAR(8)

READS

MODIFIES
The routine possibly modifies data in a table or view or issues
SQL DDL statements.
