PACKAGE_SCHEMA
This global variable contains the schema name of the package currently being used for a DRDA® connection.
This global variable has the following characteristics:It is read-only, with values maintained by system.
The type is VARCHAR(128).
The schema is SYSIBM.
The scope of this global variable is session.

If there is no package currently executing, the value
is NULL.
