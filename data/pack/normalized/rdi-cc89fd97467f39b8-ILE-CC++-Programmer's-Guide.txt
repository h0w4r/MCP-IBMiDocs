Setting Unconditional Breakpoints from the Command Line

To set an unconditional breakpoint using the BREAK debug command, enter
BREAK line-number on the debug command line. The
variable line-number is the line number in the currently displayed
view of the module on which you want to set a breakpoint.
Note:To remove an unconditional breakpoint using the CLEAR debug command,
enter: CLEAR line-number on the debug command
line.
