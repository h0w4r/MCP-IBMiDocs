Position 44 (Edit Codes)

Entry
Explanation

Blank

No edit code is used.

1-9, A-D, J-Q, X, Y, Z

Numeric fields are zero-suppressed and punctuated according
to a predefined pattern without the use of edit words.

Edit Code Summary

Position 44 is used to specify edit codes that suppress leading
zeros in a numeric field or to punctuate a numeric field without using
an edit word. Allowable entries are 1 through 9, A through D, J through
Q, X, Y, Z, and blank.
Note: The entry must be blank if
you are writing a float output field.

For more information on edit codes see Editing Numeric Fields.

Edit codes 5 through 9 are user-defined edit codes and are defined
externally by an IBM® i function. The edit code is determined at compilation
time. Subsequent changes to a user-defined edit code will not affect
the editing by the RPG IV compiler unless the program is recompiled.
