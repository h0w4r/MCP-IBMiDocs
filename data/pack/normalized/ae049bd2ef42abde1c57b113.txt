TRANSACTION Files
Using extended ACCEPT/DISPLAY statements and TRANSACTION files in the same
program is not recommended. If extended ACCEPT/DISPLAY statements are used
in the same program as TRANSACTION files, then the TRANSACTION file should
be closed when the extended ACCEPT/DISPLAY statements are performed. Unpredictable
results will occur if an extended ACCEPT/DISPLAY statement is performed when
a TRANSACTION file is open. A severe error may be generated or data on the
workstation may be overlapped or intermixed.
