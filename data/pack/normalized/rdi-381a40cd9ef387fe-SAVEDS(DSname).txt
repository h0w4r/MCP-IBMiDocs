SAVEDS(DSname)

The SAVEDS keyword allows the specification of the data structure
saved and restored for each device. Before an input operation, the
data structure for the device operation is saved. After the input
operation, the data structure for the device associated with this
current input operation is restored. This data structure cannot be
a data area data structure, file information data structure, or program
status data structure, and it cannot contain a compile-time array
or prerun-time array.

If the SAVEDS keyword is not specified, no saving and restoring
is done. SAVEDS must not be specified for shared files.

When you specify SAVEDS but not MAXDEV, the ILE RPG program
assumes a multiple device file (MAXDEV with a parameter of *FILE).
