Linear Main Module

A module which has a program entry procedure but does not use the
RPG Program Cycle can be generated by specifying the MAIN keyword
on the control specification.

This type of module has one or more procedures, one of which is
identified as the main procedure. It does not allow specifications
which relate to the RPG Program Cycle.

See MAIN(main_procedure_name) for more information.
