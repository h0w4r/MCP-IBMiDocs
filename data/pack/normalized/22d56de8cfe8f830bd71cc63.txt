Creating a Listing View for Debugging

A listing view contains text similar to the text in the compiler
listing produced by the compiler. To create a listing view for
debugging, use the DBGVIEW(*LIST) option when you create the module
or program.
Notes:

The ILE C compiler creates the listing view by copying the lines in a section
of the listing into the module.

The ILE C++ compiler creates the listing view by copying the text of the
appropriate source files into the module.
The listing view is not linked to the source files upon which it
is based.

For example, to create a listing view to debug a program created from the
source file myfile.cpp, enter:
CRTBNDCPP MYFILE SRCSTMF('/home/myfile.cpp') DBGVIEW(*LIST)

Note:The maximum line length for a listing view is 255 characters.
