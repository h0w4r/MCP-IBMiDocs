Function specifiers
The available function specifiers for function definitions
are:

inline, which instructs the compiler to expand a function
definition at the point of a function call.

explicit,
which can only be used for member functions of classes, and is described
in The explicit specifier (C++ only)

virtual,
which can only be used for member functions of classes, and is described
in Virtual functions (C++ only)
