FTRANS{(*NONE | *SRC)}

The FTRANS keyword specifies whether file translation will occur. If specified,
optionally with *SRC, file translation will take place and the translate table
must be specified in the program. If not specified or specified with *NONE,
no file translation will take place and the translate table must not be present.
