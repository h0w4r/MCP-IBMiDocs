Using the C/C++ Signal Handler
HLL-specific handlers are the language features that are defined
for handling errors. The ILE C/C++ signal() function can be
used to handle exception messages.
iSeries system exceptions are mapped to C and C++ signals by the ILE C/C++
run-time environment. A signal handler determines the course of action
for a signal. You cannot register a signal handler in an activation
group that is different from the one you wish to call it from. If a
signal handler is in a different activation group from the occurrence of the
signal it is handling, the behavior is undefined.
