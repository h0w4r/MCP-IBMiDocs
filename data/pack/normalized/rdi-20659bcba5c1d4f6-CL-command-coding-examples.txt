CL command coding examples
The Examples section provides at least one coded example
for the command. Where necessary, several examples are provided for commands
with many parameters and several logical combinations.
For clarity, examples are coded in keyword form only. The same examples
could be coded either in positional form or in a combination of keyword and
positional forms, for commands that support one or more positional parameters.
