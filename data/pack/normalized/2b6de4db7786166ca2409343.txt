User Date Reserved Words

The user date reserved words (UDATE, *DATE, UDAY, *DAY, UMONTH,
*MONTH, UYEAR, *YEAR) allow the programmer to supply a date for the
program at run time. For more information on the user date reserved
words, see Rules for User Date.
