LOG10
The LOG10 function returns a numeric value that approximates the logarithm
to the base 10 of the argument specified.
The function type is numeric.

Format

>>-FUNCTION LOG10--(--argument-1--)----------------------------><

argument-1
Must be class numeric. The value of argument-1 must be greater than
zero.

The returned value is the approximation of the logarithm to the base 10
of argument-1.
