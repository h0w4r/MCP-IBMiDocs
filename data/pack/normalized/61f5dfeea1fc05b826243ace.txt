PERRCD(numeric_constant)

The PERRCD keyword allows you to specify the number of elements per record
for a compile-time or a prerun-time array or table. If the PERRCD keyword
is not specified, the number of elements per record defaults to one (1).

The numeric_constant parameter must be a value greater than 0 with no decimal
positions. It can be a numeric literal, a built-in function returning a numeric
value, or a numeric constant. If the parameter is a named constant,
it does not need to be defined prior to this specification.

The PERRCD keyword is valid only when the keyword FROMFILE, TOFILE, or
CTDATA is specified.
