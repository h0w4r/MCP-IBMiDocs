Stream Files
The ILE C/C++ compiler allows your program to process stream files as true
text or binary stream files (using the integrated file system enabled stream
I/O) or as simulated text and binary stream files (using the default data
management stream I/O).
When writing an application that uses stream files, for better performance,
it is recommended that the integrated file system be used instead of the
default C stream I/O which is mapped on top of the data management record
I/O.
