DDS-to-C/C++ Data Type Mapping
The following table shows DDS data types and the corresponding ILE C/C++ declarations
that are used to map fields from externally described files to your ILE C/C++ program.
The ILE C/C++ compiler creates fields in structure definitions based
on the DDS data types in the externally described file.
