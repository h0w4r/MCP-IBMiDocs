The Add Sphere of Control Entry (ADDSOCE) command allows a CL user or program to add advanced peer-to-peer (APPN) network node control points to the Alert Sphere of Control.

Top

Parameters

Keyword | Description | Choices | Notes
ENTRY | Entry | Values (up to 50 repetitions): Element list | Optional
Element 1: Network identifier | Communications name, *NETATR
Element 2: Control point | Communications name

Top

Entry (ENTRY)

Specifies the systems to add to the sphere of control. The systems are specified by network ID and control point name.

You can specify 50 values for this parameter.

Element 1: Network identifier

*NETATR
Use the NETID network attribute as the value of the Network ID. The NETID network attribute is the value that gets stored. *NETATR is not stored.

communications-name
Specify the network ID of the system you want to add to the sphere of control.

Element 2: Control point

communications-name
Specify the control point name of the system you want to add to the sphere of control.

Top

Examples

ADDSOCE ENTRY((*NETATR RCHSTR1) (*NETATR RCHSTR2))

This command adds two systems (RCHSTR1 and RCHSTR2) to the alert sphere of control.
