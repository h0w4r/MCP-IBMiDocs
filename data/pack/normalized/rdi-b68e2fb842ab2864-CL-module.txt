CL module
A module is the object that results from compiling
high-level language source statements using an Integrated Language Environment® (ILE) compiler.
A CL module is created by compiling CL source using the Create
CL Module (CRTCLMOD) command. A module must be bound into a program
to run.
A CL module consists of two parts: A user-written procedure and a program
entry procedure that is generated by the CL compiler. In other high-level
languages (HLLs) (for example, C), a single module can contain multiple user-written
procedures.
