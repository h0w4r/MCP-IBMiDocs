<xxdtaa.h>
The <xxdtaa.h> include file contains the
declarations for the data area interface functions QXXCHGDA, QXXRTVDA,
and the type _DTAA_NAME_T.
The definition of _DTAA_NAME_T is:
typedef struct _DTAA_NAME_T {
char dtaa_name[10];
char dtaa_lib[10];
}_DTAA_NAME_T;
