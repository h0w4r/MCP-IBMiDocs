Specifying the Files

File translation table records must be formatted as follows:

Record
Position

 
Entry

1-7

*EQUATE

8-10

Leave these positions blank.

11-80

Enter the name(s) of file(s) to be translated. If more than
one file is to be translated, the file names must be separated by
commas.

Additional file names are associated with the table until a file
name not followed by a comma is encountered. A file name cannot be
split between two records; a comma following a file name must be on
the same record as the file name. You can create only one file translation
table by using *EQUATE.
