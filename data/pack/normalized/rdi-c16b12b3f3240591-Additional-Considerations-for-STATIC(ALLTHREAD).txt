Additional Considerations for STATIC(*ALLTHREAD)

Null-capable fields: The internal variable used
to hold the null indicator for a STATIC(*ALLTHREAD) null-capable field will
also be defined as STATIC(*ALLTHREAD). A change to the value of the null indicator
for a variable by one thread will be visible to all threads. Access to the
null indicator value will not be synchronized.

Tables and Multiple-Occurrence Data Structures: The
|internal variable used to hold the current occurrence for a table or multiple-occurrence
data structure defined with STATIC(*ALLTHREAD) will be defined in thread-local
storage. Each thread will have its own instance of the current-occurrence
variable.
