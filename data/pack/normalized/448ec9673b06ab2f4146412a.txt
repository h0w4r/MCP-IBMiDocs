DDM Files
Distributed Data Management (DDM) allows you to access data that reside
on remote systems that support DDM. You can retrieve, add, update, or delete
data records in a file that resides on another system.
For more information about accessing remote files, refer to the DB2® for
i section of the Database and File Systems category in the IBM® i
Information Center at this Web site - http://www.ibm.com/systems/i/infocenter/.
