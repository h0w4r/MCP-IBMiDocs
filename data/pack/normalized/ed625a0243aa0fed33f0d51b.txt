SYSKEYCST
The SYSKEYCST view contains one or more rows for each UNIQUE
KEY, PRIMARY KEY, or FOREIGN KEY in the SQL schema. There is one row
for each column in every unique or primary key constraint and the
referencing columns of a referential constraint.
The following table describes the columns in the SYSKEYCST
