PRFDTA(a)
Specifies the program profiling data attribute for the module. Program
profiling is an advanced optimization technique used to reorder procedures
and code within the procedures based on statistical data (profiling data).
NOCOL indicates that this module is not
enabled to collect profiling data. This is the default.
COL indicates that this module is enabled to collect
profiling data.
