Abbreviations of CL commands and keywords
Most CL command names that are part of the i5/OS® operating system and other
licensed programs that run on the operating system follow a consistent
naming style.
The first three letters of the command name (known
as the command verb) represent the action that is being performed. The remaining
letters of the command name describe the object that is having the action
performed on it.
