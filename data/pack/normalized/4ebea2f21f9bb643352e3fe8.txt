The End Transform Manager (ENDTFMMGR) command is used to end any
Infoprint Server for iSeries transform manager server jobs that are
running in the QUSRWRK subsystem. If you are currently converting
any spool files when the ENDTFMMGR command is issued, the spool
files will be held on the output queue.

Restrictions:

- *JOBCTL special authority is required to run this command.
