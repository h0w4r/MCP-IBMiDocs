Program Initialization Parameter data area
A Program Initialization Parameter (PIP) data area (PDA) is created
for each prestart job when the job is started.
The object sub-type of the PDA is different than a regular
data area. The PDA can only be referred to by the special value name *PDA.
The size of the PDA is 2000 bytes but the number of parameters contained
in it is not restricted.
The RTVDTAARA, CHGDTAARA, and DSPDTAARA CL commands and the RTVDTAARA and
CHGDTAARA macro instructions support the special value *PDA for the data area
name parameter.
