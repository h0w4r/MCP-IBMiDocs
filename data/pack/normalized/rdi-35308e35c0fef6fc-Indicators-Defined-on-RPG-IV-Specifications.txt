Indicators Defined on RPG IV Specifications

You can specify the following indicators on the RPG IV specifications:

Overflow indicator (the OFLIND keyword
on the file description specifications).

Record identifying indicator (positions
21 and 22 of the input specifications).

Control level indicator (positions 63
and 64 of the input specifications).

Field indicator (positions 69 through
74 of the input specifications).

Resulting indicator (positions 71 through
76 of the calculation specifications).

*IN array, *IN(xx) array element or *INxx field (See Indicators Referred to As Data for a description of how an indicator is defined when
used with one of these reserved words.).

The defined indicator can then be used to condition operations
in the program.
