Example: Initial program for setup (programmer)
In this example, the test library is placed first on the library
list, an output queue is selected for a convenient printer, and the programmer
menu is displayed.
Note: By using the code example, you agree to the terms of the Code license and disclaimer information.
PGM
CHGLIBL LIBL(TESTLIB QGPL QTEMP)
CHGJOB OUTQ(WSPRTR)
TFRCTL QPGMMENU
ENDPGM
