Status messages
To send status messages from your CL procedure or program to the
external message queue (*EXT) for the job or to a call message queue, use
the Send Program Message (SNDPGMMSG) command.
When a status message is sent to a call message queue, the
receiving program or procedure can monitor for the arrival of the status message
and can handle the condition it describes. If the receiving program or procedure
does not monitor for the message, control returns to the sender to resume
processing.
Status messages are not included in the job log for a job.
