Managing Activation Groups
Activation groups make it possible for multiple ILE programs to run in the
same job independently, without intruding on each other.
An activation group is a substructure of a job. It consists of
system resources such as storage, commitment definitions, and open
files. These resources are allocated to run one or more ILE or OPM
programs. For example, the storage space for the static variables of a
program is allocated from an activation group.
Once a program (type *PGM) is called, it remains activated until
the activation group it runs in is deleted. Because service programs
are not called directly, they are activated during the call to the program
that requires their services.
