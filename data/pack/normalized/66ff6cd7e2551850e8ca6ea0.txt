The SRCSTMF Parameter
The SRCSTMF parameter identifies a source stream file as a path
name. Specify the path name of the stream file that contains the ILE C
source code that you want to compile. The path name can be either
absolutely qualified or relatively qualified.
For file systems that are case sensitive, the path name may be case
sensitive.
An absolutely qualified name starts with / or
\. A / or \ character at the beginning
of a path name means that the path begins at the topmost directory, the root
(/) directory. For example:
/Dir1/Dir2/Dir3/UsrFile

If the path name does not begin with a / or \
character, the path is assumed to begin at your current directory. For
example:
MyDir/MyFile

is equivalent to
/CurrentDir/MyDir/MyFile

where MyDir is a subdirectory of your current directory.
There is no support for the tilde (~) character or wildcards
(* or ?).
SRCSTMF is mutually exclusive with SRCMBR and
SRCFILE. Also, if you specify SRCSTMF, then the
compiler ignores TEXT(*SRCMBRTXT). Other values for
TEXT are valid.
