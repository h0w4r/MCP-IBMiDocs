VALUE Clause
The VALUE clause specifies the initial contents of a data item or the value(s)
associated with a condition-name.
The VALUE clause has three formats:
Format 1 - Literal Value
Format 2 - Condition-Name Value
IBM ExtensionIBM Extension Format 3 - NULL Value End of IBM Extension End of IBM Extension

The use of the VALUE clause differs depending on the Data Division section
in which it is specified.
IBM ExtensionIBM Extension In the Linkage section, a VALUE clause used in entries
other than condition-names is treated as a comment. End of IBM Extension
End of IBM Extension In the File and Linkage sections, the VALUE clause must be used only in condition-name and type-name
entries. In the Working-Storage and Local-Storage Sections,
the VALUE clause may be used in condition-name entries, type-name entries, or in specifying the initial value of any data item. The data item
assumes the specified value at the beginning of program execution. If the
initial value is not explicitly specified, it is unpredictable.
