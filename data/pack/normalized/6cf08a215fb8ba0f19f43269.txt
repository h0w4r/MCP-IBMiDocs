DLTEDT (Delete Edit) keyword for display files

You use this field-level keyword to specify
that the IBM® i operating
system is to ignore the EDTCDE or EDTWRD keyword if either of them is specified
for a referenced field. This keyword is valid only when you specify R in position
29.

This keyword has no parameters.
If you specify a new editing
keyword, DLTEDT is unnecessary. The new editing keyword overrides the referenced
editing keyword.
Option indicators are not valid for this keyword.

ExampleThe following example shows how to specify
the DLTEDT keyword.
